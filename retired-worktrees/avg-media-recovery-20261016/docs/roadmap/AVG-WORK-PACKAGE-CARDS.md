### 3.3 BASE-01B 的实验性共享服务链路

- **配置/授权**：准备方案只解析本机现有 Agnes 路由，不发送请求；冻结原能力身份及精确 endpoint origin/path/model 的非密钥 hash。开始及执行前重新匹配，换路径须重新确认；不保存凭据。每项一笔调用、最多八项、无隐藏重试；参考权利/数据类别及有限预算由确定性代码复验。无可核实单价且有现金硬上限时不发出。
