# 《枪响以前》网站展示漫画包

《枪响以前》是一篇黑白限制色运动漫画：一名依靠视觉信号起跑的聋人短跑选手，在市赛决赛发现自己的起跑灯失灵。隔道对手主动中断发令，六名运动员把各自的灯排成所有人都能看见的一条线。

## 展示卖点

- 黑白干刷与网点呈现速度，朱红色只用于助听器、起跑灯和关键动线。
- 五页二十一格完整呈现“故障—争议—共同调整—重赛—落败但完成”的叙事闭环。
- 无障碍不是角色获得的特殊奖励，而是所有运动员共享的公平起点。
- 图片模型只负责画面，本地排字层负责对白、旁白、成绩和安全区。
