# 《凌晨四点，月亮来买面包》漫画生产说明

## 改编规格

- 形态：一话五页、二十一格、全彩固定页漫画，左至右、上至下阅读。
- 气质：都市奇幻、夜班群像、轻喜与治愈；不把夜班劳动浪漫化成无成本奉献。
- 画风：现代 ligne claire 线稿结合不透明水粉质感，柔和纸纹，造型清楚，适合网页缩略图与整页阅读。
- 色彩：深靛蓝夜景、黄油金光源、珊瑚红小面积强调、青绿色医院与街景补色。
- 文字策略：图像生成阶段禁止文字、字母、对白框和拟声词；对白、旁白、页码由本地排字层加入。

## 连续性锚点

- 江麦：27 岁中国女性，黑色齐下巴短发，左侧铜色麦穗发夹，芥末黄上衣、奶油色围裙、深蓝长裤，左脸有一道面粉月牙。
- 十六：二十岁上下的月面夜班巡检员，浅紫灰短发，银蓝短夹克带星点反光纹，靛蓝长裤，圆形银色骑行头盔；头盔右侧先有月牙裂缝，第五页修复。
- 核心道具：椭圆黄铜面包罐，盖面镂空月牙；罐内月亮碎片最初苍白结霜，逐页转为黄油金。
- 江麦的自行车：墨绿色旧式送货车，前篮有麦穗标记，后货架固定黄铜罐。
- 面包房：窄门面、圆角木质橱窗、蓝白瓷砖、黄铜门铃；第五页营业牌翻面。

## 分页与对白

### 第 1 页 · 月亮进店（4 格）

1. 横向建立格：凌晨四点的医院后街，面包房是唯一暖色窗口；江麦从橱窗取下最后一只弯月可颂。
2. 竖格：门铃响，十六推门进来，头盔右侧开裂，衣上带星点。
3. 中格：黄铜面包罐在柜台打开，苍白月亮碎片让玻璃结霜。
4. 大格：江麦与十六隔柜台对视，冷月光和烤炉金光相遇。

排字：旁白“凌晨四点，江麦准备关门。”；十六“能帮我烤一烤月亮吗？”

### 第 2 页 · 熄电与出发（4 格）

1. 烤箱近景：江麦旋温度钮，全街突然熄电。
2. 黑暗宽格：月亮碎片照亮两张脸，十六指向窗外天际缺了一角的月亮。
3. 道具格：十六在收据背面画出“日出、潮汐、七分钟”的简单图示，江麦把最后可颂装进口袋。
4. 页底动势格：两人骑墨绿送货车冲入靛蓝街道，黄铜罐固定在后架。

排字：十六“日出前装不回去，潮汐会慢七分钟。”；江麦“那就去借一座城的炉火。”

### 第 3 页 · 夜班接力（5 格）

1. 老钟把最后一勺金色高汤倒入罐中。
2. 廖护士在急诊门口倒出保温杯里的一口热茶。
3. 焊工阿明让最后一点珊瑚色焊花落入罐口。
4. 环卫工吴姨摘下头灯，青白光在碎片上停留。
5. 横向大格：自行车穿过仍在工作的夜城，罐内月亮已半数变金；医院、公交、清扫车和面馆形成连续背景。

排字：旁白“凌晨四点，城市并不空。”；四个小标签“留给晚归客的汤 / 没喝完的茶 / 收工前的火 / 借你十秒的光”。

### 第 4 页 · 还少一份（4 格）

1. 公交总站屋顶，东方泛白，十六举起碎片，它没有升空。
2. 近景：江麦掰开自己最后的弯月可颂，把一半递给十六。
3. 安静中格：江麦把黄铜罐抱在怀里，围裙与手掌把整夜积下的体温传进去。
4. 跨页高潮格：月亮像面团一样鼓起，金色光带从屋顶卷向天空，两人被光照亮。

排字：十六“还少一份。”；江麦“原来我也算夜里的一盏灯。”

### 第 5 页 · 四点半开炉（4 格）

1. 长竖格：十六骑车沿金色光带升空，头盔裂缝已合，月亮碎片归位。
2. 面包房群像：老钟、廖护士、阿明和吴姨围桌吃第一炉面包，江麦翻转营业牌。
3. 道具近景：新牌写“夜班早餐 4:30 开炉”，旁边是一盘刚出炉的月牙可颂。
4. 页底大格：靛蓝天空中完整月亮边缘像烤过的面包；地面四个夜班窗口同时有人抬头。

排字：十六“看月亮饿不饿。”；旁白“只有凌晨四点还醒着的人，看见月亮认真分走了一小块面包。”

## 自审门槛

- 五页必须形成连续动作与空间，不得成为五张互不相干的插画。
- 江麦发夹、面粉月牙、围裙和自行车；十六头盔裂缝、夹克和发色；黄铜罐的形状与发光进度必须连续。
- 每页关键动作在移除文字后仍可理解；文字不替代画面信息。
- 气泡不得遮挡人物脸、手、黄铜罐、月亮碎片和关键光源。
- 第五页既回收奇幻任务，也让夜班群体获得具体的休息、食物与互助，不以口号代替结局。
