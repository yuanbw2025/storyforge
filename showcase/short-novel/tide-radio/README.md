# 《潮汐电台》短篇展示样例

这是 StoryForge 短篇小说独立生产流程产出的完整社区展示样例。它不是提示词占位符或测试夹具，而是一篇可独立阅读、已在真实产品路径中生成、修订、审校、冻结并导出的成品。

## 成品概况

- 类型：近未来现实主义科幻悬疑
- 结构：4 章，单线限时叙事
- 正文字数：5,080 字（StoryForge 统一非空白字符口径）
- 核心悬念：失踪十年的妹妹为何仍在通过无线电准确报出实时潮位
- 人物变化：林岚从依赖规程、回避旧责，转向公开证据并承担现实代价
- 冻结版本：短篇产品 Release v3

直接阅读：[story.md](story.md)。冻结版本的校验信息、审校结论与生成链证据见 [release-evidence.json](release-evidence.json)。

## 这个样例展示了什么

1. 从创作意图、故事设计、章节卡到逐章正文的完整生产链，而不是一次性生成整篇。
2. 每章在独立候选确认后进入正式作品，并由全篇审校检查因果、时间线、人物、视角和承诺兑现。
3. 审校后修正了巡逻艇称谓、潮位数字和中文引号等真实问题；旧 Release v1、v2 保留，最终冻结为 v3。
4. 发布后的 Markdown 只读取不可变 Release manifest；后续草稿变化不会静默覆盖这个版本。

## 展示口径

仓库中的 `story.md` 与 StoryForge v3 Markdown 导出一致，保留产品内测试项目的原始标题，以便和冻结版本核对。对外展示时可使用简洁书名《潮汐电台》。作品经过 AI 辅助生成与人工终审，不应宣传为“一键直出、无需编辑”。
