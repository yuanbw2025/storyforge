# 《盐从记忆里长出来》网站展示样例

一篇近未来家庭伦理短篇：当痛苦记忆可以被析成盐，记忆治疗师蒋雾必须替罹患阿尔茨海默病的母亲决定，是否删除亡子留下的创伤。真正需要被处理的，却是母女共同误读了十八年的沉默。

## 展示标签

- 类型：近未来现实主义 / 家庭伦理 / 医疗科技
- 结构：五章伦理抉择，从治疗评估推进到不可逆操作现场
- 卖点：记忆风化、预先医疗指示、照护压力与技术边界
- 人物变化：蒋雾从试图替母亲剪掉痛苦，转向承担保留痛苦所需的长期照护
- 情绪曲线：日常异样 → 伦理冲突 → 旧事揭示 → 中断抉择 → 克制和解
- 适合网站位置：文学短篇轮播、家庭关系专题、科技伦理专题

## 复审结论

故事没有把失智症当成悬念机关，也没有用一次治疗或一次和解消除照护的现实成本。盐罐、黄色雨衣、红色浮球、停止键和两次按肩构成连续意象；高潮由专业数据越界与人物情感真相共同触发，结尾保留疾病继续发展的事实，同时兑现“先抓活着的人”的主题。
