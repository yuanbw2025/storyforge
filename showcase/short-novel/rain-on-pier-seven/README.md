# 《雨落在第七码头》网站展示样例

一篇近未来气候悬疑短篇：当城市开始出售“晴朗”，被算法视作空地的旧码头必须接住整座城市的雨。雨量审计员沈遥在台风到来前发现，十六年前被定罪的父亲留下了一套七分钟延迟协议。

## 展示标签

- 类型：近未来科幻 / 社会议题 / 气候悬疑
- 结构：五章限时调查，从晴天异常推进到台风夜公开调度
- 卖点：降雨配额、气候信用、人工测站与算法责任
- 人物变化：沈遥从寻找父亲“全对”的证明，转向建立不让任何人独自决定的公共机制
- 情绪曲线：异常 → 追查 → 揭露 → 群体行动 → 克制余韵
- 适合网站位置：短篇题材轮播、科技伦理专题、长文阅读样例

## 复审结论

故事把高概念落实到可见行动：玻璃珠、旧雨量筒、塑料桶、机械磁带和汽笛都参与破局。结局没有用一次曝光解决制度问题，也没有把有伤亡的父亲简单翻案成英雄；“公开来源与误差”既完成悬念，也兑现作品关于技术责任的主题。
