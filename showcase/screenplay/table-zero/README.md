# 《婚礼第零桌》现代群像喜剧网站展示样片

这是一部约 15 分钟的现代婚礼群像喜剧短片。五名演员受雇扮演新娘亲友；当所有角色卡被误投到婚礼直播大屏，新娘、新郎、双方家长和“第零桌”必须用真实身份决定婚礼是否继续。

## 产品卖点

- 类型差异：用现代群像喜剧补足现有都市悬疑、科技悬疑与古装短剧样片。
- 高概念开场：婚礼后台的“第零桌”集中训练五名临时亲友，角色卡在前两分钟内完成规则建立。
- 可见转折：穿帮不是口头揭露，而是临时族谱、角色卡与后台监控同时登上十五米大屏。
- 对白潜台词：人物围绕“保护、体面、角色、真实姓名”交锋，不以长篇解释替代行动。
- 可拍性：主要场景集中在酒店宴会厅、侧廊和卸货区，不依赖高成本视效。
- 成熟收束：婚礼继续不等于冲突消失；苏敏保留愤怒，唐茉提出明确条件，新郎承担公开纠错责任。

## 自审结论

12 个场景全部改变人物目标或公开信息；季夏、唐茉、顾言和苏敏拥有不同责任与选择，没有把谎言全部推给婚庆公司。喜剧来自职业细节与现场失控，而不是嘲笑新娘的福利院经历。银吊坠、角色卡、第零桌桌牌和最终合影均完成前后回收。
