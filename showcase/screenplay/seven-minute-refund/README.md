# 《七分钟退款》竖屏短剧网站展示样片

这是一套为移动端网站演示准备的 8 集都市科技悬疑短剧。它与《夜班末站》的 25 分钟电影式样片分开设计：单集约 2 分钟，每集用一个屏幕信息或实体动作开场，并以可视化反转收尾，适合竖屏阅读和低成本实拍。

## 展示文件

- `source-novel.md`：三章改编源小说。
- `seven-minute-refund-final.fountain`：8 集终稿，可导入 Fountain 兼容工具。
- `seven-minute-refund-final.fdx`：Final Draft XML 交换文件。
- `website-preview.png`：1600 × 1000 网站首屏展示图。
- `release-evidence.json`：集数、场景、格式和文件哈希等机器可读证据。

## 产品卖点

- 一句话钩子：退款审核员收到失踪弟弟发来的工单，附件显示同事将在七分钟后死亡。
- 连载结构：8 个前钩子、8 个集尾转折；信息逐层从“未来视频”翻为预演、诱饵、取证局。
- 可拍性：主要集中于风控中心、服务器间、电梯/楼梯、天台和问询室；手机屏幕承担证据推进，不依赖高成本视效。
- 改编取舍：保留源小说的责任链和姐弟情感核，将说明性材料改为门禁、硬盘、倒计时、退款按钮和执法记录仪等可见动作。

## 自审结论

每集新信息都改变人物选择，而非只延长悬念；“七分钟”先作为威胁，再被解释为预演机制，最终由女主主动关闭，构成形式与主题的双重回收。林舟是否仍活着保留开放性，但事故证据、谢闻落网和林简承担越权后果均有明确落点。
