# 《一两银子的谋杀》古装短剧网站展示样片

这是一套 6 集古装悬疑轻喜短剧。归来客栈掌柜卢青禾发现迎亲队的账面多出一两银子；随着“被杀”的新娘、父亲遗留的错账和十二名失踪女子先后出现，她必须把一笔只有幕后账房才懂的交易变成所有人都能作证的公开证据。

## 展示文件

- `source-novel.md`：三章原创改编源小说。
- `one-tael-murder-final.fountain`：6 集完整终稿。
- `one-tael-murder-final.fdx`：Final Draft XML 交换文件。
- `website-preview.png`：网站首屏与社交媒体横图。
- `release-evidence.json`：集数、场景、格式和文件哈希证据。

## 产品卖点

- 类型差异：以古装客栈、假婚案和账房推理补足现有现代都市样片。
- 连载钩子：失踪新娘、银中名单、父亲旧印、重办喜宴，每集结尾都改变下一集的行动目标。
- 可视化破案：鞋底泥、鱼线、猪血、空心银、算盘夹层、刻痕银和烧账均可直接拍摄。
- 人物声音：卢青禾用账房语言攻击问题，裴渡用自嘲掩盖愧疚，燕双从“被救者”转为共谋行动者。
- 闭环结局：反派落网来自公开证言与实物互证，不依赖最后一分钟出现的万能证据。

## 自审结论

六集均以实体动作开场或收束；一两银子的功能依次从错账、威胁、名单容器、原账校验规则，推进到群众证据。轻喜对白没有消解人口贩运主题，结尾也没有把卢青禾的人生暂停到父亲正式平反以后。
