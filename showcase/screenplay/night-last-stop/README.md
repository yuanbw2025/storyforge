# 《夜班末站》小说转剧本社区样片

这是使用 StoryForge 小说转剧本正式生产链完成并经两轮人工审校优化的 25 分钟现实主义都市悬疑样片。展示重点不是一次提示词直出，而是从来源事实、因果图、改编 Brief、删改决定、Beat Sheet、Scene Cards 到逐场写作、双轨审查、定点修订和不可变 Release 的完整闭环。

## 推荐阅读

- `source-novel.md`：用于改编的 3 章、3,370 字源小说。
- `night-last-stop-final.fountain`：最终社区展示版，可导入支持 Fountain 的专业剧本工具。
- `night-last-stop-final.fdx`：Final Draft XML 交换格式。
- `screenplay-studio-final.png`：StoryForge 正式完稿与 v3 Release 的产品界面实证。
- `release-evidence.json`：机器可读的发布、审查、时长和文件哈希证据。

## 成品指标

- 类型：25 分钟单集/短片，PG-13，现实主义都市悬疑。
- 结构：3 幕、8 Beats、8 Scene Cards、8 个完整场景。
- 正文：176 个结构化剧本块，Fountain 373 行。
- 时长：目标 1,500 秒，成品 1,500 秒。
- 审查：8 场全部完成来源/连续性审查和戏剧审查；0 个开放问题。
- 版本：不可变 Release v3，前两版仍保留用于证明修订与版本链。

## 审校优化

最终版重点修复了开场两场重复揭示“周远是否为活人”的问题：第一场停在死者姓名与断电倒计时的悬念上，第二场才通过新款助听器、当年反光条标准和临时承包商证完成现实主义证伪。标题页也替换掉了占位作者信息，形成可直接展示的社区样片版本。

格式与流程设计参考 Academy Nicholl 的剧本格式资源、BBC TV screenplay format、Fountain 官方语法、Final Draft 的 screenplay elements，以及 Sundance Collab 和 Screen Australia 关于改编与 story documents 的专业资料。
