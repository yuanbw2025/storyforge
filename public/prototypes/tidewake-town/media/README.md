# 《潮痕灯塔：回潮镇》作者媒资包

本目录保存首个后日谈 AI 小镇原型的原创生成图片。图片由本次原型制作流程生成，
只作为产品自有媒资进入 `ProductRelease`；它们不是世界引擎语义，也不会被回写到
`WorldRelease`。

`manifest.json` 将稳定的生产 Artifact key 映射到实际图片，并在导入时复验字节哈希。
后续原型可以新增自己的独立目录和清单，不共享或覆盖本包。

## 生成与权利边界

十八个媒资槽位使用 StoryForge 本次原型的原创视觉设定生成，其中包括四张独立场景背景，
以及七张同时覆盖完整站姿和三种表情的角色设计表（分别登记为立绘与表情资源）。不要求复刻任何第三方 IP、
商标、在世艺术家风格、签名或水印。提示方向分别为：暮色海湾与潮汐灯塔全景、
临海潮声诊疗室、旧船修造工坊、盐钟广场与七位居民；共同采用温暖而克制的手绘叙事游戏
语言，并为界面覆盖层或后续裁切预留可读空间。

当前清单明确标记为 `community-prototype-only`，`commercialUse=false`。这表示图片可随
首个社区原型用于非商业体验和产品验证，但在商业发行前仍必须独立复核生成服务条款、
项目权利记录和最终美术验收。生产代码不会把这批图片冒充 Agnes、OpenAI Relay 或
已经通过商业权利审查的素材。

## 接入方式

开发或受控演示部署显式设置：

```bash
VITE_STORYFORGE_AUTHORED_IMAGE_PACK_URL=/prototypes/tidewake-town/media/manifest.json
```

AI 小镇选择“内部评审”质量时，生产 Harness 会通过
`storyforge.authored-image-pack.v1` 加载本包。清单 URL 必须同源，资产路径必须位于清单
目录内，且文件大小、真实 MIME、固有尺寸和 SHA-256 必须全部匹配后才能写入产品媒资表。
