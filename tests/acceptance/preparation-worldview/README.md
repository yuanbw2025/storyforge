### 失败与修订

- 第一轮：原始输出上限2500；Agnes本机profile默认参数，没有生产端的嵌套关闭思考参数。修船新版有互助细节，但淡化雾中归船；县城新版虚构“摸方向盘感知刹车液温度”。旧新县城JSON均有语法问题。硬规则旧结果长度不完整后停止。场景消费前没有先校验结构，已记录为探索缺陷。
- 第二轮：输出上限6000，两版同用生产已验证的Agnes嵌套关闭思考参数；结构预检后才消费。完成10份材料/场景响应，第11次（硬规则旧场景）HTTP429停止；没有重发或换模型。参数变更使跨轮不能作为纯指令对照。
- 修船：旧版擅加“禁止外部资本”“经济目标非追求规模”，损害经营成长；新版恢复交易、协作和归船影响，但仍有“让生活保持简单”等泛化。新版场景“春汛收尾→等开春第一波渔汛”时序倒转，又以“沉在记忆的深海”替换本来可见的归船，不可判优。
- 县城：新版避免了首轮的错误设备常识，固定座位的视野/用途差异可用；但“被迫接受指导”等轻幽默用语不够自然。两版场景都以概括式温暖收尾；新版“送你下酒”也缺任务支持。没有足够证据宣称更好。
- 硬规则：旧版加入热铜训练与未认证高阶能力，新版擅加稀有体质、黄铜和阶层壁垒。即使放进temporaryAssumptions也不能视为忠实于作者。后续修订强调不能借假设改作者条件，熟练度不等于新增超能力；尚待复测。
- 第二轮后修订：保护关键现象的生活影响；避免编造现实技术；温暖不等于无成长；不能加血统/稀有体质和修改材质/时限。当前修订还没有新的模型收益证据，不能用测试通过替代。

神秘信仰、多世界、单意象均因前序停止而尚无本轮结果；不得当成已测。资料选择影响、完整模板、重复与留出输入也尚待实测。无真人作者/读者反馈。

## 后续实测与当前裁决（2026-11-20）

首批40份完整响应来自round4（Agnes，四组16次）、round5（DeepSeek，四组16次）、round6及round7（DeepSeek，信仰定向各4次）；它们不是40次独立文学任务。每个条件只有一份结果，信仰定向属于开发集反复修订，不能视为留出验证。round3两份响应因原版JSON非法停止，也保留。各轮模型、终止原因、回答hash及用量见model-evidence-index.json，原文和请求位于同名仓库外研究目录。

- round3仍是纯文本传输；原版JSON非法。由此核对到正式单字段入口也没有启用已有JSON对象能力。现已按已验证的provider/model启用JSON对象选项，Agnes 2.5 Flash沿现有协议关闭思考；未知服务不假设支持，不失败后降级重发。新回归检查实际冻结调用收到的选项与单次调用次数。
- round4/5两版共同采用JSON对象选项与相同预算，比较的是同一传输下的内容指令。不能将跨轮结构改善算成提示词收益。之前的结构预检只检查JSON基本形状；已用正式parseWorldviewFieldCandidateDraft对全部准备材料追验，round4信仰旧版divineRules数组、round5信仰新版value额外键不合格，其场景只算探索，不算正式候选链验收。当前评测已复用生产解析器；无效候选留样、跳过该组场景，继续其它独立样本；传输失败仍整体停止。没有修补旧回答。
- DeepSeek硬规则新版明确“学习只增加熟练度”，减少原版回弹/高阶控制等冲突；但“松手后一分钟”被写成“一分钟内恢复”，且继续塑形作为假设，需要作者核对。新版场景不再出现原版的“回弹算工序”，但没明确展示锁最终是否打开，不能全项判优。Agnes新版仍误读不恢复形状，不能宣称方法对所有模型稳定有效。
- DeepSeek多世界新版具体说明旧杂志、陶罐、白石与回信怎样延续，场景兑现带杂志的承诺；旧版在场景中把已返乡写成还要再回去。新版新增“雾推回”规则仅为提议，不自动升为正式通行规则。Agnes新版虽然有物件延续，却擅加居民永远不睡、把送杂志改成信物，仍不合格。
- DeepSeek单意象新版把月亮来历写为居民不同说法，保留“搁在竹竿上”的直接日常；旧版把薄壳裂开和世界轴心写成事实。新版收被场景也保持这一日常尺度。代价是重复“就在那儿”的静态表达较多，生活变化仍可更丰富。Agnes新版仍建立千年黄昏与隐形竹竿，且场景变成重新晾被而非收被，属于退步。
- 信仰研究暴露了字段语义：现有界面开关是“存在神明或宗教信仰”，hasDivinity=true表示启用神明/信仰设定，不证明真神存在；false会使正文在现有界面及旧上下文formatter不启用。已统一类型注释、界面说明与内容方法，沿用四键对象，不新增真相状态或迁移。不得以false冒充未知并隐藏正文。
- round7采用当前生产解析器，旧新均通过结构；新版hasDivinity=true且正文明确“神明是否存在未获确认”，可在原作者入口展示并经作者确认沿原adopt进入下游；新增回归覆盖确认前零写入、采纳后未知正文进入原世界上下文。旧版仍只回模板占位词。新版信仰中“不可替别人应答”与“大人替孩子应声”仍需审改，不能当作已通过完整内容终验。

各轮完整请求自带promptHash，实际消息是证据依据。round4期间仅调整了内容资源的换行转义，旧评测的源文件hash在结束时取得，不能单靠该hash绑定逐次消息；后续评测改在开始时冻结源码hash，保留实际请求。没有修改旧原答或挑选最好一次。

当前功能工程门通过不等于内容已全面达标。PR仍保持Draft；本轮没有合并或发行。下一批须进入轻量灵感/定位/研究、规则与文风及剩余世界/词条入口，不能以继续扩充世界样本替代完整范围交付。
