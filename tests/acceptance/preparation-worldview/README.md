## 模型研究

`node scripts/evaluate-preparation-worldview.mjs <仓库外新绝对目录> [profile]`：固定六组原创输入，旧新同模型、同输入、同组输出预算、temperature 0.3；交错顺序。同一场景指令分别消费整份旧新材料。最多24次串行、90秒超时，失败停止，无重试或换服务。仅用测试材料，不读浏览器数据库，无采纳权限。

旧系统指令原文冻结在fixture（基线commit随附）；新系统指令从当前生产构造器提取，避免导入初始化浏览器store。此评测只比较共同指令，不包含完整Gateway选择、模板渲染、正式传输和采纳；真实冻结路径由回归覆盖。单份结果、单模型和开发者审读均不证明稳定文学收益。

原答、完整请求、用量与失败保存在作者指定的仓库外研究目录 `创作准备与世界观-20261120/model-round1b` 和 `model-round2`。不把模型全文写进长期文档。

### 失败与修订

- 第一轮：原始输出上限2500；Agnes本机profile默认参数，没有生产端的嵌套关闭思考参数。修船新版有互助细节，但淡化雾中归船；县城新版虚构“摸方向盘感知刹车液温度”。旧新县城JSON均有语法问题。硬规则旧结果长度不完整后停止。场景消费前没有先校验结构，已记录为探索缺陷。
- 第二轮：输出上限6000，两版同用生产已验证的Agnes嵌套关闭思考参数；结构预检后才消费。完成10份材料/场景响应，第11次（硬规则旧场景）HTTP429停止；没有重发或换模型。参数变更使跨轮不能作为纯指令对照。
- 修船：旧版擅加“禁止外部资本”“经济目标非追求规模”，损害经营成长；新版恢复交易、协作和归船影响，但仍有“让生活保持简单”等泛化。新版场景“春汛收尾→等开春第一波渔汛”时序倒转，又以“沉在记忆的深海”替换本来可见的归船，不可判优。
- 县城：新版避免了首轮的错误设备常识，固定座位的视野/用途差异可用；但“被迫接受指导”等轻幽默用语不够自然。两版场景都以概括式温暖收尾；新版“送你下酒”也缺任务支持。没有足够证据宣称更好。
- 硬规则：旧版加入热铜训练与未认证高阶能力，新版擅加稀有体质、黄铜和阶层壁垒。即使放进temporaryAssumptions也不能视为忠实于作者。后续修订强调不能借假设改作者条件，熟练度不等于新增超能力；尚待复测。
- 第二轮后修订：保护关键现象的生活影响；避免编造现实技术；温暖不等于无成长；不能加血统/稀有体质和修改材质/时限。当前修订还没有新的模型收益证据，不能用测试通过替代。

神秘信仰、多世界、单意象均因前序停止而尚无本轮结果；不得当成已测。资料选择影响、完整模板、重复与留出输入也尚待实测。无真人作者/读者反馈。
