# 内容审读与工程验证记录

日期：2026-11-19。审读者：本任务开发 Agent；没有真实读者/作者盲评。所有比较均是探索性审读，不使用综合“文学质量分”。

## 改进依据和实际差异

| 问题 | 旧路径/产物 | 改后与仍有的限制 |
|---|---|---|
| 中后段证据消失 | 综合每维前3块×前200字；旧引用前3块×前150字 | 综合保存全部完整分块；引用使用完整条目、来源和缺省计数。超预算不截断证据冒充综合；大书仍可能明确超预算，未实现无限规模分层综合 |
| 报告隐藏反证 | 相似度仅比较句首60字，后段即使反驳也可被去重 | 报告保留每条来源，回归锁定共同句首但不同结论的反例 |
| 读者/人物知情混淆 | 原创航票样本中，旧分析写读者与人物同步知道，或把阿渡的回答归给姐姐 | 新分析识别读者先知道柜中收据，人物不知；对白归属在后轮修正。仍会把“各自替对方省事”说得过满，不能免除人工复核 |
| 将缺页当技巧 | 残页旧分析认证多个“伏笔”，给灯灭安排转折功能 | 改后明确交接/环境变化只是局部，需前后材料确认，不认证伏笔或袭击；个别叙述仍擅自假定人物不知道某事，保留失败 |
| 安静体验被模板化 | 修补铺旧分析称移椅是怕淋雨（原文雨已停），替师母现状和双方心理下结论 | 改后区分外部动作、动机解释及师母现状未知。发现新的副作用：失效条件机械要求后续回收；因此又明确“关系/氛围/感知可自行完成”，并用安静原创与孔乙己复测 |
| 公共文本过读 | 水浒71旧分析断言石碣实为宋江操控手段，援引没提供的后文李逵之死 | 新分析把明示招安分歧与伏笔分开，保留真情/治理冲突等竞争解释，不以单回认证后续后果 |
| 时间与解释 | 巡河簿留出任务旧分析把正文揭示顺序混入起承转合，还断言徒弟不敢质疑 | 新分析分别描述初九事件与初十呈现，鞋带可只是准备，也可表示停顿；仍偶有“没有后续影响就是姿态”的模板句，促成最后修订 |
| 原创迁移 | 旧、新资料×旧、新运用指令并不一致提升 | 有更具体的隐瞒/照顾动作，也有超500字、套用参考人物名、加入解释、空间站工具状态不清或因果偏离的退步。增加交付前核对；不声称稳定原创收益 |

孔乙己新分析能分开伙计见闻、传闻与死亡推断，也会把一个教学短例写成与原作过于相似的完整事件链；最后修订要求短例只演示一个决定，并改变冲突来源与因果解法。水浒001新分析仍有“读者先于人物”与“同时被点醒”的内部不一致。水浒120新分析保留争议选择和块内呼应，但不能据一回评价全书所有兑现。上述不足均未被工程成功覆盖。

最后修订的复测仍未根除模板化建议：安静样本的情节维度还写“没有后续呼应可能悬空”，与指令保留局部完成的要求存在张力；不能写成已解决所有安静体验问题。人物维度对动机保留多义解释、伏笔维度不认证未见后文，属于可核对的局部改善。

最后一轮孔乙己教学例仍出现“小店赊账—出场变化—节令欠账”的相似事件链，因此不能声称原创示例全部摆脱换名迁移；该项保留为方法候选审查的具体风险。

## 真实模型轮次

同轮均使用 `deepseek-flash`、temperature 0.3，分析输出上限8192、应用上限2048，串行、无自动重试。Agnes初轮首请求90秒超时且结果未知，停止；之后明确另建 DeepSeek 对比轮次，未混作同模型对照。

- 迭代一：5个原创材料×旧新、两例重复、两任务2×2资料/运用指令，22次。
- 迭代二：相同5材料×旧新，10次。
- 扩展轮：两原创、孔乙己、水浒001/071/120网页段落、一个在前轮后新增的原创留出任务；另有重复和2×2运用，26次。
- 最后修订：仅复测安静原创与孔乙己，旧新各一，4次；其余题材未在最后修订后再全部生成。

这些是相关样本与多次迭代，不能当作62个独立样本。旧分析在重复中有波动，不能只取最差旧稿与最好新稿。所有轮次的完整消息、原答、失败、用量及源码哈希均保留在同一WPS专项的本机研究目录，脱敏索引见 `model-evidence-index.json`。索引不含凭据、端点或用户手稿。

资料/指令2×2使用相同任务、模型、参数、最多1800字符的完整资料单元和相同输出上限。实际入选资料长度与token数不完全相等，输入指令也有长度差；只能观察，不据此独立归因。模型/开发Agent审读不替代目标读者。

元信息修正：扩展轮保存的分析消息中，fixture未给文件偏移，因此发送“未知”。随后类型检查纠正实现读取 `ChunkPlan.startChar/endChar`，定向测试验证真实字符范围。它不改变这些fixture已发送的消息；源码哈希差异不能掩作相同提交。最后修订轮绑定纠正后的实现。
