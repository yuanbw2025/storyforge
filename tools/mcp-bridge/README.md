# 可选本机 MCP 桥

普通插件无需本机桥。仅当插件需要访问你明确配置的本机 stdio 工具时使用。

需要 Node.js 22 或更高版本。复制本目录到任意位置后运行 `npm install --ignore-scripts`，或在熔炉开发仓库使用已经安装的依赖。复制 `config.example.json`，将 `origin` 改为正在使用的熔炉地址（只有协议、主机和端口），填写本机工具的绝对路径和允许调用的工具名。工具服务本身必须支持 MCP 2026-07-28 的无状态请求；此桥不把旧式有状态 stdio 服务伪装为新协议。

运行 `node cli.mjs /absolute/path/bridge-config.json`。桥只监听 `127.0.0.1`，终端显示一次临时配对令牌；把它填入熔炉宿主的外部工具面板。关掉终端即停止桥与子进程，令牌不写入作品备份。只从你信任的本机程序配置中启动工具，插件不能提供命令或额外参数。

目录公开到网上无需上传本机配置。工坊包只声明桥地址、协议和工具名。MCP 服务的部署、模型额度、原生二进制以及它需要的 Node/Python 环境由该服务自己负责。当前验证平台为开发机 macOS；其他操作系统可使用此 Node 源码，但尚未提供签名安装器或平台验证承诺。
