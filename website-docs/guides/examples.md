# 内置作品与示例

## 内置作品的移动与资源核对

《潮痕》和《远日点》的移动按实际经过时间计算，在低帧率下不再因单帧上限明显拖慢；键盘、触屏摇杆和点地寻路仍走原有碰撞检查。《盐脊》的发布资源按各自文件摘要核对，旧旅程保持原版本。卡顿或资源错误时先保留存档和实际错误信息，不以清空浏览器数据作为修复。依据 [#342](https://github.com/yuanbw2025/storyforge/pull/342)、[#375](https://github.com/yuanbw2025/storyforge/pull/375)。


从“首页 → 示例作品”或相应产品作品库进入。示例用于理解真实输出、阅读和交互方式，不能代表所有模型都能自动生成同样效果。

## 《雾港：失潮钟声》

提供文字冒险和 AVG 两种玩法，是预先编写的内置作品，不需要配置模型 API。按页面明确开始后进入独立体验与存档。

它没有运行时模型对话或配音；通关一部内置作品不表示通用文字游戏编辑器已经完成。

## 《雾港：最后一盏灯》

跑团社区预览作品，包含 AI KP、调查、同伴、秘密和结局选择。AI 相关环节需要可用模型服务，进入前检查配置和费用。

当前公共联网多人服务未部署，不要把作品的跑团桌面当作已经上线的公开多人平台。

## 《盐脊：断流之夜》

从“文字开放世界 → 先试玩《盐脊：断流之夜》”进入，无需选择工作区或配置模型。首次开始建立独立发布与存档，之后可继续自己的进度。

这是主干内置的开放世界展示作品。它展示已准备内容中的探索、任务与结局，不等于通用生产已经通过所有真实模型和真人验收。自己的作品走[文字开放世界制作流程](/features/interactive/open-world)。

《潮钟群岛：最后的灯火》是作者本地的未发布试玩，其展示与恢复代码已进入主干，但作品本身、图片和存档不随新安装自动提供，也不计入此处内置作品。其它本地开发中的作品见[待合并开发记录](/updates/development-status)。

## 三款 3D 叙事游戏

在“文字开放世界”的玩家页面找到“内置叙事游戏”，无需先建工作区、配置 API 或安装外部游戏引擎。三款游戏不在首页展示。

- **《潮痕：两声之间》**：约 4–5 分钟的独立短篇；调查水线、取工具、按顺序开闸，亲手执行两条救援路线。
- **《潮痕：最后一盏灯》**：十章海边奇幻，三万汉字以上主线、五百句以上独立对白、四种结局。
- **《远日点：第七码头》**：十章深空科幻，三万汉字以上主线、五百句以上独立对白，包含设备谜题、支路和四种结局。

建议先玩《两声之间》。桌面支持 WASD/方向键、点击移动和 E 就近交互；手机可点按界面按钮，设置提供文字探索、轻量画面和阅读方式。首次明确开始才准备独立游戏内容；刷新后可继续，另开旅程和检查点分支保留原存档。使用完整项目备份迁移进度，浏览器数据不会自动跨设备同步。

主线使用随仓库提供的冻结剧情，无自由输入模型对话或角色配音。长篇仅有可选程序化环境声，短篇暂无声音。这些作品不代表通用文字开放世界生成能力已完成。请下载包含本次更新的 `main` 或后续 Release；旧版本压缩包不会自动获得新内容。

## 《末班来信》

从“漫画 → 作品库”或“首页 → 示例作品 → 漫画”打开 50 秒动态漫画，支持全屏、有声播放和静帧对照。无需 API，不写入你的作品；已有四套页漫仍可逐页阅读和下载。

这是一部预制效果样片，不代表当前产品能自动制作同等动画。观看操作与限制见[小说转漫画](/features/comic)。

## 创作产品示例

短篇、剧本、漫画等作品库提供示例入口。阅读时观察成品结构、审校依据和交付形式；需要自己修改时，使用界面提供的独立体验副本或自己的作品，先核对当前对象。
