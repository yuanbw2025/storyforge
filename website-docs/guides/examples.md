# 内置作品与示例

从“首页 → 示例作品”或相应产品作品库进入。示例用于理解真实输出、阅读和交互方式，不能代表所有模型都能自动生成同样效果。

## 《雾港：失潮钟声》

提供文字冒险和 AVG 两种玩法，是预先编写的内置作品，不需要配置模型 API。按页面明确开始后进入独立体验与存档。

它没有运行时模型对话或配音；通关一部内置作品不表示通用文字游戏编辑器已经完成。

## 《雾港：最后一盏灯》

跑团社区预览作品，包含 AI KP、调查、同伴、秘密和结局选择。AI 相关环节需要可用模型服务，进入前检查配置和费用。

当前公共联网多人服务未部署，不要把作品的跑团桌面当作已经上线的公开多人平台。

## 创作产品示例

短篇、剧本、漫画等作品库提供示例入口。阅读时观察成品结构、审校依据和交付形式；需要自己修改时，使用界面提供的独立体验副本或自己的作品，先核对当前对象。
