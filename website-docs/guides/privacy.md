# 本地数据、模型与隐私

## 内容保存在哪里

核心创作以浏览器本地数据库为主。绑定硬盘工作区后，可通过作者确认的同步保存受支持内容。不同浏览器、地址和设备不会因此自动云同步。

## 什么情况下内容会发出去

- 启动 AI 生成、分析或审校时，本次任务所需资料会发送给你配置的模型服务。
- 使用图像、音频等外部服务时，相关请求和素材可能发送给对应服务。
- 在官方反馈中心提交表单时，你填写的描述和附件会进入官方反馈流程。

本地优先不等于使用云模型时完全离线。模型服务的保存与使用政策应以其自身说明为准。

## API Key 怎样处理

只在模型设置中填写自己的凭证，理解“记住”等保存选项。不要把 Key 放进正文、Prompt、截图或反馈附件，也不要分享含凭证的设置文件。

## 反馈内容适合公开吗

官方反馈用于创建 GitHub Issue，请按公开内容准备问题描述和附件。不要提交私密手稿、个人资料或密钥。附件会由官方反馈系统临时保存，约 10 天后自动清理；这不代表 Issue 文本也会被删除。

## 离线与费用

手工编辑、已存在内容的本地检查和备份不需要云模型。离线能否加载应用仍取决于安装、缓存和浏览器状态；远程模型调用需要网络，本地模型则需本机服务正常运行。
