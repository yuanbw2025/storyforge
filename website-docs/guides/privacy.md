# 本地数据、模型与隐私

## 内容保存在哪里

核心创作以浏览器本地数据库为主。绑定硬盘工作区后，可通过作者确认的同步保存受支持内容。不同浏览器、地址和设备不会因此自动云同步。

## 什么情况下内容会发出去

- 启动 AI 生成、分析或审校时，本次任务所需资料会发送给你配置的模型服务。
- 使用图像、音频等外部服务时，相关请求和素材可能发送给对应服务。
- 在官方反馈中心提交表单时，你填写的描述和附件会进入官方反馈流程。

本地优先不等于使用云模型时完全离线。模型服务的保存与使用政策应以其自身说明为准。

## API Key 怎样处理

只在模型设置中填写自己的凭证，理解“记住”等保存选项。不要把 Key 放进正文、Prompt、截图或反馈附件，也不要分享含凭证的设置文件。

## 反馈内容适合公开吗

官方反馈用于创建 GitHub Issue，请按公开内容准备问题描述和附件。不要提交私密手稿、个人资料或密钥。附件会由官方反馈系统临时保存，约 10 天后自动清理；这不代表 Issue 文本也会被删除。

## 离线与费用

手工编辑、已存在内容的本地检查和备份不需要云模型。离线能否加载应用仍取决于安装、缓存和浏览器状态；远程模型调用需要网络，本地模型则需本机服务正常运行。

## 官网 PV 与每日 UV 统计

官网、知识库与官网项目体验共用页面浏览量（PV）和每日浏览器访客数（UV），仅供服务器后台查看，公开页面不显示数字。每日统计按北京时间划分；同一浏览器当天重复浏览只计一个 UV，刷新和切换页面增加 PV，同页锚点不重复计数。原累计 PV 保留；日报从新功能启用后开始，首日为部分日，不补造历史数据。未来共享入口的新页面自动纳入，本地创作版与预览不参与。

UV 使用第一方随机 Cookie，30 天有效并在访问时续期，限定统计接口，不能作为账号或登录凭据。官网和知识库共用该标识；服务器只保留按日期计算的去重摘要（约 31 天后清理），不保存原始 Cookie。汇总保留，随机重试回执约一天后清理。不提交账号、IP、浏览器指纹、页面地址、查询参数、手稿或密钥。换浏览器、设备或清除 Cookie 会重新识别，因此 UV 不等于真实人数。Cookie 被阻止时仍计 PV，但不凭空增加 UV；禁用脚本、拦截请求或网络故障可能漏计。

继续阅读：[备份与恢复](/guides/backup-restore) · [模型配置](/getting-started/model-config)。

## 本地错误记录与主动反馈

浏览器最多保留最近 7 天的 20 条错误类型、时间和筛选后的代码位置；便携启动器另保留有限故障和会话状态。这些属于本机运维诊断，不进入作品库、世界版本或项目备份，不用于统计首次启动、日活或留存。

不会自动发送诊断、截图、作品、模型输入输出或密钥。你查看摘要并打开官网表单后，仍可编辑或删除，再明确提交。提交内容进入公开 Issue；浏览器错误可在通用设置中清空。具体边界见[故障反馈](/guides/troubleshooting#下载版的问题与故障反馈)。
