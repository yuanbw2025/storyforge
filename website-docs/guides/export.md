# 导出、交付与分享

先决定是“交给别人阅读”“继续在其他工具加工”，还是“以后恢复整个项目”。

| 产品 | 主要交付方式 | 交付前检查 |
| --- | --- | --- |
| 长篇 | Markdown / TXT 正文，JSON 备份 | 章节顺序与实际正文 |
| 短篇 | Markdown / TXT / JSON | 完成检查、正文、审校与版本 |
| 剧本 | Fountain / FDX / 打印 | 场景、格式、来源与双重审查 |
| 漫画 | PNG / WebP / CBZ / PDF，依版本条件 | 分镜版或视觉版、图片与排字 |
| 漫剧素材 | 提示词和参考素材工具适配包 | 镜头、物料版本、目标工具约束 |
| 世界 | 世界分享包 | 语义范围、来源、署名和许可 |
| 互动作品 | 产品内发布版本与存档 | 制作完成条件与实际游玩状态 |

## 推荐交付顺序

1. 检查当前选择的作品与版本。
2. 处理未确认候选、缺失内容和阻断问题。
3. 保存需要的发布版本或历史记录。
4. 导出后实际打开文件，抽查开头、结尾及关键内容。
5. 另外保留完整备份。

“发布”通常是保留本地不可变版本，不代表作品自动出现在公共网站。

## 分享之前

检查原文、图片、声音和参考素材的使用权。完整备份可能包含私稿、候选与运行记录，适合恢复的文件未必适合公开分享。

漫剧适配包仍需进入外部视频工具；漫画分镜完成也不等于视觉版已经具备所有图片。
