# 保存、备份与恢复

作品主要保存在当前浏览器、当前站点的本地数据库中。自动保存方便日常编辑，但不能替代独立备份。

## 先分清三种文件

| 文件 | 用途 | 注意事项 |
| --- | --- | --- |
| Markdown / TXT 等正文导出 | 阅读、投稿、外部编辑 | 不包含完整项目关系和运行记录 |
| 完整 JSON 备份 | 保存与恢复项目数据 | 保留原文件；导入时检查格式兼容性 |
| 本地记忆工作区 / 工作区包 | 可读映像、差异核对和恢复 | 同步需要作者主动检查、确认 |

## 第一次备份

![当前数据管理界面：导出导入与版本历史](/assets/current/data-current.png)

1. 打开“首页 → 数据与备份”并选择工作区；也可从对应产品的“版本与导出”或“通用设置”进入数据备份。
2. 选择完整项目 JSON 导出，确认下载文件已经存在。
3. 在另一处保留副本，文件名记录作品与日期。
4. 重要正文另存一份阅读格式。

各产品的“发布版本”有不同交付内容，不等于完整项目备份。图片和其他大素材的包含范围以导出类型说明为准；不要仅凭文件名就认定所有附件都已打包。

## 换浏览器、设备或运行地址

在线版、本地 localhost、另一个端口以及另一个浏览器可能使用不同的存储空间。先在原环境导出，再在目标环境按导入提示恢复；恢复后核对作品、章节和关键素材，再处理旧环境。

浏览器隐私模式、清除站点数据或浏览器配置丢失可能导致本地作品不可访问。

## 使用硬盘工作区

在“设置 → 项目存储工作区”绑定目录，再进入数据管理检查差异。绑定文件夹不会自动写盘，模型任务完成也不会自动同步硬盘。

详见[本地记忆工作区](/features/memory-workspace)。

## 数据突然看不见

先确认地址、端口、浏览器和浏览器配置文件是否与原来一致。不要立即清理站点数据或覆盖原目录。

有 JSON 或工作区包时按支持的恢复入口操作；旧备份被拒绝时保留原件，查看[兼容说明](/updates/compatibility)并提交反馈。
