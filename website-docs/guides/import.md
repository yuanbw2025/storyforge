# 导入已有小说与参考资料

先判断材料用途，再选入口。导入一份备份和让 AI 分析一部小说，是两件不同的事。

| 材料和目标 | 使用入口 | 是否可能调用模型 |
| --- | --- | --- |
| 恢复 StoryForge 项目 | 数据备份与恢复中的 JSON 导入 | 数据导入本身不需要 AI |
| 把已有正文变成长篇创作材料 | 长篇 → 文档导入 | 内容分析与提取可能调用 AI |
| 学习参考作品 | 长篇工作台 → 项目参考与分析 | AI 分析会调用模型 |
| 把小说改成剧本、漫画或漫剧材料 | 相应产品的原作来源入口 | 后续改编生成会调用模型 |

## 导入前

保存当前项目的完整备份。确认目标作品和世界，检查文件是否含私人资料、API Key 或没有使用权的内容。

文档支持格式以当前文件选择器为准；剧本来源入口接受 TXT、Markdown、DOCX、PDF。扫描 PDF 不应被当作一定可以提取正文的文本文件。

## 导入过程中

先检查提取文本、章节切分与来源范围，再开始需要 AI 的步骤。长材料的分析可能分阶段执行，不要仅因等待较久就同时开启多个导入。

查看导入进度、候选和报告。合并前确认重名人物、重复章节与归属，避免把相似名字当成同一个角色。

## 导入后

核对正文开头和结尾、章节顺序、关键人物和生成的结构化资料。AI 提取的事实仍可能误判，确认前需要阅读依据。

已有小说改编时保留原文来源；不要为了通过改编完成检查直接修改来源记录。

## 旧备份提示

当前备份导入有版本校验，不接受任意旧格式。保留原始备份及原运行环境，阅读[升级与兼容说明](/updates/compatibility)。不要手工改 JSON 版本号来绕过检查。
