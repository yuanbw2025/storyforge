# 费用、Token 与省钱方法

StoryForge 的 AI 使用你自己配置的模型服务。费用由服务商、实际模型和请求决定；项目不提供统一的免费模型额度。

## 哪些操作可能产生费用

| 操作 | 模型费用 |
| --- | --- |
| 手工编辑、查看已有正文 | 不需要模型调用 |
| 文件差异检查、同步、结构校验与恢复 | 本地执行，不消耗 AI Token |
| AI 生成、续写、提取、文风学习与语义审校 | 调用模型，按服务商计费 |
| 图片、音频等生成 | 按对应服务计费，不能只看文本 Token |
| 确定性格式转换与已有素材打包 | 本地处理本身不需要模型 |

## Token 应该怎样看

输入包含本次任务要求及实际读取的相关资料，输出是模型生成内容。中文字数与 Token 没有适用于所有模型的固定换算。

查看应用中的用量统计与实际模型记录，再与服务商账单核对。缺少精确用量或价格时，估算不能当作结算金额；不要根据旧价格表推算当前花费。

## 控制费用的顺序

1. 用一个小任务测试模型，再处理整章或整篇。
2. 明确修改范围；修一段对白不必重新生成全章。
3. 检查来源是否正确、资料是否足够，减少无效重试。
4. 先确认上游候选，再生成下游，避免沿错误方案继续花费。
5. 文本、图像和音频分别设预算，制作漫画前先确认分镜。
6. 错误发生时先排查认证、余额、限流和网络状态。

正式创作流程对修复和重试设有边界，但一次完整产品流程可能包含多个任务，不能理解为整部作品最多只调用一两次模型。

## 模型与上下文

上下文窗口越大，不代表所有资料都值得发送。选择符合任务的模型，使用准确的章节任务和已确认资料；检索帮助查回依据，但不能替代作者检查。

本地模型可能没有按 Token 的外部账单，但仍有设备、内存、时间和电力成本。
