**为什么要关心 Token？**

用 AI 写小说，每一次请求都会消耗 Token。Token 是大语言模型计费的基本单位——你发给 AI 的内容（输入 Token）和 AI 回给你的内容（输出 Token）都会计费。

中文大约 1 个汉字 ≈ 1.5 个 Token（各模型有差异，故事熔炉内置的估算就用这个比例）。

这意味着什么？

写一章正文，消耗几千 Token，几分钱，你不会在意。

但如果你用大师研读分析一本百万字长篇，消耗可能飙到数百万 Token——选错模型，一次分析就能花掉好几块钱。

故事熔炉做了三件事来帮你省钱。

**第一件事：Token 全透明——花了多少，一目了然**

流式生成实时估算

AI 生成文字时是逐字输出的（流式）。在流式生成过程中，故事熔炉会实时显示当前已生成的 Token 估算值，让你在等待的过程中就能感知消耗量级。

生成结束后，如果 AI 平台返回了精确的 Token 用量（大多数平台都会返回），估算值会自动替换为精确值，分为输入 Token（↑）和输出 Token（↓）两部分。

**全模块 Token 显示**

不只是章节生成——故事熔炉的以下模块全部会显示 Token 消耗：

你在故事熔炉里触发的每一次 AI 调用，消耗都会显示在你眼前。没有隐藏消耗，没有暗箱操作。

第二件事：上下文窗口预算管理——智能裁剪，不浪费一个 Token

**问题：上下文越长，Token 越贵**

写到第 50 章的时候，你的世界观、角色设定、大纲、前文摘要加在一起，可能已经有几万字了。如果全部塞进 AI 的上下文窗口，每次生成都要消耗巨量输入 Token。

但实际上，很多信息对当前这一章的生成并不关键——比如角色 A 的完整背景故事，在角色 A 不出场的章节里是多余的。

**解决方案：四层分级注入**

故事熔炉把所有上下文内容分为四个优先级层：

上下文预算进度条

在章节编辑器中，每次触发 AI 生成前，你会看到一个上下文预算进度条。它用四种颜色分别标示 L0-L3 各层的 Token 占比，并显示总用量相对于当前模型上下文窗口的百分比。

绿色：充裕，随便用

黄色：接近上限，注意控制

红色：超出窗口限制

自动裁剪

如果上下文超出了当前模型的窗口限制，故事熔炉会提示你，并提供一键自动裁剪功能——从 L3 层开始，逐层削减低优先级内容，直到总 Token 数回到安全范围内。

你不需要手动去删减世界观或前文。系统帮你做，而且一定是先砍最不重要的内容。

**第三件事：大师研读专用模型——批量分析不再烧钱**

**问题的真实案例**

群里有用户用 DeepSeek V4 Pro 分析了一本 125 万字的小说，花了 5.44 元。

这是因为他在全局设置里选了 deepseek-v4-pro，大师研读的分析流水线直接使用了全局模型。125 万字切成 50 块分析，每块都要调用一次 AI，Pro 模型输入 ¥3 + 输出 ¥6/百万 Token，积少成多就很可观了。

主要还是要考虑你自己的需求，是想要分析的质量更佳，还是找个平衡，还是大致看一下。在成本和效果之间找到一个平衡。

像这个字数，用 GLM-4 Flash 或魔搭 Qwen3 分析同一本书是 ¥0，用 DeepSeek Flash 大概是 ¥2.5。

**解决方案：分析专用模型**

故事熔炉现在支持为大师研读单独配置一个 AI 模型，和你日常写作用的模型互不干扰。

在「学习设置」Tab 里，你可以看到一个「分析专用模型」选择器，提供了 7 个推荐选项。你可以全局用 DeepSeek V4 Pro 写高质量正文，但分析时自动切到 Flash 甚至免费模型。

费用预估面板

在添加作品时，故事熔炉会根据你选的分析深度和当前分析专用模型，实时计算并显示预估费用。你在点击「开始分析」之前就能清楚地知道这次分析大概要花多少钱。

如果预估费用超过 ¥2，系统还会主动提醒你是否愿意切换到更便宜的模型。

省钱实战建议

日常写作

不需要刻意省。从上面的场景 A 可以看到，用 DeepSeek Flash 写 100 章也就 ¥3，Gemini Flash 在免费层更是零成本。

关注上下文预算条。如果经常显示黄色或红色，说明你塞了太多上下文，可以考虑精简世界观描述或切换到更大窗口的模型（Gemini 的 100 万窗口容量较大）。

浮动工具栏的润色/扩写等操作消耗很小（选中几百字，输入输出各几百 Token），放心用。

如果你追求性价比：DeepSeek V4 Flash（¥1 输入 + ¥2 输出）或 Qwen Plus（¥0.8 + ¥4.8）是最佳选择。

如果你追求质量：DeepSeek V4 Pro 的深度思考、Claude Sonnet 4 的文学表现力确实更好，建议只在写关键章节（高潮、转折）时用贵模型。

大师研读

第一件事：去学习设置选个便宜模型。GLM-4 Flash 和魔搭 Qwen3 完全免费，DeepSeek Flash 两三块钱就能分析一整本百万字小说。

分析深度选「快速」可以先试水。快速模式切块更大（4 万字/块），AI 调用次数只有深度模式的约 1/3。

巨型作品（百万字以上）强烈建议用免费模型。Flash 模型的五维分析已经足够提炼出有价值的方法论，不需要 Pro 级别。

技术细节（给感兴趣的同学）

Token 估算原理

流式生成中：中文字符按 1.5 Token/字估算，英文/标点按 0.25 Token/字符估算

生成完成后：如果 API 返回了 usage 字段（包含 prompt_tokens 和 completion_tokens），则用精确值替换估算值

上下文预算计算：对每个上下文段（系统指令、世界观、角色设定等）分别估算 Token 数，再加总

上下文分层注入的工作方式

大师研读的分块策略

块数直接决定 AI 调用次数，也就直接决定费用。快速模式的块数是深度模式的 1/3 左右。

分析专用模型的实现方式

故事熔炉维护两套 AI 配置：

全局 AI 配置：在「系统设置 → AI 配置」中管理，用于日常写作、审校等

分析专用配置：在「大师研读 → 学习设置」中管理，仅用于作品分析流水线

分析流水线在调用 AI 时，会优先读取分析专用配置。如果未设置专用模型（选的是"跟随全局设置"），则退化为使用全局配置。两套配置共享同一个 provider 的 API Key，你不需要填两次。

总结

故事熔炉的目标是：让你把钱花在真正需要好模型的地方（写正文），而不是花在可以用便宜模型完成的地方（批量分析）。
