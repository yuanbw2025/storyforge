# 常见问题

## 必须先创建世界才能写小说吗？

不需要。长篇和短篇可以独立创作。需要复用时，再由作者显式派生世界。见[项目、作品与世界](/concepts/work-world)。

## 不配置 API 能用吗？

可以手工整理与编辑作品，也可体验免 API 的《雾港：失潮钟声》。AI 生成、分析和部分互动需要自己的模型服务。

## 为什么同样是 3.9.1，界面却不同？

正式 Release 固定在发布时间，而 main 后续已有大量变化。版本号未变不代表代码相同；排查时补充构建 commit 和访问地址。见[版本说明](/updates/compatibility)。

## 为什么换地址或浏览器后作品不见了？

各站点和浏览器有独立存储。先回到原地址、端口和浏览器检查，再导出备份。不要清除原站点数据。见[备份与恢复](/guides/backup-restore)。

## AI 生成了，为什么还要点确认？

生成内容通常先是候选，作者确认后才写入正式作品。还可能需要处理结构问题或版本过期。见[AI 工作流程](/guides/ai-workflow)。

## 改了世界，为什么已有游戏没有变化？

游戏引用的是封存版本，已有产品和存档保留自己的依据。编辑世界草稿不会自动改写旧作品。见[封存与发布](/concepts/versions)。

## 发布是不是自动上传到社区？

通常不是。产品中的发布主要用于保存不可变版本供导出或游玩，公共社区、账户与云同步不能视为已经上线。

## 模型测试成功，为什么某个任务失败？

连接成功不代表所有模型能力、输入长度、账户额度和输出格式都满足要求。先用小任务测试，再看具体错误。见[故障排查](/guides/troubleshooting)。

## 为什么漫画不能直接使用参考图？

参考图是否实际发送取决于图像服务适配器。提示词里写到参考图不等于模型收到了图片。见[漫画指南](/features/comic)。

## 漫剧素材能直接生成完整视频吗？

当前交付止于外部视频生成之前：准备剧本、分镜、素材与工具提示词包。生成视频和后期制作在外部工具完成。

## 系统 Prompt 与用户 Prompt 有什么区别？

系统 Prompt 通常表达任务规则和角色要求，用户 Prompt 表达本轮具体目标。它们都不能保证模型绝对遵守所有要求；仍需检查结果。可以从[Prompt 使用说明](/guides/using-prompts)开始。

## 如何反馈问题？

使用[官方反馈中心](/feedback/)，提供版本、步骤和错误文本。删除密钥、私稿及个人敏感内容后再提交。
