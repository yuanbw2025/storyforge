**一、 system Prompt和user Prompt有啥区别呀**

system Prompt是系统设定，user Prompt是任务具体要求。

系统设定就是给大模型的全局规则、底层规则。你的user提示词是让它执行的具体任务。

模型在执行不同的任务（user提示词）的时候，必须要遵守一个底层的规则（system提示词）。打个比方，就像是我们在生活中会做各种各样的工作，但必须遵守法律，大概是这个意思。

所以你在做个性化提示词的时候，系统规则建议用大而化之的东西，比如遵循故事写作规则，保证情节逻辑，理解情绪节奏，在user提示词的时候，就让它写具体的故事或者你想要的具体的东西，比如主角被追杀、主角被追杀的时候爱上了追杀他的人这种具体的故事，模型会在执行你的任务的基础上，遵循系统提示词的要求，合理安排故事规则、情节逻辑、情绪节奏这些东西。
