# 反馈

如果你发现问题、希望提出建议，或需要纠正文档，可以通过以下 GitHub Issue Forms 提交。

<div class="feedback-grid">
  <a class="feedback-card" href="https://github.com/yuanbw2025/storyforge/issues/new?template=bug.yml" target="_blank" rel="noreferrer"><strong>Bug 报告</strong><span>报告可以稳定复现的问题，支持截图、录屏和附件。</span></a>
  <a class="feedback-card" href="https://github.com/yuanbw2025/storyforge/issues/new?template=feature.yml" target="_blank" rel="noreferrer"><strong>功能建议</strong><span>说明使用场景、问题和你希望的改进方式。</span></a>
  <a class="feedback-card" href="https://github.com/yuanbw2025/storyforge/issues/new?template=documentation.yml" target="_blank" rel="noreferrer"><strong>文档纠错</strong><span>指出不准确、过时、缺失或不清楚的说明。</span></a>
</div>

::: info 国内反馈入口
后续可在 `feedback.storyforge-lab.com` 增加无需 GitHub 账号的中文表单，再由服务端把确认后的反馈同步到 GitHub Issues。当前页面先使用 GitHub 原生表单。
:::
