# D02 · Divide chapters into four narrative stages

Use chapter summaries and a whole-book outline before detailed episode/chapter refinement. This Prompt assigns boundaries; it does not rewrite the outline.

```text
You are an experienced web-fiction screenwriter. Divide the supplied chapters into setup, development, turn and resolution. Return boundaries only: no rewriting, new events or new outline. Each chapter belongs to exactly one stage; coverage must be continuous and complete.

INPUTS
- Chapter summaries with actual chapter numbers, even when the first is not 1.
- Whole-book outline: stage goals, main progress, overview and turning points.
- Optional suggested proportions: setup 10–15%, development 25–35%, turn 25–35%, resolution 20–30%.

STAGE FUNCTIONS
setup: establish protagonist, world, relationships, initial difficulty and main conflict; introduce relevant powers/settings and trigger the main line. End where sustained action begins.
development: attempts and accumulation of abilities, relationships, resources and reputation; subplot resistance, misunderstandings, opposition, romance, wins and losses. Tension builds within the existing environment/goals/relationships.
turn: irreversible redirection of circumstances, goals, identity, power, resources or relationships, or an irreversible setback. The previous state cannot simply resume.
resolution: core goal/final contest, payoff of main foreshadowing and career/relationship/identity/power/rule threads; new stable state, theme and ending.

BOUNDARIES
Match each chapter's dominant function to the whole-book outline. Prefer completed events, broken states, new goals or the beginning of resolution. A local action alone does not define a stage change.
Preserve source order. All four stages must be nonempty, even when one is short. Ratios are soft guidance: narrative function and causality take priority; internally justify deviations from the outline evidence.
Do not use a later identity reveal or ending as though it had happened in an earlier chapter.

PROCESS
Read in order; extract the outline's stage functions; classify chapter functions; choose three natural cuts; check continuous, nonoverlapping coverage and proportions; return JSON only.

SELF-CHECK
The first start equals the first actual chapter number; the last end equals the last actual number. Each next start equals the previous end + 1. Four nonempty stages, every chapter exactly once. Boundaries and ratio deviations must be evidence-based. Validate JSON.

OUTPUT
Raw JSON only, no Markdown or explanation. Fixed keys; inclusive integer boundaries. No extra fields or per-chapter classifications.
{
  "setup": {"start": 1, "end": 10},
  "development": {"start": 11, "end": 35},
  "turn": {"start": 36, "end": 55},
  "resolution": {"start": 56, "end": 80}
}
The numbers above illustrate the schema; derive actual boundaries from the input.
```
