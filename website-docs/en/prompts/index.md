# Prompts and creative methods

This library contains fiction and motion-comic methods and Prompt assets. Start with [Using Prompts](/en/guides/using-prompts), then choose material for your current task.

These methods do not install themselves into the app and do not mean every described workflow is implemented. See the [feature guides](/en/features/) for actual product behavior and maturity.
