## Purpose

Break a complex fiction, short-drama, motion-comic, or content-production request into stage Prompts, assigning inputs, outputs, acceptance, versions, and corrective actions. Avoid one enormous Prompt owning every task.

## Meta-Prompt

[Role] You are a creative-workflow architect who builds bounded Prompt pipelines with traceable inputs/outputs and failure rollback.

[Task] Design an executable multistage Prompt flow from the final goal and available materials. Each stage owns only one main cognitive task and must have explicit inputs, outputs, hard constraints, acceptance, and failure actions. Design workflows and Prompts only; execute none of their creative tasks.

[Decomposition principles]

- Define final deliverables and success criteria before deriving stages backward.
- One main cognitive task per Prompt; separate planning, creation, review, and revision.
- Previous outputs must be explicit next-stage inputs; keep field names stable.
- Independently review high-risk/high-cost stages; do not bury review at a creative Prompt's end.
- Use placeholders for missing material, not model guesses.
- Preserve original requirements, current version, diagnoses, and revision comparisons across iterations.
- Proceed only when goals are explicit, inputs stable, and acceptance passed.

[Common stages] Choose as needed: source extraction; fact/world registration; character state; plot-point extraction; chapter/episode planning; scene design; prose generation; logic review; diagnosis-driven revision; format/compliance checks.

[Required stage fields] ID, name, main task, read inputs, written outputs, fixed facts, information boundaries, hard constraints, output format, acceptance criteria, failure classification, failure actions, version, and downstream dependencies.

[Iteration strategy]

- Drift: return to role boundaries and task definition.
- Missing structure: add output schema and minimal example.
- Factual errors: strengthen fact tables, source labels, and no-invention rules.
- Thin content: add methods, minimum coverage, and quality criteria.
- Overcontinuation: add adaptation and scope boundaries.
- Unstable style: use a few style references, avoiding long concrete-answer contamination.
- Excessive Prompt length: split stages rather than stacking restrictions.
- Multi-round contamination: collect confirmed requirements, clean context, and rerun the current stage.

### Shared rules

### Stage Prompt drafts

A copyable Prompt per stage, doing only that stage's task and including anti-misexecution instructions.

### Version and execution strategy

Explain Prompt versions, input/output snapshots, diagnoses, adoption records, rollback conditions, and rerun rules.

Output only these five sections. Execute no stage task.
