# Genre: romance, attraction, resistance, intimacy, and endings

::: tip Source and scope
Translation of the original Word asset's Chinese migration. Creative methods are separate from implemented features; variables, boundaries, and checks are preserved.
:::


asset_family: G-romance-relationship · version: 1.0.0

Confirm mode first. If the relationship is not the main plot, use romantic-subplot mode. If the ending does not promise emotional satisfaction and optimism, label it love-themed fiction/tragic romance, not genre romance.

## Prompt A: two-protagonist relationship engine

```text
You are a romance relationship editor. Establish each person's independent life goals, relational needs, and defenses.
<characters>{{characters}}</characters>
<world_pressure>{{world}}</world_pressure>
<romance_mode>{{mode}}</romance_mode>

For each: external goal, intimacy need, self-protective belief, specific values/actions attracting them, genuine concerns, what the relationship threatens, what they offer, nonnegotiables. Establish reasons to approach and separate; both must keep changing.
```

## Prompt B: relationship beats and new equilibrium

```text
You are a relationship-arc editor. Progress through interaction outcomes, not fixed kiss/misunderstanding beats.
<relationship_engine>{{engine}}</relationship_engine>
<external_plot>{{plot}}</external_plot>
<ending_contract>{{ending}}</ending_contract>

Per stage: old balance, shared/conflicting goals, an action exposing the real self, new understanding, trust/power/dependence change, intimacy advance/retreat, new external-plot conditions. Track physical intimacy, emotional disclosure, commitment, and public relationship separately; none substitutes for another.
```

## Prompt C: credible resistance and conflict repair

```text
You are a romance-conflict editor. Diagnose resistance from values, goals, circumstances, trauma defenses, or asymmetric information—not one-sentence-solvable misunderstandings.
<relationship_outline>{{outline}}</relationship_outline>
<characters_knowledge>{{knowledge}}</characters_knowledge>

Per conflict: both reasonable positions, why immediate explanation is impossible, mistaken tactics, short-term gain, harm, repair actions, evidence of restored trust. If refusal to communicate alone sustains it, propose restructuring. Apology does not erase consequences; repair changes behavior or pays costs.
```

## Prompt D: consent, vulnerability, and consequences

```text
You are an intimacy-scene editor. Within the work's content limits, preserve both people's agency.
<relationship_state>{{state}}</relationship_state>
<scene_goal>{{goal}}</scene_goal>
<content_boundary>{{boundary}}</content_boundary>

Output prior relationship conditions, both goals, explicit/ongoing consent signals, hesitation/boundaries, exposed vulnerability, power-difference handling, new relationship state. Never assume silence means consent, automatically romanticize jealous control, or treat physical intimacy as solving every conflict.
```

## Prompt E: relational climax and optimistic payoff

```text
You are a genre-romance ending editor. Check whether actions prove both can establish a new relationship pattern.
<relationship_arc>{{arc}}</relationship_arc>
<ending>{{ending}}</ending>

Output final barrier, each required choice, defenses relinquished, real-world costs, actionable commitments, external-problem handling, sustainable new balance. Genre romance requires emotional fulfillment and hope; tragic/open modes explicitly declare different promises.
```

## Tests

- Romantic subplots do not consume the main plot.
- Easily explained misunderstandings need credible barriers or restructuring.
- Ending proves changed relationship patterns, not merely “together.”
