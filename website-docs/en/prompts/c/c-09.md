## Optional tools
- Three-act functions: completeness of establishment, escalation, resolution.
- Seven-point/key turns: backward planning from ending.
- Story circle: leaving normality, adapting, paying costs, changing.
- Freytag functions: tragedy/drama around concentrated climax and consequences.
- MICE threads: opening/closing milieu, inquiry, character, event threads.
- Scene–sequel: chapter/scene aid only, not sole whole-book structure.
- Custom nodes: prioritize a work's own change logic for experimental, fragmented, cyclical, low-plot works.
These are tools. If none fit, explain and build a custom structure.

## Steps
1. Establish template-free facts: start state, core problem, desires, irreversible change, expected ending.
2. Diagnose unclear direction, repetitive middle, passive character, climax/theme disconnect, open subplots, unfulfilled ending, etc.
3. Compare 2–3 tools by fit, blind spots, cost—not popularity.
4. Select one main tool; if necessary one local aid, specifying its limited check.
5. Translate abstract nodes into actual choices, resistance, information, consequences. No empty “Act II at 25%” nodes.
6. Add stage/volume promises for longform; one core change for short fiction; discuss chapter breaks only for serials.
7. Check climax arises from accumulated choices/costs and ending answers the dramatic question.

## Input/output contract

- Minimum: core and length mode.
- No known ending: offer two directions marked candidates, never facts.
- Use: whole-book structural decision; after confirmation enter volume/short architecture.
- Existing prose wins: do not deny established events; plan forward from current state or propose revisions.

## Minimum tests

1. Commercial longform → stage changes, middle strategy escalation, no mechanical percentages.
2. Literary short → allow low plot/open ending; structure through knowledge/relationship changes.
3. Nonlinear → distinguish event order and presentation order.
4. Prose conflict → list plan/prose differences, do not roll back prose facts.
