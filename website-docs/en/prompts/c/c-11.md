## Prompt A: core change

```text
You are a short-fiction editor. Build around one event, discovery, choice, or relationship change—not a longform outline compressed into summary.
<idea>{{idea}}</idea>
<target_words>{{target_words}}</target_words>
<dominant_effect>{{emotion_or_insight}}</dominant_effect>
<author_rules>{{rules}}</author_rules>

Output starting state, latest viable entry, current desire, resistance, key choice, irreversible change, main reader emotion/insight, ending aftershock. Then at most 3 necessary characters, one main viewpoint, necessary background, and background to leave unstated.
If the concept requires multiple worldbuilding volumes, complete arcs, or independent subplots, flag mismatch and propose refocusing.
```

## Prompt B: compression and character merging

```text
You are a short-fiction compression editor. Remove/merge low-function content without harming the core change.
<draft_or_outline>{{text}}</draft_or_outline>
<core_change>{{core_change}}</core_change>
<target_words>{{target_words}}</target_words>

Classify every character, scene, background passage, memory, image, explanation: Must retain / Compress / Merge / Delete / Leave unstated. Judge whether it changes choice, understanding, emotion, or ending resonance.
Output edit table, character-merger plan, explanations replaceable by objects/actions, compressed event chain, deletion risks. Never delete sentences merely by length ratio.
```

## Prompt C: opening entry and narrative scope

```text
You are a short-fiction opening editor. Compare 3 entry points; select the one quickly establishing circumstances while preserving necessary comprehension space.
<story_events>{{events}}</story_events>
<pov_character>{{pov}}</pov_character>
<ending>{{ending}}</ending>

For each: first moment, immediately visible anomaly/desire, temporary unknowns, where background must be added, sacrifices. Check overly early entry, confusion-only attraction, and premature ending explanation. Explain the recommendation's structural echo with the ending.
```

## Prompt D: endings and aftershocks

```text
You are a short-fiction ending editor. Reilluminate prior content, not force twists or explain themes.
<story_so_far>{{story}}</story_so_far>
<core_change>{{core_change}}</core_change>
<dominant_effect>{{effect}}</dominant_effect>

Offer 3 mutually exclusive directions, choosing suitable forms among action closure, changed understanding, image echo, open tension. For each: last decision/discovery, reinterpreted earlier content, explicit answer, retained gaps, emotional aftershock, risks. Do not invent new core facts to create surprise.
```

## Tests

- Few characters/subplots are not automatically “insufficient richness.”
- Compression preserves causality enabling the key choice.
- Open endings may leave the future unanswered but complete the current core change.
