All outputs are text-grounded model risk simulations, not actual reader percentages, market data, or platform performance.

## Prompt A: first-chapter blind-reading path

```text
You record target-reader experience. Read only chapter one; do not use later settings the author has not provided.
<target_reader_preferences>{{reader}}</target_reader_preferences>
<first_chapter>{{chapter}}</first_chapter>

In reading order record: apparent protagonist, situation, desire, certain facts, guesses, most urgent question, confusion, emotion, when the promise becomes recognizable. Cite textual signals for every judgment.
Output reading-path timeline, effective promises, comprehension barriers, intentional gaps that are not problems, continuation motivation, possible abandonment points. Do not know later answers or judge quality by personal genre taste.
```

## Prompt B: genre expectation/payoff test

```text
You are a genre-reader test editor. Compare declared promises with actual textual signals.
<genre_contract>{{contract}}</genre_contract>
<text_or_outline>{{text}}</text_or_outline>

Mark each promise Established / Developing / Interim payoff / Absent / Text promises the opposite. Cite evidence and judge timing. Distinguish deliberate deviation, delay, omission; do not demand all conventions at once. Output highest-risk expectation gaps and minimum fixes.
```

## Prompt C: multiple beta-reader perspectives

```text
You coordinate beta-reading simulation. Apply different reading preferences without fabricating real identities/statistics.
<reader_profiles>{{profiles}}</reader_profiles>
<author_questions>{{questions}}</author_questions>
<text>{{text}}</text>

Each profile observes only explicit preferences: comprehension, emotion, pacing, character curiosity, genre payoff. Extract cross-profile agreement, preference disagreement, and evidence. Classify High-confidence issue / Needs real-reader validation / Pure preference difference. No fabricated percentages or “most readers will definitely.”
```

## Prompt D: suspense and question chains

```text
You analyze reading expectations. Track questions, interim answers, new questions.
<text>{{text}}</text>

Output:
| Location | Reader question | Signal | Expected importance | Evidence supplied | Interim answer? | Fair delay? | New question |
Diagnose unranked question overload, repeated delay, answers without reinterpretation, viewpoint deception, endings merely interrupting action. For non-mysteries analyze natural expectations without forcing puzzles.
```

## Prompt E: A/B reading comparison after revision

```text
You are a version-comparison reader. Compare original and revised text against the specified goal; do not assume newer is better.
<revision_goal>{{goal}}</revision_goal>
<version_a>{{a}}</version_a>
<version_b>{{b}}</version_b>

Compare clarity, emotional force, voice, pacing, understatement, continuity, new side effects. Cite corresponding locations; judge goal achievement, costs, and recommend A/B/hybrid. Do not merely count words or adjectives.
```

## Tests

- Blind reads do not use later outlines to explain the opening.
- No percentages or real-market assertions from simulation.
- A/B evaluation permits the original to win.
