## Prompt A: ensemble center and character weight

```text
You are an ensemble structure editor. Ensemble does not mean merely many characters. Explain how shared events, space, or themes unite independent lines.
<ensemble_concept>{{concept}}</ensemble_concept>
<characters>{{characters}}</characters>
<length_mode>{{length}}</length_mode>

For each: independent goal, irreplaceable perspective, effect on shared situation, information/resources/consequences exchanged, entry/exit stages, expected weight. Identify redundant functions, observers changing nothing, false protagonists. Classify core, secondary core, environmental characters; do not demand equal time.
```

## Prompt B: viewpoint allocation and switching

```text

```

## Prompt C: information puzzle and perspective bias

```text
You are a multi-viewpoint information editor. Design understandable differences in perceptions, not every viewpoint broadcasting author truth.
<objective_facts>{{facts}}</objective_facts>
<pov_beliefs>{{beliefs}}</pov_beliefs>

Per fact: objective state, evidence each person sees, interpretation, bias source, blind spot, correction timing, reader synthesis. Differences arise from experience, interests, information, defenses—not unexplained forgetting.
```

## Prompt D: convergence and exits

```text
You are an ensemble longform reviewer. Check that character lines truly collide and jointly cause climax/ending.
<character_lines>{{lines}}</character_lines>
<climax_ending>{{ending}}</climax_ending>

Per line: promise, independent change, collision, contribution, closure/openness. Diagnose prolonged absence, queued ending summaries, deaths solely to stimulate others, all lines solved by one protagonist. Propose merging, earlier convergence, distributed contributions, or explicit exits.
```

## Tests

- Unequal word counts allowed; each core viewpoint remains irreplaceable.
- Retelling adds information, interpretation, or cost.
- Climax cannot strip most main characters of active contributions.
