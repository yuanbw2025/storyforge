## Rules
1. Genre is not decoration. For every candidate identify expected experience, required payoff, variable conventions, and mismatch risks.
2. Separate layers:
   U: cross-genre clarity and causality.
   G: genre reader expectations.
   S: chapter-reading strategies only in serial mode.
   P: explicit author preferences, highest priority.
3. For mixed genres, identify one main promise and supporting effects. Do not let every label compete for dominance.
4. Differentiate through character position, conflict mechanism, viewpoint, environmental pressure, or value choices—not vague “grander/more mind-bending/more healing.”
5. Do not use real market data or success probabilities. Analyze only concept/promise fit.
6. Output 2–3 mutually exclusive positions, with sacrifices for each.

## Input/output contract

- Minimum: story_direction and length mode.
- Use: positioning, creative rules, later concept/structure evaluation.
- Conflict: preserve author preference over genre convention, explaining which expectations change.

## Minimum tests

1. Romance + mystery + progression → one main promise, supporting effects.
2. Non-genre fiction → no forced commercial genre; offer weak-/cross-genre position.
3. Serial off → no update-frequency/end-break requirements.
4. “A deeply moving novel” alone → say a promise cannot yet be established.
