# Project references, work analysis, and retrieval

Entry: Longform workbench → Inspiration and references → Project references and analysis (灵感与参考 → 项目参考与分析). References support learning and evidence; uploading a file does not make it an official setting of your work.


## Sharing novels and book analysis publicly

Select public chapters at the novel entry, or select analysis content under Document parsing → Project references → Work analysis. Confirm chapters, analysis entries, description and genres separately. Inspect the exact generated public preview, enter a public pen name and license, and confirm publication rights. Email OTP signs into the community account while local writing remains independently available.

Submission creates a fixed snapshot of the selected content. Check My submissions and review status after submission. Content becomes public after approval, with uncertain cases sent for human review. Open Reading space for the bookshelf, messages and flower baskets, or Manage submissions and updates to inspect, withdraw or appeal a submission. Confirm the version before withdrawal. Unselected chapters, notes, source files, prompts and local settings stay on the device. Verify rights for quotations and third-party content in analysis. See [PR #234](https://github.com/yuanbw2025/storyforge/pull/234).

## Choose the right purpose

| Need | Appropriate entry |
| --- | --- |
| Import your own novel manuscript | Document import |
| Study a reference work's structure, characters, or techniques | Project references and analysis |
| Learn your own revised language habits | Style learning |
| Manage searchable creative research | Materials and retrieval |

Keeping these purposes separate prevents importing a reference novel's characters and plot as your own work.

## Analysis depth and source use

Choose the analysis depth needed. Long materials may be processed in chunks, with progress and analysis versions recorded. Deeper analysis is not always more suitable; it also means more model calls and waiting.

Check source type, usage scope, and rights notes. Research materials or unknown sources have stricter usage scope. Permission to analyze does not mean permission to copy into original work.

## Pending, active, and historical versions

Completed analysis starts pending confirmation. Review the new report and differences from the active analysis before activating an appropriate version. Older reports remain historical rather than being overwritten by every analysis.

A failed or cancelled analysis is not active. After re-uploading or reanalyzing, check which version is still in use.

## How it affects writing

Reference analysis turns materials into reviewable conclusions. Whether later generation reads them depends on the task, reference settings, and actual context. Putting a file in the library does not make the model read it in full every time.

Distinguish historical facts, narrative techniques, and fictional settings. Research still needs evidence checks; using a technique is not copying a plot or character.

## Difference from longform memory

Project references store external materials and analyses. Your own prose, confirmed facts, summaries, and post-chapter states provide continuity evidence. External references cannot override confirmed facts of your work.
