# Character-driven plotting

Entry: Longform workbench → Character-driven (角色驱动). Derive plots from desires, contradictions, and change, then use a selected plan for outlining or later writing.

## Planning and revision

New-work planning develops character arcs and plot plans; revision adjusts an existing work. Decide whether you are exploring a possibility or replacing established planning.

Character cards describe current information; arc plans describe how characters may change. Future states that have not happened must not be treated as current character facts.

## Manage multiple plans

Create plans, duplicate them as new versions, rename them, and browse between them. Viewing and activating are different:

- Set as current reference (设为当前参考) explicitly decides which plan later outline and prose AI uses.
- Later AI is referencing this (后续 AI 正在参考) identifies the active plan.
- Browsing candidates does not make all of them current references.

To compare different character directions, duplicate a plan before editing and preserve the basis for your choice.

## From character to volumes and chapters

Add characters, check information imported from their cards, and complete arcs and extra requirements. After generation, check the causal connection between choices and events, then review volume/chapter candidates.

Adopting into the outline and setting the current reference are separate actions: the former changes selected outline content; the latter controls which plan later generation references. One does not automatically perform the other.

## Relationship to existing prose

Existing chapters establish written facts. If a new arc conflicts with them, decide the revision scope first, then use revision and impact checks for later plans and states.

This tool supports planning character-driven events; it cannot guarantee psychologically convincing changes. The author must judge whether actions arise from the character and whether turns have sufficient setup.
