# Text open world

> The current interface explicitly says this is still under development and not a formal feature.

For regional exploration, character schedules, resources, factions, and ongoing quests. Dedicated production/runtime foundations exist; regional autonomy, long-term quest evolution, and performance have not completed acceptance.

## Identifying the current entries

Text open world includes page previews and Development experience (开发体验). The development experience requires a workspace; production also needs explicit authorization for the current project and valid sources.

These entries help explore mechanics in development. They are not a fully delivered open-world game editor.

## What to inspect

Foundations include regions, travel paths, quests, and resource changes. During a trial, check an action's prerequisites, cost, result, and save against expectations. Long-term changes belong to the product's runtime and do not write back to the shared world.

Back up important works first. If you cannot continue, record the app version, entry, and steps in a [bug report](/en/feedback/bug).
