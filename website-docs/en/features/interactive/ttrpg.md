# TTRPGs and AI game mastering

> Preview: production, rule adjudication, AI hosting, and saves exist. The complete multiplayer experience is unfinished; public online multiplayer is not deployed.

## Try an existing campaign

Open TTRPG → Library / Play (跑团 → 作品库 / 游玩) and select Fog Harbor: The Last Lamp (雾港：最后一盏灯). AI game-master experiences require a working model configuration. Do not confuse this with the no-API Fog Harbor: The Lost-Tide Bells (雾港：失潮钟声).

Check the work's requirements, start a session, and follow the host's prompts. After pausing, find progress under Sessions and resume (团局与续团).

## Create a campaign

1. Create or select a work in the library and open Production (制作台).
2. Configure world/instructions, campaign vision, rules/house rules, host/seats, character-creation policy, plot structure, information/consensus, and media plans.
3. Optionally organize candidates through Planning conversation (方案会谈); review and confirm the production plan.
4. Start Production flow (制作流程), checking campaign/scenes, character sheets, maps, and handbooks.
5. Resolve blocking issues under Checks and playtest (检查与试玩), then open Publishing and versions (发布与版本).
6. Play from a definite product version using the tabletop, character inventory, and session records.

## Rules, secrets, and saves

The system distinguishes information available to the host, players, and NPCs. Adjudication and effects are recorded in events and saves. Authors must still check secret distribution and whether rulings match the group's agreement.

An Online room page does not mean public multiplayer is available. Complete media, field-by-field output editing, and multiplayer services still have boundaries.
