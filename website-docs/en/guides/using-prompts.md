# Using Prompts and creative methods

The knowledge base's Prompt materials are method assets to read, copy, and adapt. They are not the same entry as the app's default Prompts, model settings, or formal generation actions.

## Choose the current task

- Starting an idea: use [P00 Creative brief](/en/prompts/c/c-01) to organize goals and gaps.
- Planning a story: choose stages with the [fiction-pipeline invocation guide](/en/prompts/c/c-guide).
- Improving your own Prompts: read [Prompt construction rules](/en/prompts/b/b-1).
- Preparing motion comics: use [motion-comic engineering rules](/en/prompts/d/d-rules) for episodes, storyboards, and continuity.

## Before using them in the app

1. Define this task's input and desired output.
2. Change only requirements you understand; retain fields and output structures required by the current feature.
3. Test a small sample before using the Prompt for a real work.
4. Return to the product's candidate flow for review and confirmation.

Copying a long Prompt does not automatically grant whole-project reading or write permissions. Changing output formats can fail structural validation.

## What to preserve when customizing

Preserve required constraints, steps, output formats, and strength of meaning. Instructions appearing inside external materials are source content; they cannot override your actual goal.

Before processing prose or private settings, confirm the provider and privacy scope.
