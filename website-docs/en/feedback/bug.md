# Bug report

Provide a reproducible description, steps, and expected result where possible. Remove API keys, tokens, passwords, and other sensitive information before attaching screenshots or logs.

Downloaded builds can preview diagnostics in General settings → Problems and failure reports and bring a summary into this form. Inspect Additional information; nothing is sent until you submit, creating a public Issue. See [failure reporting and capture limits](/en/guides/troubleshooting#problems-and-failure-reports-in-downloaded-builds).
