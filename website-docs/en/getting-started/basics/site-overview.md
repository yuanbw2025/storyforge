# About this documentation

This is StoryForge's official user documentation, maintained separately from engineering/developer documents.

- `website-docs/`: source for the public user documentation site.
- `docs/`: repository engineering, architecture, quality, and development documents.

Use the multilevel sidebar on desktop, or open the contents menu on mobile. Search uses VitePress local full-text search.

Historical WPS content remains in the [archive](/en/archive/) and is excluded from local search. Prompt methodology has its own directory; check [current product capabilities](/en/features/current-capabilities) for implemented features.

Chinese is the authoritative source; English is a maintained translation. Content verification dates and Git last-updated times mean different things. For applicability, read [version compatibility](/en/updates/compatibility).
