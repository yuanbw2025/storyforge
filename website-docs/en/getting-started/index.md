# Getting started

For your first small project:

1. [What is StoryForge?](/en/getting-started/what-is-storyforge): local-first storage, author confirmation, and separate products.
2. [Choose a product](/en/getting-started/choose-product): start with the output you want.
3. [Install and launch](/en/getting-started/install): open the app.
4. [Quick start](/en/getting-started/quick-start): complete a first manual writing cycle.
5. [Models and APIs](/en/getting-started/model-config): connect your provider when you need generation.
6. [Backup and recovery](/en/guides/backup-restore): keep an independent copy.

Already familiar with the project? Go to [product guides](/en/features/) or the [latest changes](/en/updates/changelog).

These documents describe the current main branch. Tagged releases and live deployments may differ; check [capabilities and versions](/en/features/current-capabilities).
