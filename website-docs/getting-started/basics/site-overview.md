# 文档站说明

本站是 StoryForge 面向用户的官方文档中心，与仓库中的工程/开发文档分开维护。

- `website-docs/`：面向用户公开的文档站源文件。
- `docs/`：仓库内的工程、架构、质量与开发文档。

桌面端可使用左侧多级目录；移动端从顶部菜单打开目录。顶部搜索使用 VitePress 本地全文搜索。

历史 WPS 内容保留在[历史归档](/archive/)，不参与本地全文搜索。Prompt 方法资料保留独立目录，实际软件能力请核对[当前产品状态](/features/current-capabilities)。

中文为当前维护的完整知识库，English 入口仍为预留说明页。页面内容核对日期与 Git 的最后更新时间含义不同；功能适用范围请阅读[版本说明](/updates/compatibility)。
