# 根据目标选择产品

> 适用于当前 main；核对日期：2026-09-20。固定 Release 可能没有这些入口。

先决定这次要交付什么，再选择产品。写小说可以直接开始，不需要先完成世界引擎。

## 三个容易混淆的选择

**长篇与短篇**拥有各自的创作流程。短篇围绕整篇结构和篇幅收束；长篇强调卷章规划与持续创作。不要把短篇当作长篇工作台里的一个开关。

**漫画与漫剧素材**面向不同交付物。漫画管理纸面或屏幕上的页格、阅读顺序和排字；漫剧素材面向视频前期，准备分镜与外部工具输入，不在 StoryForge 内完成视频剪辑和成片。

**作品与世界**可以独立存在。长篇或短篇可由作者显式派生世界；原作修改不会自动同步到派生世界。剧本、漫画和漫剧素材不提供“封装为世界”的通路。

## 第一次使用的建议

先用一个小目标完成闭环：写一章、改编一个片段，或封存一个小世界。确认保存和导出都符合需要，再扩大篇幅。
