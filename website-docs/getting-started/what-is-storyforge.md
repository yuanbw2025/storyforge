# StoryForge 是什么

StoryForge（故事熔炉）是开源、本地优先的叙事创作与体验工具。你可以写小说、改编剧本或漫画、准备漫剧材料、建立可复用的世界，也可以试用基于世界的互动产品。

## 从你的作品开始

长篇、短篇、剧本、漫画和漫剧素材有各自的工作台与交付物。写小说不需要先完成世界引擎，小说改编也不会接管原作。

[选择产品](/getting-started/choose-product)可以帮助你找到入口。

## 作者决定哪些内容成为正式结果

AI 用于生成、分析和审校，输出通常先成为候选。你可以修改、拒绝或确认；模型的文学判断和事实理解仍需核对。

## 本地优先是什么意思

核心作品保存在当前浏览器。你可以导出备份，或使用作者确认的硬盘工作区同步。调用云模型时，任务所需内容会发送给你配置的模型服务。

本地优先不等于自动云备份，也不等于云模型完全离线。

## 当前能用到什么程度

六个产品在当前目录标为已发布：长篇、短篇、剧本、漫画、漫剧素材和世界引擎。节点与互动产品为预览，部分文字游戏界面仍在开发。

请结合[当前能力状态](/features/current-capabilities)选择路径。工程主链完成不等于自动保证文学质量或商业成品。
