# StoryForge 是什么

StoryForge（故事熔炉）是一个开源、本地优先的 AI 叙事创作与体验工具，目标是让创作者不只生成一段文字，而是持续构建、维护并扩展一个故事世界。

当前仓库提供长篇、短篇、剧本、漫画和世界引擎等正式入口；节点工作流与部分互动产品处于预览或持续开发阶段。项目也提供内置示例作品，便于在不接入模型 API 的情况下体验部分叙事形态。

## 核心原则

- **本地优先**：作品与大量创作状态保存在用户本地环境；部分能力可以投影到用户选择的本地项目目录。
- **作者确认**：AI 输出先形成候选，作者可以查看、编辑、拒绝或确认，不把模型输出直接等同于正式设定。
- **自备模型服务**：用户自行配置第三方模型/API；StoryForge 本身不提供模型账号、API Key 或模型额度。
- **长程一致性**：围绕人物、事实、伏笔、状态、物品、时间线与来源证据建立可追踪的创作状态。
- **多产品复用**：同一套世界与叙事基座可以服务小说、改编、互动体验等不同产品形态。

## 适合谁

- 长篇小说、网文和系列故事作者
- 短篇、剧本、漫画等叙事内容创作者
- 希望把世界设定复用于不同作品的人
- 需要可追踪 Prompt、上下文、记忆与 AI 运行证据的创作者
- 希望研究 AI 叙事生产流程、Prompt 工程和互动叙事的人
