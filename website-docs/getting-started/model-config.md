# 模型与 API 配置

StoryForge 的 AI 功能使用用户自己配置的第三方模型服务。

## 基本步骤

1. 在 StoryForge 中打开“模型与本地设置”，或从对应创作工作区进入设置。
2. 选择服务商，填写你自己的 API Key、Base URL 与模型名称。
3. 使用连接测试检查配置。
4. 再用一次小规模生成验证实际可用性。

连接测试成功只说明基础接口可访问，不代表账户余额、模型权限、上下文长度或输出上限一定满足所有任务。

## 本地与自定义服务

对于 Ollama、LM Studio 或其它 OpenAI-compatible 服务，可使用自定义 Base URL。部分本地服务可以不需要 API Key；云端服务是否需要认证以服务商规则为准。

## 跨域与代理

部分模型服务不允许浏览器直接跨域访问。遇到 CORS/跨域错误时，应按 StoryForge 设置页提供的本地代理方式处理，而不是把 API Key 提交到公开 Issue、作品内容或截图中。

::: danger 安全提醒
提交 Bug、截图或日志前，请检查并移除 API Key、Token、密码、个人访问令牌等敏感信息。
:::
