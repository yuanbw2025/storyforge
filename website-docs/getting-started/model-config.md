# 模型与 API 配置

AI 生成需要你自己的模型服务。手工创作与免 API 的内置作品可以先使用。

## 第一次配置

1. 打开首页右上角“模型与本地设置”，或产品里的“通用设置”。
2. 选择服务商。API 服务填写账户实际支持的 API Key、Base URL 和模型名称；本机 Codex 按下方订阅连接步骤操作。
3. 检查模型上下文与输出设置，避免直接沿用其他模型的参数。
4. 使用连接测试，然后执行一次小规模生成。
5. 查看实际模型、输出和用量，再用于正式长任务。

连接测试成功只证明本次检测通过，不代表所有任务都可用。账户余额、权限、模型格式和输出上限仍可能造成失败。

## Codex 本机 ChatGPT 登录

此功能随 Codex 提供商开发分支交付；合并和部署状态见[开发记录](/updates/development-status)。它是本机文本生成连接，不能在纯静态线上版直接使用。

1. 安装支持当前隔离协议的 Codex CLI（最低 0.162.0，当前实测 0.162.0-alpha.2），在本机使用 ChatGPT 账号登录。若已登录，通常无需再次登录；仅用 Codex 打开项目不能替代连接检测。
2. 在 StoryForge 项目目录运行 `npm run dev`；也支持 `npm run build` 后执行 `npm run preview`。服务须能在 PATH 找到 `codex`；找不到时安装 CLI，或设置 `STORYFORGE_CODEX_BIN` 为可执行文件路径。
3. 在设置中选择 **Codex（本机 ChatGPT 登录）**，等待显示实际登录状态。无需填写 API Key 或 Base URL。
4. 选择本机目录中的模型，点击“测试最小连接”。测试消耗少量套餐额度。可保存预设，再分配到创作、提取等任务。
5. 只有没有检测到登录时，才使用面板的“使用 ChatGPT 登录”→“打开 OpenAI 官方登录页”，或在本机终端执行 `codex login`；完成后点击“检测连接”。登录可能改变本机 Codex 当前账号。

登录由 Codex 管理，StoryForge 不保存登录 token。API Key 登录模式会被拒绝，额度不足或连接失败不会自动切到其他付费 API。“停止连接”不会退出 Codex 账号，下次检测或生成时可重新连接。

订阅有额度与模型权限限制，不等于免费或无限。这里只接文本和结构化输出，暂不支持带 API 金额统计的模型评测；图片、语音、向量嵌入需独立配置。温度和 API 输出 token 上限不适用于该通道；本地上下文预算仍生效。长任务、批量生产和文学质量需另外验证，金额预算要求也不会因订阅而自动取消。

刷新或断线后，先查看面板“最近请求”。本机服务保留至多 24 小时、100 条请求状态和返回文本（不保存输入提示词和登录凭据）；复制的内容仍需审查、走原流程采纳。服务重启会将未完成请求标为“结果未知”，不会自动重发。恢复记录不属于作品备份。

请保持原来的浏览器地址与端口，不要把换地址误认为数据迁移。不同 origin 的 IndexedDB 手稿互不共享，切换前先按[备份指南](/guides/backup-restore)保护作品。本功能限本机个人/开源应用连接，不作为托管商业 API 或共享订阅池；依据 [OpenAI app-server 文档](https://learn.chatgpt.com/docs/app-server)。

## 本地与自定义服务

本地模型或自定义 OpenAI 兼容服务需要正在运行的服务地址与可用模型。使用设置页提供的模型列表读取能力，失败时按实际服务信息填写模型名称。

无鉴权本地服务与云服务的 Key 要求不同。不要把云模型的认证错误当作“软件不支持”，也不要把本地地址暴露给无关访问者。

## 任务模型与媒资模型

创作、提取、分析、审查等任务可以按当前设置页提供的路由配置。检查实际任务使用的模型，不要只看全局默认值。

文字配置不自动配置图片、声音或外部视频工具。漫画与漫剧相关服务能力请看对应[产品指南](/features/)。

## 跨域与代理

浏览器可能限制直接访问第三方 API。本地通过 `npm run dev` 运行时，支持的服务商可在设置页切换到开发服务器提供的本地代理；线上部署不自带这些代理，不显示该切换按钮。

线上版的语义检索预设使用服务商直连地址，仍需服务商允许浏览器跨域访问。若部署者提供了同源反向代理，请手动填写它的 Base URL。已有代理地址会保留，也可以显式切回直连；打开设置不会自动改写已保存的配置。

不要把 API Key 放进作品简介、提示词或公开反馈。具体账单以模型服务商为准。
