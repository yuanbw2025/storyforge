# 五分钟上手

本页帮助你完成第一轮手工创作。AI 生成所需时间和费用由模型服务决定。

## 1. 打开应用

使用 [安装与启动](/getting-started/install) 中的在线地址或本地源码方式。文档站只提供说明；作品在 StoryForge 应用中创建。

第一次可以先打开“首页 → 示例作品”，通过[内置示例](/guides/examples)了解成品。

## 2. 新建一部长篇

进入“长篇 → 作品库 → 新建长篇”，输入名称。只写小说不需要先建立独立世界。

![长篇作品库与新建长篇入口](/assets/current/longform-create-current.png)

在长篇工作台填写本轮需要的故事核心：主角想做什么、阻力是什么、失败会失去什么。资料可以逐步补充，不必先填满所有世界设定。

## 3. 准备第一章

在“人物与关系”整理主角，在“大纲与章纲”建立第一章，再用“场景细纲”安排行动、冲突与转折。你可以全部手写。

需要 AI 时，先完成[模型与 API 配置](/getting-started/model-config)。从小范围生成开始，检查候选再确认；确认前的生成结果不等于已保存为正式作品。

## 4. 写作与核对

进入“正文 → 章节与正文”。写作或采纳后检查实际正文，核对人物、地点和前后因果。需要时整理章后事实、伏笔与状态变化，为下一章建立依据。

看到“候选过期”时，先保留自己的编辑，按提示重新核对当前版本；不要反复点击采纳。

## 5. 保存第一份备份

进入“版本与导出”中的数据备份入口，下载完整 JSON；正文可另外导出 Markdown / TXT。确认下载的文件存在，再关闭页面。

浏览器自动保存与硬盘备份不同。换浏览器、换设备或从在线版切换到本地版之前，请先阅读[备份与恢复](/guides/backup-restore)。
