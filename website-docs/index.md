StoryForge 是开源、本地优先的叙事创作与体验工具。你可以写小说、改编剧本与漫画、准备漫剧材料，或建立世界并试用互动产品。

> 本轮指南核对至 2026-09-20 的 main 基线。固定 Release 与在线部署可能不同，先看[当前能力状态](/features/current-capabilities)和[版本说明](/updates/compatibility)。

## 第一次使用

1. [根据目标选择产品](/getting-started/choose-product)，找到适合自己的工作台。
2. [打开应用](/getting-started/install)，按[五分钟上手](/getting-started/quick-start)完成一轮小创作。
3. 需要 AI 时[配置模型](/getting-started/model-config)，确认候选并保留[第一份备份](/guides/backup-restore)。

只写小说不需要先建立世界引擎；可以先手工创作，或[体验免 API 的内置作品](/guides/examples)。
