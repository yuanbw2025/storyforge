# StoryForge 简介

StoryForge（故事熔炉）是一个开源、本地优先的 AI 叙事创作与体验工具，帮助创作者持续构建、维护并扩展故事世界，而不只是生成一段孤立文字。

当前仓库包含长篇、短篇、剧本、漫画、世界引擎和多种互动体验入口。不同产品的成熟度、模型依赖和使用边界各不相同，具体以对应页面和当前版本为准。

## 推荐阅读顺序

1. 先读[StoryForge 是什么](/getting-started/what-is-storyforge)，了解产品边界与核心原则。
2. 按[安装与启动](/getting-started/install)运行本地项目。
3. 根据[模型与 API 配置](/getting-started/model-config)接入你自己的模型服务。
4. 浏览[当前产品能力](/features/current-capabilities)，再进入具体功能和使用指南。
5. 需要创作方法或 Prompt 资产时，进入[Prompt 与创作方法资料库](/prompts/)。

::: info 当前边界
StoryForge 的创作数据以本地存储为主，AI 生成使用用户自己配置的第三方模型服务。StoryForge 不向用户提供模型 API Key、模型账户或平台代理额度。
:::
