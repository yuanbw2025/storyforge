## Unreleased / 主干

### 2026-08-26 · 项目权威、主干与文档体系重建

项目重新明确长篇/节点、短篇/改编、世界引擎和上层产品之间的边界，并重建工程文档、产品契约、能力基线和路线图。

### 2026-08-17 · 可编辑记忆工程与本地项目工作区

长期记忆从浏览器内数据与按需检索扩展为作者、Harness、IndexedDB 与本地硬盘共同维护的创作状态。支持项目目录映像、差异检查、冲突处理、恢复胶囊和作者确认的双向同步。

### 2026-08-17 · Agent + Harness 统一执行架构

核心 AI 流程逐步收进统一的 Agent + Harness：生成先形成候选，作者确认后采纳；运行记录任务合同、上下文、候选、重试与终态证据，并限制无边界重试和费用失控。
