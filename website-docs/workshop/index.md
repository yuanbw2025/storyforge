# 插件与创意工坊

**把你想要的功能，装进自己的熔炉。** 插件可以是一套新的历史年表、一张写作看板、一组内容卡片，也可以是带有界面、数据和 AI 能力的完整工具。不同作品可以使用不同插件。

::: warning 当前为开发预览
本文对应插件 1.0 体验版、API 1、SDK 0.1。功能由 [PR #113](https://github.com/yuanbw2025/storyforge/pull/113) 交付，请确认使用包含该 PR 的应用版本；合并状态与在线部署状态需要分别核对。旧版本没有工坊入口时，不能仅靠这份教程获得新功能。不要把开发预览当作已经公开上线或长期兼容的承诺。
:::

## 现在能做什么

下面是能力示例，不是插件题材的限制。是否可以实现某个需求，取决于所需的公开接口。

| 想达到的效果 | 当前方式 | 参考插件源码目录 |
| --- | --- | --- |
| 独立便笺、人物灵感卡、任务看板 | 自建界面和插件自有记录，挂在作者工作台 | `writing-notes`、`idea-cards` |
| 更自由的年表和故事进程 | 添加或替换世界历史、作品故事进程面板，复用正式历史数据 | `world-timeline`、`story-board` |
| 年表采用另一个插件的历法 | 公开服务加准确版本依赖，多个插件组合 | `calendar`、`world-timeline` |
| 分享设定卡片或一整套写作工具 | 无代码内容包，或锁定依赖的组合包 | `prompt-cards`、`writer-bundle` |
| 自定义 AI 灵感与结构化结果 | 声明任务、上下文和结果格式，由作者开始、编辑、确认 | `idea-cards` |
| 分享可编辑的情节生成流程 | 将声明的流程复制到长篇节点工作台，作者再运行 | `plot-flow` |
| 把插件中的节庆设定用于世界与衍生产品 | 明确预览、确认到世界词条，再沿既有世界封存流程使用 | `world-festivals` |
| 自定义跑团判定规则 | 既有 RulePack 格式，随产品发布冻结 | `harbor-rules` |
| 接入资料查询、外部工具 | 声明网络来源，或使用宿主确认的 MCP 工具连接 | `research-desk`、`tool-desk` |

源码位于仓库 `examples/plugins/`，也随 [AI 开发资料包](./ai) 提供。没有编程能力也可以把上表中的效果描述给自己的 AI。

## 三种包怎么选

- **功能插件**：有代码，可提供交互界面、数据处理、AI 或外部工具入口。
- **内容包**：没有执行入口，交付结构化内容记录；不要期待任意内容包自动变成专属界面或直接写入官方设定。
- **组合包**：没有执行入口，锁定一组插件的版本；依赖需要同时可下载，数据归属必须一致。

## 哪些预期需要调整

插件不是任意改动熔炉源码的补丁。当前专用替换接口是世界历史与故事进程；其他产品提供通用作者工作台，不代表所有编辑器、按钮、生成算法和游戏运行逻辑都可以替换。新接口可通过[功能建议](/feedback/feature)提出。

普通插件运行不要求安装 Node 或 Python。开发插件需要开发环境；调用本机程序的插件可能需要单独启动桥接服务。AI 与外部服务可能产生费用，安装插件本身不会自动开始模型调用。

原生界面插件与熔炉同源运行，应信任其作者和代码来源。能力声明有助于理解用途，但不是恶意代码沙箱。停用、卸载保留插件数据；缺少插件时可以查看原始记录，但专属交互需要重新安装对应版本。
