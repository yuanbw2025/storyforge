# 安装与使用插件

适用范围：插件 1.0 开发预览。先确认自己运行的是包含工坊的版本，状态见[工坊首页](./)。建议第一次使用独立测试作品，并先导出重要作品的[完整备份](/guides/backup-restore)。

## 打开工坊并体验

1. 在当前熔炉地址的应用路径后打开 `workshop`。例如本地应用是 `http://localhost:5173/storyforge/`，工坊就是 `http://localhost:5173/storyforge/workshop`。保留你的域名、端口和应用路径，不要照抄别人的地址。
2. 点击 **开启工坊开发预览**。以后可以从首页进入工坊。
3. 在 **发现插件** 中选择 **创建体验作品** 或 **创建体验世界**，阅读确认后创建。它会新建独立测试内容并安装参考插件，不调用 AI。
4. 作品可试“创作便笺”，世界可试“世界历史工作台”。保存一条内容，刷新后检查仍在，再试停用插件。

**预期结果**：便笺随当前作品保存；历史工作台显示时间线，历法服务为它提供日期格式。停用历史插件后，已经写入正式历史的内容仍可在官方面板查看。

## 安装一个插件

### 从目录下载

1. 在 **发现插件** 搜索名称，阅读作者、用途、归属与依赖。
2. 点击 **下载并安装**；目录中的准确版本依赖会一起下载。此时尚未启用代码。
3. 进入 **已安装**，在上方选择工作区及 **当前作品** 或 **当前世界**，与插件归属一致。
4. 点击 **启用**，阅读信任提示，再点击 **信任并启用**。
5. 打开 **插件工作台**，或进入它替换的 **世界历史／故事进程** 页面。

### 从别人发来的文件安装

下载作者提供的 `.sfplugin` 原始文件，在工坊点击 **从文件安装**。不要解压后拖入，也不要把源码 ZIP 或开发资料包当作插件包。若有依赖，先取得并安装作者列出的准确版本，再按上面的步骤启用。

### 添加社区目录

在 **发现插件** 的社区目录地址框填入作者提供的 HTTPS JSON 地址，点击 **读取目录**。这是目录文件地址，不是项目首页、GitHub 文件展示页或下载网页。目录读取不代表已安装，更不代表已经信任启用。

## 更新与停用

- **停用**：在“已安装”中停用当前作品／世界的插件。它不会删除记录，也不会自动影响其他作品。
- **升级**：先备份，停用依赖它的插件，再停用它；安装新包后点击 **切换到此版本**。迁移成功后再按依赖顺序启用。不要覆盖作者发布过的同版本文件。
- **卸载**：移除浏览器中的安装包，保留创作数据。如果包在其他作品仍启用，先在相应作用域停用，再重试卸载。
- **恢复**：通过“数据恢复与操作记录”查看旧数据代；需要旧包时安装对应版本。恢复会保留恢复前的较新编辑，细节见[故障与恢复](./troubleshooting)。

## 保存和换设备

插件包保存在当前浏览器地址对应的本地数据库，作品／世界保存各自的启用配置和记录。换浏览器、端口或网站地址不会自动迁移。

完整作品备份保存插件数据与版本契约，**不携带可执行插件包**。换设备时保留备份与原始安装包；导入后插件默认停用，重新安装匹配版本并确认信任。历史 AI 候选和工具结果只读保留，不会自动继续旧外部任务。

## 使用 AI 或外部工具

普通便笺、年表不要求配置模型。AI 插件需要你配置模型，在宿主面板明确开始，检查和编辑候选后确认保存；未确认的候选不等于正式内容。费用取决于模型服务。

MCP 工具会显示目标、参数和确认界面；外部服务可能需要单独启动或认证。宿主令牌不要写进插件清单或备份。声明为网络查询的功能会把请求发送到相应网站，应先读作者说明。出错时不要连续盲点重试，见[排查步骤](./troubleshooting)。
