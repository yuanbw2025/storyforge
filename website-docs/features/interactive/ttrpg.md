# 跑团与 AI KP

> 预览：已有制作、规则判定、AI 主持与存档路径，完整多人体验尚未封板，公共联网多人未部署。

## 先体验已有战役

进入“跑团 → 作品库 / 游玩”，选择内置作品《雾港：最后一盏灯》。AI KP 相关体验需要可用模型配置；不要与免 API 的《雾港：失潮钟声》混淆。

先查看作品要求，开始团局后跟随主持提示行动。暂停后从“团局与续团”查看已有进度。

## 制作自己的战役

1. 在作品库创建或选择作品，进入“制作台”。
2. 配置世界与指令、战役愿景、规则与村规、主持与席位、车卡策略、剧情结构、信息与共识及媒资方案。
3. 可通过“方案会谈”整理候选，核对后确认制作方案。
4. 在“制作流程”开始生产，检查战役与场景、角色卡、地图与手册。
5. 在“检查与试玩”处理阻断问题，进入“发布与版本”。
6. 从确定的产品版本进入“游玩”，使用跑团桌面、角色物品和团局记录。

## 开放跑团试用与旁白

在开发预览的作品库勾选“启用开放跑团试用（实验性）”，再选择“新建开放跑团（预览）”。试用偏好只保存在当前浏览器；旧有剧本式作品与存档保留。

1. 在制作台核对冻结世界、目标、规则与预算，利用作者设计和方案会谈整理需求。保存草稿不会开始生成；检查方案后明确开始制作。
2. 审阅战役内容、角色与局势候选，再冻结发布并开始团局。共同事实、线索分享、Oracle 与行动后果按各自的授权和确认入口处理；主持、队友与玩家可知范围仍分开。
3. 中断后先检查团局记录与待确认结果，从原运行的恢复入口继续。未知调用结果不连续重发，也不通过修改存档绕过结算。
4. 开局的“旁白试听与选择”可先试听声线、调整语速；新生成旁白使用所选声线，已有音频保留原声音，播放语速可另外调整。生成的音轨仍需审听和确认，播放不等于采用。

本机 Qwen 合成需要已配置运行库的 Apple 芯片 Mac，不能据此假定所有设备都有本地生成能力。30+ 有效轮次、独立真人完整游玩和听感仍待验收；公共联网多人不因本次工程整合而开放。依据：[PR #196](https://github.com/yuanbw2025/storyforge/pull/196)。

## 规则、秘密与存档

系统区分主持、玩家和 NPC 可知的信息，规则判定和效果会记录到事件与存档。作者仍需要审看秘密是否分配正确、判定是否符合本团约定。

“在线房间”页面存在不代表公共多人服务可用。当前完整媒资、逐字段产物编辑和多人服务仍有边界。
