# 文字开放世界

> 当前界面明确标注“尚在开发完善中，目前非正式功能”。

面向地区探索、角色日程、资源、势力与持续任务。当前具备专用生产和运行基础，区域自治、长期任务演化及性能仍未完整验收。

## 如何识别当前入口

“文字开放世界”下包含页面预览与“开发体验”。开发体验需要选择工作区，制作能力还需当前项目的明确授权和有效来源。

这些入口适合了解开发中的机制，不能作为已经完整交付的开放世界游戏编辑器使用。

## 可以关注什么

已有地区与旅行路径、任务和资源变化等基础。试用时关注一次行动的前置条件、消耗、结果和存档是否符合预期。长期变化只属于该产品自己的运行，不会回写共享世界。
