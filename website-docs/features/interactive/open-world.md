# 文字开放世界

> 当前为预览。已贯通专属制作流程、玩家界面和运行时 AI；通用生产仍需真实模型校准和真人双结局验收。

文字开放世界围绕地区探索、人物日程、任务、战斗、物品与持续变化展开。它可读取冻结世界版本，也可使用作者明确选择的小说范围；产品素材和游玩结果归产品自身所有，不自动回写世界或原作。

## 先试玩《盐脊：断流之夜》

进入“文字开放世界”，点击“先试玩《盐脊：断流之夜》”。不需要选择工作区或配置模型；首次开始会建立独立发布与存档。可体验探索、人物互动、任务和结局，继续游戏时读取自己的进度。

这是预先准备的展示作品，不证明任何输入都能自动生成同样完整的游戏。参见[内置作品与示例](/guides/examples)。

## 三款 3D 叙事游戏

在“文字开放世界”的玩家页面找到“内置叙事游戏”，无需先建工作区、配置 API 或安装外部游戏引擎。三款游戏不在首页展示。

- **《潮痕：两声之间》**：约 4–5 分钟的独立短篇；调查水线、取工具、按顺序开闸，亲手执行两条救援路线。
- **《潮痕：最后一盏灯》**：十章海边奇幻，三万汉字以上主线、五百句以上独立对白、四种结局。
- **《远日点：第七码头》**：十章深空科幻，三万汉字以上主线、五百句以上独立对白，包含设备谜题、支路和四种结局。

建议先玩《两声之间》。桌面支持 WASD/方向键、点击移动和 E 就近交互；手机可点按界面按钮，设置提供文字探索、轻量画面和阅读方式。首次明确开始才准备独立游戏内容；刷新后可继续，另开旅程和检查点分支保留原存档。使用完整项目备份迁移进度，浏览器数据不会自动跨设备同步。

主线使用随仓库提供的冻结剧情，无自由输入模型对话或角色配音。长篇仅有可选程序化环境声，短篇暂无声音。这些作品不代表通用文字开放世界生成能力已完成。请下载包含本次更新的 `main` 或后续 Release；旧版本压缩包不会自动获得新内容。

## 制作自己的作品

1. 进入“文字开放世界 → 制作”，选择工作区及世界版本或小说来源范围。
2. 检查来源预览与缺口，再继续到主 Agent 会谈；选择来源本身不会启动生产或计费。
3. 确认作品目标、玩法、规模、预算与制作简报，处理必需输入和模型配置问题。
4. 明确授权开始制作，查看进度和待确认产物；中断时根据当前任务的恢复提示继续。
5. 检查故事、主角、地图、任务、玩法和素材。需要改动时编辑或修复相应产物，再重新检查受影响部分。
6. 完成质量检查与试玩证据，确认可发布后冻结产品版本。制作预览与正式游戏库分开。

生产可能调用你的模型和图片服务。预算、失败和质量门不是可以通过修改数据绕过的步骤。

## 验收自己的制作版本

先为实际制作的作品保存[完整备份](/guides/backup-restore)，记下当前制作版本、已发布版本和要复测的存档。展示作品的游玩进度不能替代自己制作版本的验收记录。

1. 在 AI 设置中，为“审查校验”选择独立预设。供应商与模型的组合必须区别于生产生成器；只更换密钥不算独立模型。在制作工作台的“独立模型与数据校准”核对两者身份，明确承担本次调用费用后点击“运行一次独立校准并冻结回执”。查看评分、重复度、时长库存、调用量和费用；冻结价格估算与服务商实付金额分别记录。
2. 校准通过后，由作者本人完成当前制作版本的两至六条路线，至少到达两个不同结局，并覆盖行动、探索、战斗、成长和恢复。至少实际使用一次自由输入并取得运行时 AI 响应。在“真人双结局完整试玩”选择对应存档，填写不含挂机的操作时长、十项评分与观察说明、费用和等待情况，再确认四项真人声明并冻结回执。无法取得服务商费用时，选择“服务商未提供可归因费用”。
3. 更新验收从已发布版本中实际发现的问题开始：登记问题，保存需要修复的完整试玩回执，再从局部修复入口创建后继制作版本。复验受影响产物和发布条件后，明确发布该源版本的直接后继版本；原发布版与存档保留。
4. 在修复后的发布版重新完成双结局试玩，逐项复测原问题与低分项。打开“修复版真人更新验证”，填写复测说明并关联实际完成的路线；实际打开旧存档，验证它继续运行旧发布版，或在系统判定兼容时验证显式创建的迁移子存档。完成四项更新声明后冻结更新回执。

回执保存在作品中，并随完整备份保留。图片还需按当前版本的逐图审查要求确认。校准未通过、存在未解决问题，或尚未发生真实修复与旧档复测时，相应验收仍保持待完成；作者评价和确认由实际试玩者填写。

## 玩家操作与存档

“玩家”界面提供场景、地图、任务、角色、背包、战斗、制作交易、世界记录及存档设置。先查看行动条件、代价与结果；不可用的操作应按提示处理。

新游戏和每条旧存档分别绑定不可变发布版本。旧存档不会随新版本静默升级；只有通过兼容检查的升级路径才能迁移。恢复、分支或删除时间线之前先确认目标，删除一条时间线不会删除其它存档或其冻结发布。

运行时 AI 可辅助理解意图、角色对话与结果表达，仍受玩法状态和权限约束。服务异常时查看错误和恢复入口，不要连续重发结果未知的行动。

## 产品化分支预览（未合并、未部署）

`feat/text-open-world-productization-20261013` 分支增加以下变化，实际可用性以所运行版本为准，不代表发布了新正式版本。交付见[开发记录](/updates/development-status)。

- 制作工作台按**游戏内容、产品系统配置、媒资生产**显示进度。展开可查看缺少的产物、依赖、阻塞、调用费用与原返修入口。三条线共同完成一个游戏，并保留底层执行 lane。
- 新 Build 在组装时冻结三线输入 Hash。返修创建子 Build，只重跑受影响的依赖；历史 Build、Release 和旧存档继续绑定原版本。本分支产生的新格式记录需用包含本次更新的程序打开，旧程序可能拒绝读取。
- 图片需逐张打开、接受或退回，并由作者明确确认亲自查看。角色分组只使用已声明身份，自动检查不判断视觉相似度；退回后进入媒资返修。新版含图片 Build 需要这份回执才能通过最终发布质量门。原有图片生成/导入和已声明静音降级继续可用。
- 玩家在“更多”中点击“读取本地体验记录”，查看任务、战斗、旅行、自由输入与重复内容统计。主线耗时是首末推进记录的时间跨度，包含停留和离线时间；同来源/同指纹次数不等于语义相似度，无法核验的 AI 记录另列数量。
- 选择问题分类，填写不含原文与私人信息的描述，主动导出反馈文件到本机。未导出的表单不保存，不上传或自动发送给作者；反馈与统计不会生成真人试玩回执。

本次开发环境未取得历史盐脊浏览器证据。工程检查、模拟供应商通过，均不能替代真实独立模型校准、真人双结局、实际图片质量确认和后继发布版旧档复测。

## 当前限制

产品目录仍为预览。已有工程检查、自动游玩和展示作品不能替代真实服务校准、长期游玩和独立真人验收。重要创作请先[备份](/guides/backup-restore)。
