# 后日谈 AI 小镇

> 预览：已有日程、居民关系、事件、检查点与回放链路。真实模型的长期表现、媒资质量与成本仍需专项验证。

适合探索原作结局之后角色怎样继续生活。入口：“AI 小镇 → 作品库”。

## 制作一座小镇

1. 在“结局与生活”明确故事从哪个结局继续、生活目标是什么。
2. 在“居民与地点”“日程与生活规则”设置居民、地点和日常安排。
3. 核对世界来源与视听方案，通过“方案会谈”确认候选。
4. 确认制作方案，在“制作流程”生产并检查居民档案、日程与事件、小镇与设施。
5. 完成“检查与试玩”，保存发布版本。
6. 从“游玩 → 进入小镇”开始，查看“邻里与变化”和“小镇档案”。

## 观察哪些变化

居民按时段与地点规则行动，拥有各自知识、对话记忆与关系。轻经营、时间推进、事件回放和检查点帮助追踪变化；重要变化需要按界面确认。

离线时间补算不表示服务器一直运行着你的世界，也不等于在线多人社区。

## 试用建议

先用少量居民和清晰日程验证一次生活循环，查看用量和角色表现后再延长运行。运行与图片、声音可能有不同配置和费用，不要把示例素材效果当作所有服务商的保证。
