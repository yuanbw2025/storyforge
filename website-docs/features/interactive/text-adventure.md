# 文字冒险

> 当前为预览。专业生产、素材审查、发布与确定性运行已有实现；真实模型内容质量、真人试玩和首个社区推荐成品仍需专项验收。

文字冒险围绕行动选择、背包资源、能力状态、任务与结局展开。作品引用冻结世界版本，自己保存制作产物、图片、发布版本和游玩进度。

## 选择体验或制作

想直接体验，可从“首页 → 示例作品”打开[《雾港：失潮钟声》](/guides/examples)，不需要模型 API。

制作入口为“文字冒险”，包含“作品与试玩”“产品定向”“自动制作”“质量与素材”“发布与导出”“开始冒险”。先选择正确工作区和作品；正式制作需要明确授权及有效世界来源。旧版仅提供开发体验入口时，先核对[版本](/updates/compatibility)。

## 从来源到可玩版本

1. 在产品定向中选择世界版本，说明目标体验、剧情范围、规模与预算。
2. 检查来源是否足够；遇到缺口先补充资料或按允许方式明确决策，再开始制作。
3. 在自动制作中检查故事与人物规划、任务、场景、对白等产物，处理待确认事项。
4. 在质量与素材中审查视觉方向、角色和场景图片；作者确认视觉要求及图片，独立审查通过后才可纳入交付。
5. 检查任务路线、决策后果和结局，完成自动游玩与实际试玩。修复时优先处理失败项和受影响依赖，预算耗尽后按提示补充授权。
6. 在发布与导出中检查冻结版本与产品包，再从对应版本开始冒险。导入产品包后核对来源、素材与新存档；它与整个项目的 JSON 备份用途不同。

## 工作区、作品库与存档导航

通过顶部“文字冒险”页签往返作品库、制作台和游玩时，当前工作区会保留并重新校验。无效或不属于当前作品的 Work 不会加载播放器；若目标不存在，回作品库重新选择，不用清除浏览器数据。

在同一作品中切换存档或创建分支后，路由跟随实际选中的存档，玩家面板保留。快速切换或退出页面后，旧的异步读取不会覆盖新列表。局部读取失败时，使用错误区域的恢复入口，并核对作品与存档名称后再继续。此修复不等于已经确认偶发整窗退出的根因。依据：[PR #208](https://github.com/yuanbw2025/storyforge/pull/208)。

## 游玩与恢复

任务完成和奖励遵守冻结规则的显式结算；分支只延续自己的已提交行动和正文，行动提示不得把未完成的结局写成已经完成。存档面板显示经核验的作品版本，不会因刷新或继续游玩静默切换版本。

任务日志按类别展示目标；背包、装备、技能点及行动提示帮助判断下一步。选择受前置条件和资源约束，结局由真实过程决定，不能只凭生成文本判定已经完成目标。

游玩进度与冻结版本绑定。刷新或恢复时检查当前版本和存档；出现损坏提示时使用支持的恢复路径，不要手工修改冻结数据。制作失败或暂停也应先查看本次运行与已保留产物，避免直接重做整个作品。

任务修订输入已增加首次进度加载保护，避免作者正在输入的修订稿被后台首次加载清空。切换制作任务或运行控制版本变化仍会重置相关输入；未提交草稿不保证刷新后保留，详见[候选与恢复输入](/guides/ai-workflow)。

## 作品库、试玩与局部修订

“作品与试玩”现在按作品展示封面；进入详情后选择开始、继续或存档，同名历史版本集中在详情中。未正式发布但具备有效来源的 Build 会明确标为“未发布试玩”，不能当作已经签发的产品发布。开始前若所选 Build 已变化，应刷新作品库后重新确认。

阅读时可使用沉浸模式、字体、对比度和减少动态效果设置；开始、继续、分支及刷新恢复对应自己的存档。场景中的人物依据冻结出场表显示，受限选择会说明缺少的目标、物品或资源，已完成动作也有明确反馈。

制作中可对已确认故事、人物、场景计划、正文、对白及路线做受版本约束的局部修订；核对影响后只重跑需要更新的依赖。暂停恢复、上传替换图片及视觉审查仍走原制作流程，保留旧 Build 与存档。更改时间容量时只允许提高上限，不能缩减旧版本的可用时间。

以上能力随 [PR #100](https://github.com/yuanbw2025/storyforge/pull/100) 于 2026-10-04 合入主干。《潮钟群岛：最后的灯火》仍是本地未发布试玩：工程代码合并不等于该作品已签发正式发布或可从新安装中直接获得；作者本地图片和浏览器存档也不会随 Git 同步。其它待处理分支见[待合并开发记录](/updates/development-status)。

## 保留插图的定稿修订

以下操作已随 [PR #119](https://github.com/yuanbw2025/storyforge/pull/119) 合入 main，晚于 v4.0.0 发布包；请先按[兼容说明](/updates/compatibility)核对所用构建。

1. 在当前文字冒险制作中展开“修订定稿并保留插图（高级）”，点击“下载可编辑的当前定稿”。
2. 保留 JSON 中的版本与原稿标识，只修改允许的文字内容、任务或选择；这不是整个项目的备份，也不是换人物、地点或美术设计的入口。
3. 导入修订文件，核对修改项目与保留图片数量，勾选保留原图及仍需独立审图和真人验收的确认。
4. 点击“创建修订版并重新审校”。系统生成新 Build，重新检查正文、对白、连贯性、视觉依据与自动游玩；旧版本和存档保留，不会自动迁到新版本。

若原稿已经变化，重新下载当前版本再修改；不要手改版本号绕过校验。审校重试或备份恢复继续核对图片授权、内容与冻结来源；缺失或无效证据会阻断，不能把“保图”理解为免审发布。完成修订后仍需完成相应真人验收。

## 导出独立网页游戏

同一主干更新在“发布与导出”的产品包区域增加“导出独立网页游戏”。它与原有完整产品包并列，要求正式 ProductRelease、有效素材和已有的真人验收及社区候选资格；没有签发的试玩 Build 不能直接导出为正式网页作品。

1. 选择通过资格复核的正式版本，点击“导出独立网页游戏”。
2. 下载 ZIP 并解压，将完整目录放到支持静态文件的 HTTPS 站点，或用本机 HTTP 服务打开；不要直接双击 `index.html`。支持部署在站点子目录。
3. 玩家打开该目录入口即可游玩作品内冻结剧情和规则，不需要安装 StoryForge，也不连接 AI 服务。包内保留运行所需素材与许可，不携带完整创作工作区、私密配置或生产历史。
4. 导出不会上传或公开作品。发布前另行核对内容和素材权利；需要公开时由作者自行选择托管方式。

网页存档留在当前浏览器和站点空间，按作品包身份隔离。换地址、浏览器或重新导出新版本不会自动搬迁旧存档；保留旧包以继续旧版。若提示播放器模板未构建，应使用包含模板的当前构建，而不是改包绕过检查。此功能的技术交付不证明任何具体作品已通过真实模型质量或真人试玩验收。
