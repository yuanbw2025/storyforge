# 文字冒险

> 当前界面明确标注“尚在开发完善中，目前非正式功能”。

文字冒险围绕行动选择、背包资源、能力状态、任务和结局展开。通用制作与运行尚未形成完整的正式用户体验。

## 目前可以怎样体验

推荐从“首页 → 示例作品”进入《雾港：失潮钟声》。这是已经准备好的[内置作品](/guides/examples)，可以体验文字冒险和 AVG 两种玩法。

“文字冒险 → 开发体验”提供已有制作与运行能力的试用入口，需要正确的工作区、作品与世界来源；正式制作还受项目显式授权和能力检查约束。

## 已有机制与限制

已有行动前置条件、资源消耗、任务目标、判定和效果结算机制。具体可玩内容、规则、媒资和结局仍需要逐作品验证。

页面预览不是已经完成的制作功能。不要为绕过检查手工修改数据或授权标记；入口不可用时先查看当前版本和页面提示。
