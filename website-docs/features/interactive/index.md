# 互动产品：先制作，再游玩

这些产品基于确定的世界版本，拥有自己的制作流程、素材和存档。目前均为预览，文字冒险和文字开放世界的通用界面仍在开发。

| 产品 | 适合的体验 | 当前主要限制 |
| --- | --- | --- |
| [跑团](/features/interactive/ttrpg) | AI 主持、调查、规则判定与团局 | 公共联网多人尚未部署 |
| [角色聊天](/features/interactive/character-chat) | 与确定角色交谈，保存关系和记忆 | 当前主要是文字，长期效果继续验证 |
| [AI 小镇](/features/interactive/ai-town) | 观察结局之后的居民生活与关系 | 长期模型、素材和性能仍需实测 |
| [AVG](/features/interactive/avg) | 分支剧情、背景、立绘与声音演出 | 通用文学与视听质量仍需逐作品验收 |
| [文字冒险](/features/interactive/text-adventure) | 行动、资源、任务与结局 | 通用制作界面仍在开发 |
| [文字开放世界](/features/interactive/open-world) | 地区探索与持续变化的任务 | 长期演化与完整体验仍在建设 |

## 共同流程

1. **世界封存**：准备可引用的世界版本。
2. **产品定向**：在具体产品中保存目标、规则和范围；部分产品允许先保存没有世界来源的草稿。
3. **产品执行**：开始正式制作前选择和检查所需世界版本，明确确认开始；检查产物，再发布为确定的产品版本。
4. **游玩**：从发布版本开始独立存档。

保存定向草稿不等于已经满足正式制作条件。游玩内容和角色记忆不会自动回写共享世界。

想先体验成品，可读[内置作品与示例](/guides/examples)。
