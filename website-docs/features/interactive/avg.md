# AVG 与视觉小说

> 预览：已接入作者工作台、制作修订、发布和玩家存档。通用生成的文学及视听质量仍需逐作品验收。

入口：“AVG → 作品库”。可以先通过[免 API 的内置作品](/guides/examples)了解舞台与选择。

## 推荐流程

1. 在“制作台 → 故事与体验”确定目标，在“路线与结局目标”安排分支。
2. 选择世界版本，通过“方案会谈”确认候选与制作方案。
3. 开始“制作流程”，核对“叙事图与对白”“变量与结局”。
4. 在“背景与立绘”“音频与演出”“素材管理”检查素材和演出引用。
5. 执行“检查与试玩”，修订问题后保留发布版本。
6. 在“游玩 → 玩家舞台”体验，通过“存档与路线”管理进度。

## 文本与演出怎样关联

剧情节拍可以关联背景、人物和音频等演出信息。素材缺失或引用错误会影响舞台，文字生成成功不代表视听交付已经完成。

检查每条关键路线能否到达预期结局，并确认恢复存档后的舞台状态。

## 当前边界

内置作品通过人工准备的剧情与素材展示可玩的结果，不代表任意世界都能自动生成同等质量的作品。声画素材需要合法来源及实际服务支持。
