# AVG 与视觉小说

> 预览：已接入作者工作台、制作修订、发布和玩家存档。通用生成的文学及视听质量仍需逐作品验收。

入口：“AVG → 作品库”。可以先通过[免 API 的内置作品](/guides/examples)了解舞台与选择。

## 推荐流程

1. 在“制作台 → 故事与体验”确定目标，在“路线与结局目标”安排分支。
2. 选择世界版本，通过“方案会谈”确认候选与制作方案。
3. 开始“制作流程”，核对“叙事图与对白”“变量与结局”。
4. 在“背景与立绘”“音频与演出”“素材管理”检查素材和演出引用。
5. 执行“检查与试玩”，修订问题后保留发布版本。
6. 在“游玩 → 玩家舞台”体验，通过“存档与路线”管理进度。

## 文本与演出怎样关联

剧情节拍可以关联背景、人物和音频等演出信息。素材缺失或引用错误会影响舞台，文字生成成功不代表视听交付已经完成。

检查每条关键路线能否到达预期结局，并确认恢复存档后的舞台状态。

## 图片、配音与本地原型的实验流程

在可用的开发预览中，从作者工作台进入对应媒资面板。先确定需求、用途、来源和使用权；图片与声音服务分别配置，保存需求不会自动发出请求。

1. “图片生产”可管理背景、人物家族、参考图与候选原图。仅供生成参考的图片不会自动加入演出。生成后先看原图、准确来源与费用记录，再审查用途和使用权并明确选用。
2. 需要局部加工时，核对输入图、配方和输出版本。两图区域合成、前景与表情等本地处理保留来源与回执；加工未完成、审查有阻断或来源过期时不能直接采用。可查看已有需求不等于当前环境已经开放新图片调用。
3. “逐句配音需求”从已保存对白选择 1～8 句，核对说话人、服务能力、合法音色和演法，再明确开始。等待本批生产完成后逐句审听、比较原件与加工结果并确认采用；不要把声音文件先出现当作生产已收尾。
4. 在演出中检查配音、BGM、环境声和音效的绑定与叠播。采用某个音频不等于所有对白都已配音；失败或中断按原槽位恢复，原件和历史版本保留。
5. 试玩后在“本地原型版本验收”选择完成的试玩存档，检查路线和冻结媒资，再明确保存本地原型。从该版本开始独立存档；修改时建立新 Build，旧版本不被改写。

迁移时使用[完整备份](/guides/backup-restore)，恢复后核对媒资、来源和冻结版本。工程中的九类媒资组合与恢复验证不替代每部作品的剧情、视觉、听感或商业验收。依据：[PR #219](https://github.com/yuanbw2025/storyforge/pull/219)。

## 当前边界

内置作品通过人工准备的剧情与素材展示可玩的结果，不代表任意世界都能自动生成同等质量的作品。声画素材需要合法来源及实际服务支持。
