# 角色聊天

> 预览：当前主要是文字互动；长期会话、角色表现和更多模型的效果继续验证。

入口：“角色聊天 → 作品库”。适合让确定的角色在给定背景与场景中互动，并保存独立关系与记忆。

## 制作与开始对话

1. 在“制作台”明确互动目标、角色与场景、记忆与边界。
2. 选择需要的世界版本；用“方案会谈”整理候选并确认制作方案。
3. 进入“制作流程”，核对人物快照、场景与规则。
4. 执行“检查与试玩”，处理阻断项后进入“发布与版本”。
5. 在“游玩 → 开始对话”启动会话。
6. 用“关系与记忆”“会话与分支”查看进展和历史。

## 角色为什么会记得

会话可记录承诺、秘密、冲突和关系变化。角色只能使用其允许知道的信息；会话与分支拥有独立状态，不会自动改写世界原始人物档案。

这套记录帮助持续对话，但不保证模型每次都保持人设。出现偏离时检查角色快照、场景约束和相关记忆，再决定是否分支或重新制作。

## 需要注意

新世界版本不会自动替换已有会话的来源。制作稿、发布版本与游玩存档分别管理，切换作品时先确认正在操作的对象。

## 开发分支中的新流程（尚未发布）

以下操作说明对应角色聊天开发分支中的候选界面，**尚未完成完整验证或进入正式下载包**。当前软件没有这些入口时，请继续使用上面的现有流程。交付状态见[待合并开发记录](/updates/development-status#character-chat-candidate)。

### 从原创起稿或角色卡准备作品

作品库中显式开启“查看原创体验起稿（实验性）”，可预览单角色行动、关系发展、多人调查三类原创种子。确认后创建一部新作品，不覆盖已有作品。它们仍是制作草稿：需要选择冻结世界、检查人物资料和知情范围、明确开始制作，再审核和发布，不能直接当作可玩体验包。

在私域人物配置中，可从本地 Character Card V2 JSON 或 PNG 转换角色草稿。先核对姓名、经历、性格和说话方式，再填写本体验中的身份并确认；之后保存方案。系统提示词、历史指令、世界书、扩展、宏和开场台词不会自动执行，PNG 图片也不会同时变成立绘。保留原卡与许可说明；署名不等于已经获得再分发许可。

### 填写作品署名与使用说明

在实验性 v3 制作方案中，显式勾选“随体验包提供作品署名与使用说明”，填写作品署名、可选的素材归属与致谢，以及适用许可或使用限制，再保存方案。它们会随新发布版本公开，不能充当角色的故事知识；修改制作草稿不会改写已发布版本。未填写时显示“未提供”，不默认授予使用或再分发许可，也不代表平台已经核实作者身份与权利。

### 安装与导出体验包

在“安装、比较与导出体验包”中选择完整包 JSON，检查人物、开场、角色行动时机、图片和许可说明，再确认安装。安装本身不调用 AI；开始聊天仍使用你配置的模型服务，服务凭据和设备语音不会随包传递。

发行版本号不会因安装次序改变。同一发行版本号出现不同内容时，请选择另一部作品安装，不会覆盖原版本或存档。

同一作品的不同版本并列保留；内容相同且完整的版本可复用，损坏的本机副本会明确阻止覆盖。导出完整体验包包含已发布内容和图片，**不包含聊天存档或制作草稿**；保存这些内容请使用[完整备份](/guides/backup-restore)。系统保存取消或失败时，按提示重试。

### 在兼容新版本中继续存档

选中正式存档后，打开“为当前存档检查新版本”，选择已安装版本并检查兼容性。只有被判定兼容的直接后继版本才能“确认创建升级副本”：作品介绍或图片可以变化，人物知识、剧情、权限或世界来源变化需要从新版本开始新故事。

若作者与使用说明发生变化，确认前会同时显示原版与目标版的声明。升级保留原存档，在新副本中继续对话；“返回原存档”回到原进度，不会把两边的新对话合并。未发送草稿留在原存档，改写继承的旧消息也应回原存档操作。还有未结束生成或待处理情境时，先处理这些事项，再检查升级。
