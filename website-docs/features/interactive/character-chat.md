# 角色聊天

> 预览：当前主要是文字互动；长期会话、角色表现和更多模型的效果继续验证。

入口：“角色聊天 → 作品库”。适合让确定的角色在给定背景与场景中互动，并保存独立关系与记忆。

## 制作与开始对话

1. 在“制作台”明确互动目标、角色与场景、记忆与边界。
2. 选择需要的世界版本；用“方案会谈”整理候选并确认制作方案。
3. 进入“制作流程”，核对人物快照、场景与规则。
4. 执行“检查与试玩”，处理阻断项后进入“发布与版本”。
5. 在“游玩 → 开始对话”启动会话。
6. 用“关系与记忆”“会话与分支”查看进展和历史。

## 角色为什么会记得

会话可记录承诺、秘密、冲突和关系变化。角色只能使用其允许知道的信息；会话与分支拥有独立状态，不会自动改写世界原始人物档案。

这套记录帮助持续对话，但不保证模型每次都保持人设。出现偏离时检查角色快照、场景约束和相关记忆，再决定是否分支或重新制作。

## 需要注意

新世界版本不会自动替换已有会话的来源。制作稿、发布版本与游玩存档分别管理，切换作品时先确认正在操作的对象。
