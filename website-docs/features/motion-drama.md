# 漫剧素材与前期生产

## 11月13日：保存、恢复与使用核对

逐镜采纳提示词前核对当前集的全部镜头覆盖，重复编号不能冒充完整镜头清单。快速切集遇到版本冲突时保留较新的选择。导出参考素材包会核齐当前版本实际选用的图像、音色等文件及原字节，缺件时停止导出；不从当前草稿偷偷补入不同素材，纯提示词版也不会夹带媒体。依据 [#312](https://github.com/yuanbw2025/storyforge/pull/312)、[#385](https://github.com/yuanbw2025/storyforge/pull/385)。


从一句话、本地小说或导入原文开始，准备外部视频制作所需的系列设定、逐集剧本、物料、分镜与提示词。入口：“漫剧素材 → 作品库 → 漫剧制作台”。

交付终点是外部视频生成之前。StoryForge 不在此流程中完成视频生成、选片、剪辑、混音或成片。


## 任务失败或刷新后

在任务列表检查运行失败、暂停、恢复中或需要核验的状态，打开原任务证据。已有保存候选时按入口恢复并检查，再由作者确认采纳。原请求结果未知时先保留记录，明确发起新请求会创建独立调用并可能计费。恢复读取失败保留错误，可再次检查原任务。见 [PR #255](https://github.com/yuanbw2025/storyforge/pull/255)。

## 开始前

确定来源范围、作品类型、目标篇幅、画面风格和计划使用的外部工具。使用小说时先核对冻结来源；不必先创建独立世界。

## 制作流程

1. **小说来源**：核对输入与冻结范围。
2. **系列设定、分集规划**：确认整季动力、人物弧线、单集转折与尾钩。
3. **物料库**：准备角色、服装、场景、道具和声音资料，记录版本和使用权利。
4. **单集节拍、单集剧本**：逐集推进动作、对白、声音和时长。
5. **分镜、参考帧**：安排镜头目的、构图、表演、转场，选择相关参考帧。
6. **画面提示词、运动提示词**：分别检查静态画面与动作过程、镜头运动和结束状态。
7. **质量审查**：检查连续性、完整性、权利和目标工具约束。
8. **版本与交付 → 工具适配包**：整理对应工具的逐镜输入，再交给外部工具使用。

## 如何使用工具适配包

当前实现包含 Seedance、Runway、LTX 及通用适配方向。按界面提供的包检查每个镜头的提示词、参考素材和输入槽位，再在目标工具中完成设置。

适配包表示内容经过相应整理，不保证第三方平台的当前版本、套餐或接口支持全部能力。素材尺寸、数量、时长和权限以目标工具实际要求为准。

## 修订时注意

修改系列设定或物料版本后，检查受影响的单集和镜头。先确认候选，再保留新的交付版本，避免把不同版本的角色素材和分镜混在一起。

图片、试听音频与文本生成可能使用不同服务并分别计费。只整理已有内容和执行确定性适配，不等于调用视频模型。
