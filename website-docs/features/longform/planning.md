# 长篇：设定、人物与故事设计

本页对应长篇工作台的“灵感与参考”“世界与设定”“故事设计”“人物与关系”。

## 先确定推动故事的内容

在“故事核心”写清主角、目标、阻力、代价和主线。世界设定为故事服务；只有背景百科而没有人物行动时，生成也可能停留在介绍设定。

在“创作规则”中补充视角、文风、基调、禁止事项和一致性要求。把“不要改变主角身份”写成具体约束，比“写得好一点”更容易检查。

## 从灵感或已有材料开始

短想法适合“灵感反推”；长篇原文适合“文档导入”，参考作品适合“项目参考与分析”。不同入口的用途见[导入与参考资料](/guides/import)。

AI 提出的设定先检查再采纳。不要把参考作品的专有角色与剧情直接作为自己的原创设定。

## 世界与地点

按需要维护真实与幻想规则、世界起源、自然环境、人文环境、力量体系和历史年表。地点库与地图用于表达空间关系，故事年表用于整理剧情实际发生的先后。

多世界作品还需要明确每个世界的范围和通道关系。记录放错世界，会影响后续资料读取；先检查当前世界再编辑。

## 人物与关系

使用主要角色、次要角色、NPC 和路人分类管理人物。填写能影响行动的动机、性格、目标、弱点、经历和关系；角色补全时检查选中字段，保留已经确定的内容。

关系网用于理解人物之间的联系。正文发生新关系或认知变化后，应核对相应候选，而不是只改人物简介就认为所有历史都已更新。

## 一次可执行的准备清单

- 有一个可写成行动的本章目标。
- 关键人物的目标彼此存在冲突或牵制。
- 本章需要的地点和规则已经明确。
- 创作规则没有互相矛盾的要求。
- 本轮 AI 候选已经经过确认。
