# 长篇：设定、人物与故事设计

## 编辑后怎样确认保存

作品资料、人物、世界设定与大纲等已接入保存确认的字段，编辑时保留当前输入，显示“正在保存…”；完成输入法组词后再切换。出现保存错误时不要关闭当前页面，保留输入，点击该字段的“重试保存”并确认错误消失。另一处修改造成冲突时先核对新记录，不反复覆盖。异常原文字段会保留数据并暂停该项编辑，先按提示恢复。

大纲与细纲候选仍需作者明确保存或采纳；正式作品字段、候选和原始模型回复分别保留。刷新前检查保存结果，回到原作品确认内容，不能只凭文字已出现在输入框就认为落盘完成。相关修复见 [PR #215](https://github.com/yuanbw2025/storyforge/pull/215)。


本页对应长篇工作台的“灵感与参考”“世界与设定”“故事设计”“人物与关系”。

## 先确定推动故事的内容

在“故事核心”写清主角、目标、阻力、代价和主线。世界设定为故事服务；只有背景百科而没有人物行动时，生成也可能停留在介绍设定。

在“创作规则”中补充视角、文风、基调、禁止事项和一致性要求。把“不要改变主角身份”写成具体约束，比“写得好一点”更容易检查。

包含 [PR #141](https://github.com/yuanbw2025/storyforge/pull/141) 的源码版本提供可选系统文元素：进入“故事设计 → 创作规则 → 系统文元素”，填写主角处境与目标、系统机制、奖励与成长、限制与代价、对抗力量与关系；题材仍在“作品概况”选择。勾选启用并点击“保存元素”，核对保存提示。各项可留白，停用保留原文；计划奖励不会自动成为已获得物品，也不会替换你选择的提示词模板。


## 从灵感或已有材料开始

短想法适合“灵感反推”；长篇原文适合“文档导入”，参考作品适合“项目参考与分析”。不同入口的用途见[导入与参考资料](/guides/import)。

AI 提出的设定先检查再采纳。不要把参考作品的专有角色与剧情直接作为自己的原创设定。

## 世界与地点

按需要维护真实与幻想规则、世界起源、自然环境、人文环境、力量体系和历史年表。地点库与地图用于表达空间关系，故事年表用于整理剧情实际发生的先后。

多世界作品还需要明确每个世界的范围和通道关系。记录放错世界，会影响后续资料读取；先检查当前世界再编辑。

多条故事进程或穿越记录尚未命名时，资料读取会用记录身份区分，不会仅因同属一个类别就判定内容冲突。已有名称仍按原规则检查冲突；遇到真实重复或矛盾时，请核对对应记录后再继续生成。

## 力量体系在哪里编辑

长篇工作台进入“世界与设定 → 世界起源 → 力量体系”。在同一页维护体系全貌、规则明细及等级词条；规则明细包含体系名称、描述、等级列表与修炼约束。世界引擎的“世界设定”也使用这个入口。

旧的“力量体系”独立导航已收起，旧链接会定位到世界起源的力量页。已有概述、规则明细和记录身份保留，不会自动互相覆盖；若概述与明细不一致，请核对后修改。多世界作品先选择当前世界，再编辑所属规则。

## 人物与关系

使用主要角色、次要角色、NPC 和路人分类管理人物。填写能影响行动的动机、性格、目标、弱点、经历和关系；角色补全时检查选中字段，保留已经确定的内容。

关系网用于理解人物之间的联系。正文发生新关系或认知变化后，应核对相应候选，而不是只改人物简介就认为所有历史都已更新。

## 一次可执行的准备清单

- 有一个可写成行动的本章目标。
- 关键人物的目标彼此存在冲突或牵制。
- 本章需要的地点和规则已经明确。
- 创作规则没有互相矛盾的要求。
- 本轮 AI 候选已经经过确认。
