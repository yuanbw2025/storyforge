# 伏笔、事实、认知与状态

入口集中在长篇工作台的“伏笔看板”“事实与认知”“状态与物品”“故事年表”。它们回答不同问题，不应当相互代替。

| 资料 | 解决的问题 |
| --- | --- |
| 伏笔 | 什么信息已经埋下、何时回应或回收 |
| 事实 | 正文证据支持什么，以及在哪个时间范围成立 |
| 角色认知 | 哪个人物已经知道什么 |
| 状态与物品 | 当前状态、持有物及获得消耗的过程 |
| 故事年表 | 剧情事件发生的先后 |

## 伏笔怎样进入写作

维护伏笔内容、状态与关联章节，让后续任务能了解该埋设、回应或回收什么。计划回收不等于正文已经回收；应当在实际写出后核对状态。

修改伏笔记录不会自动改写已完成正文。若调整揭示时机，检查关联章节与后续章纲，避免旧计划继续误导生成。

## 事实候选需要确认

章节的“提取事实”会提出候选；事实库区分“待确认候选”“已确认 Canon”和“异常待复核”。Canon 在这里指作者确认的正式事实。

确认时核对主体、事实内容、原文证据和有效时间。角色猜测、谎言或传闻不应直接升级为客观事实；角色知情范围需要另外核对。

正文修改、删除章节或角色之后，证据可能过期、缺失或时间范围失效。异常条目不会继续作为有效事实注入生成，需作者复核，而不是简单忽略警告。

## 物品与状态为什么仍要查

“人物档案说有一把剑”和“物品流水显示本章已经丢失”可能冲突。检查获得、交出、消耗与失去发生的章节，确认后续任务读取的依据是否正确。

同样，故事年表描述剧情发生时间，不等于你编辑文件的时间；跨章和多线叙事尤其需要核对顺序。

## 修改后的处理

先修正正文，再检查相关事实、状态、伏笔和摘要。影响分析帮助定位需要处理的后续内容，作者决定是否修订，不会自动把全书重写一遍。
