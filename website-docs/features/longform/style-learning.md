# 文风学习与互动校准

入口：长篇工作台 → 文风学习。它把你认可的写作习惯整理为当前作品的文风画像，供后续生成参考。它不是训练或微调模型，也不会自动重写已经完成的正文。

## 学习什么

语料来自你已经打磨的章节，以及保存的改稿对照样本。章节状态需要是“已修改 / 已润色 / 定稿”；纯初稿未必代表你想保留的风格。

改稿样本包含改前、改后和作者说明。说明“删掉解释性旁白，让情绪通过动作表达”，比只存两个文本更能解释你的取舍。当前可保存 8 组样本，带作者说明的样本优先参考；每轮实际注入有数量与长度限制，以界面提示为准。

## 画像与开关是两回事

点击“一键学习我的文风”或“重新学习我的文风”，先得到“待确认文风画像”。确认之前不会覆盖正式画像，也不会开启下游注入。

确认后可以在“我的文风画像”中修改，失焦保存；“注入中 / 已关闭”控制是否在支持的后续生成中使用。关闭可以保留画像，删除则会同时删除当前作品的画像、改稿样本和校准反馈。

不要仅因为画像已经存在，就认定每一次 AI 调用都会参考它。任务用途和实际上下文仍决定是否使用。

## 用互动校准判断效果

“互动校准”接受短文，当前上限 1600 字符。生成只改写这段文字，用于检验画像；它不会直接覆盖章节。

比较改写与原文，记录“更接近”或“仍需调整”，补充原因。确实认可的修改可以保存为改稿对照样本，供下次重新学习参考。反馈保存不意味着已经重新生成画像。

## 与其他功能的分工

| 功能 | 主要作用 |
| --- | --- |
| 创作规则 | 明确视角、基调、禁止事项和本作要求 |
| 文风画像 | 总结你认可的语言与表达习惯 |
| 项目参考分析 | 学习特定作品的结构、手法与研究资料 |
| 本轮生成要求 | 指定这一次允许改什么、必须保留什么 |

若三者互相冲突，先整理要求，避免反复试生成。学习和校准都会调用模型；选取有代表性的少量语料，比无差别重复分析更易判断效果。
