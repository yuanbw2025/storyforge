# 多世界、地点与地图

长篇中的世界设定服务本作；世界引擎中的独立世界用于封存和复用。编辑长篇设定，不要求先把小说转成独立世界。

## 多世界什么时候有用

多个世界、位面或时代拥有不同的规则、地点和角色归属时，可在“作品概况 → 多世界设置”管理世界范围与通道。

在具体模块编辑前确认当前世界。人物同名不代表同一个实体，不同世界的力量规则也不应自动混用。跨世界通道表示明确关系，不代表所有内容天然互通。

## 地点库、地理设定与地图

| 入口 | 主要内容 |
| --- | --- |
| 地点库 | 故事中可识别的地点及其叙事用途 |
| 地理设定 | 环境、区域与空间关系 |
| 世界地图 | 对世界地理与实体位置的可视表达 |

地图不能替代地点说明。角色的移动是否合理，还要结合距离、交通、规则与故事时间判断。

## 生成地图后发生什么

地图生成先形成候选。候选页面显示配置、命名实体与空间关系，可先预览；只有“确认使用此地图”后才替换正式地图，放弃候选则保留原图。

生成前核对地理资料，生成后检查重要地点、相邻关系和通达性，而不只看画面是否漂亮。当前 3D 地图仍属于 Labs，界面标为不可用。

## 何时派生到世界引擎

当你希望把小说中确认的设定提供给其他产品，使用“派生世界”，明确范围并检查结果。派生后双方分别维护，改地图、人物或规则不会自动同步回原作。
