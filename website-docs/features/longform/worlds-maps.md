# 多世界、地点与地图

## 11月19日：二维图集与三种画风

在世界地图选择“简笔地图 / 绘本地图 / 连续绘画”。简笔用纸面和线绘符号；绘本内部选择中式或欧式素材。地图由已有设定形成有限几何候选，核对地点与关系后确认使用；三种画风共用同一布局，不新增地理事实。依据 #493/#495/#501。

可筛选 18 个图层、缩放平移、返回全图、调整文字大小并导出当前画风 PNG。湖泊孔洞、湖心岛、相邻陆块共享海岸及跨水道路按同一几何绘制；成图仍需作者核对。

三种画风都可选择“程序绘制”或“AI 美术增强”。程序版不需要生图 API；增强会先展示原版与候选，点击“使用此底图”后才应用。山林按原有范围合成，海岸、水域、道路、河流、城镇与文字继续由程序控制，山脉和森林仍可分别筛选；模型内部细节仍需核对。

在“图片连接与增强候选”中选择已保存的 API 预设，填写图片模型并选择对应图片接口与能力。图片连接可与写作连接不同；只会聊天、只能看图或只支持文生图的连接不会启用参考图重绘。当前适配 Agnes 参考图、OpenAI 兼容图片编辑及 Gemini 原生 Interactions，实际可用性取决于服务与账号权限。一次生成一个候选，可能消耗服务额度；失败或停止等待不会自动重发，也不会清除当前地图。

采纳后可保存到本机查看缓存，刷新或返回同一张地图时恢复，不重复生图。可在制作方式中切回程序版，已保存的增强图仍保留。修改海陆、山林等地形或种子后会暂停旧增强图，允许导出旧包或重新生成；仅改地名、城镇或道路不会要求重画。

**本机查看缓存不包含在项目完整备份中，换设备或清理浏览器前请导出底图包。** 保存失败会保留本次查看图并提示导出。导入底图包会检查地形、画风、图片格式和尺寸；旧版整图包仍可在连续绘画中导入，但其中山林合在图片内，不能独立筛选。此入口不是 3D 或游戏发布功能。

## 11月13日：保存、恢复与使用核对

切换世界、作品或分组前先等待当前世界观/地理草稿保存；失败会保留原稿并提供重试。另一个分组保存成功不会清除当前草稿的保存错误，空分组也不会显示上一个分组的地点。概念地图预览失败时可重试本地解码，原图保持；世界规则保存失败保留当前草稿。依据 [#332](https://github.com/yuanbw2025/storyforge/pull/332)、[#367](https://github.com/yuanbw2025/storyforge/pull/367)。


长篇中的世界设定服务本作；世界引擎中的独立世界用于封存和复用。编辑长篇设定，不要求先把小说转成独立世界。

## 多世界什么时候有用

多个世界、位面或时代拥有不同的规则、地点和角色归属时，可在“作品概况 → 多世界设置”管理世界范围与通道。

在具体模块编辑前确认当前世界。人物同名不代表同一个实体，不同世界的力量规则也不应自动混用。跨世界通道表示明确关系，不代表所有内容天然互通。

## 地点库、地理设定与地图

在“世界与设定 → 地点与地图”内切换地点库、地理设定、世界地图、城池词条和资料关联预览。旧地理或地图链接仍会打开对应视图。地点实体、地理树和地图布局保留各自资料；同名不会自动合并。城池词条可选择已有地点建立明确关联，关联预览帮助核对已有引用和未映射资料。

| 入口 | 主要内容 |
| --- | --- |
| 地点库 | 故事中可识别的地点及其叙事用途 |
| 地理设定 | 环境、区域与空间关系 |
| 世界地图 | 对世界地理与实体位置的可视表达 |

地图不能替代地点说明。角色的移动是否合理，还要结合距离、交通、规则与故事时间判断。

## 生成地图后发生什么

地图生成先形成候选。候选页面显示配置、命名实体与空间关系，可先预览；只有“确认使用此地图”后才替换正式地图，放弃候选则保留原图。

生成前核对地理资料，生成后检查重要地点、相邻关系和通达性，而不只看画面是否漂亮。当前 3D 地图仍属于 Labs，界面标为不可用。

## 何时派生到世界引擎

当你希望把小说中确认的设定提供给其他产品，使用“派生世界”，明确范围并检查结果。派生后双方分别维护，改地图、人物或规则不会自动同步回原作。
