# 项目参考、作品分析与资料检索

入口：长篇工作台 → 灵感与参考 → 项目参考与分析。参考资料用于学习和提供依据，不会因为上传就成为本作正式设定。

## 选择合适的用途

| 需求 | 合适的入口 |
| --- | --- |
| 把自己的小说正文导入作品 | 文档导入 |
| 研究参考作品的结构、人物或写法 | 项目参考与分析 |
| 学习自己修改后的语言习惯 | 文风学习 |
| 管理创作中需要查找的资料 | 资料与检索 |

区分这几种用途，可以避免把参考小说导成自己作品的人物和剧情。

## 分析深度与来源用途

参考分析提供不同深度，先按需要选择；长篇材料可能分块处理，并记录进度和分析版本。更深不等于更适合每次任务，也意味着更多模型调用和等待。

核对来源类型、使用范围和权利说明。研究资料或不明来源有更严格的使用范围；不要把“可以分析”理解为可以复制成原创作品。

## 待确认、当前使用和历史版本

分析完成后先处于待确认状态。检查新报告及与当前分析的差异，再将合适的分析版本设为当前使用。旧报告会保留为历史，而不是每次分析都覆盖一切。

失败或取消的分析不等于已经生效；重新上传或重新分析后，也应核对哪个版本仍是当前使用。

## 怎样影响写作

参考分析把材料转为可检查的结论。后续生成是否读取，取决于当前任务、引用设置和实际上下文。只把文件放入资料库，不代表模型每次会读取全文。

历史事实、叙事手法和原作虚构设定应分别理解。引用研究资料时仍需要核对证据；引用写作手法不等于照搬情节和人物。

## 与长篇记忆的区别

项目参考保存外部材料与分析；本作的正文、已确认事实、摘要和章后状态构成自己的连续性依据。外部参考不能覆盖本作已经确认的事实。
