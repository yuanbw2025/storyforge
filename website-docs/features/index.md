# 功能指南

先按目标选择产品，再阅读对应的操作指南。各页面包括入口、准备、流程、交付物与当前边界。

## 独立创作

- [分步骤长篇](/features/longform/)：从构思和人物到卷章正文与连续性管理。
- [短篇小说](/features/shortform)：围绕整篇结构与篇幅完成一篇故事。
- [小说转剧本](/features/screenplay)：冻结来源、改编、场景写作和格式导出。
- [小说转漫画](/features/comic)：分页、页格、排字与视觉交付。
- [漫剧素材](/features/motion-drama)：为外部视频生成准备逐集、逐镜材料。
- [节点创作（预览）](/features/nodes)：在画布上组合长篇动作。

## 世界与互动

- [世界引擎](/features/world-engine)：编辑、派生和封存可复用设定。
- [互动产品](/features/interactive/)：跑团、角色聊天、小镇、AVG 与开发中的文字游戏。
- [内置作品与示例](/guides/examples)：先阅读或游玩，再决定创作方向。
