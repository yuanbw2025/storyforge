# 节点创作

> 当前为预览。完整跨模式互操作和真实用户路径仍在验证。

入口：“长篇 → 长篇工作台 → 节点创作”。节点把输入、生成步骤和中间结果放到画布上，供作者查看和组合。

## 适合什么时候使用

已经熟悉分步骤长篇，并希望拆解某次生成、复用中间材料或检查上下游输入时，可以尝试小范围工作流。

日常写作仍可使用[分步骤长篇](/features/longform/)。

## 推荐试用方式

1. 先保存完整备份，选择一个小任务。
2. 检查官方节点或模板的输入要求，连接所需资料。
3. 逐步执行并核对每一步实际输入与输出。
4. 需要写入正式作品时，使用允许的候选确认入口。
5. 返回分步骤界面检查正式结果。

官方节点复用长篇领域能力、作品和记忆。实验节点的草稿不能直接成为正式设定。

## 当前限制

不要把任意节点连通理解为语义正确，也不要把预览画布理解为第二套独立作品数据库。非法连接、过期输入或缺少权限时，应按提示修正再执行。

继续阅读：[AI 候选与恢复](/guides/ai-workflow)。

## 两种节点入口

长篇工作台的“节点创作”使用正式领域节点。提示词库中的工作流编辑器则提供“本节点模板”、材料绑定和“给 AI 的提示”；它们是不同入口，不能把提示词工作流的模板更新理解为领域画布已经同步更新。

提示词工作流可使用[熔炉写作工坊](/guides/using-prompts)模板；连接上游材料时明确变量，不能只连接线而遗漏输入。

## 节点维护与恢复

以下改进通过 [PR #115](https://github.com/yuanbw2025/storyforge/pull/115) 交付；完整检查和合并状态以 PR 为准，在线部署另行核对：

- 单字段节点可填写“生成要求”；节点库可以查找，实验草稿默认隐藏。
- “运行到此节点”只处理该节点与所需上游，其他未完成分支可继续留作草稿。
- 候选修改和版本选择自动保存；切换模式前等待保存，失败保留输入。拒绝候选不写入作品，已采纳和已拒绝结果保持只读。
- 固定目标角色的节点可确认采纳，返回分步骤页面检查同一角色。原稿或目标变化时阻止旧候选覆盖。
- 刷新中断后先恢复已保存结果；恢复本身不调用模型，继续生产需另行操作。
- 手机分开显示节点库、画布、节点设置和候选与证据，切换视图保留修改。

本轮自动测试使用隔离模型响应，不代表真实文学质量；所有官方长篇模板的完整跨模式验收仍待完成。继续查看[开发中内容](/updates/development-status)。

## 自由编排与提示词选择

以下操作属于 PR #115 的节点预览改进；在线版本以对应部署结果为准。

1. 从节点库点击或拖入节点，或在画布空白处右键、双击后搜索新建。
2. 从输入端口往前拖、输出端口往后拖；释放到空白处，搜索兼容节点并选择，系统创建节点并接好所选端口。也可以直接拖到已有节点的兼容端口。
3. 选中节点，在“已连接的线”中断开再连接；选择器可用 Escape 取消。画布工具栏可以放大、缩小或恢复 100%。
4. 从生成节点的 Prompt 输入拖出“Prompt 模板”，查找内置或我的模板。选择后可调整模板参数、填写必需变量和“本次补充”，也可展开调整本节点提示词。
5. 模板版本与调整随当前图保存，不改变全局模板。点击“保存”确认“已保存”后再刷新；缺少必需输入时先补齐，模型不会替你猜测。
6. 温度、输出 Tokens、候选数量等控制节点连接到对应端口后生效。改变上游设置后重新运行，旧候选不能采纳覆盖新稿。

连接选择只展示语义兼容的登记节点；实验草稿仍需显式开启，并且不能直接写入正式作品。
