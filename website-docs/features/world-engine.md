# 世界引擎

## 11月13日：保存、恢复与使用核对

从小说派生世界时，只有能证明属于同一作品和作用域的章节关联会在新工作区重新绑定；不确定引用保留原值及复核说明。历史封存不随派生改变。来源库中的只读世界缓存不等同于当前作者的本地封存：正式制作前核对来源用途、版本和必需资料，资料不足或不匹配时按提示处理。作者关闭的资料不会继续进入正式上下文。依据 [#307](https://github.com/yuanbw2025/storyforge/pull/307)、[#377](https://github.com/yuanbw2025/storyforge/pull/377)、[#380](https://github.com/yuanbw2025/storyforge/pull/380)、[#429](https://github.com/yuanbw2025/storyforge/pull/429)。


用于建立可复用的设定、人物、关系与规则，封存为确定版本供其他产品引用。入口：“世界引擎 → 我的世界 → 新建世界”。

## 从哪里获得世界

可以从零编辑，也可以由长篇或短篇显式派生。派生保留选定范围和来源版本；原作仍属于原作品，后续修改不自动同步。

剧本、漫画与漫剧素材不提供“封装为世界”的路径。

## 编辑与封存

1. 在“我的世界”选择目标世界。
2. 进入“世界设定”，按需编辑规则与起源、自然与地理、人文与社会、人物与关系、历史与事实。
3. 有多世界需求时维护世界集合、位面与通道。
4. 在“版本与封存”核对范围、遗漏和来源，确认后生成不可变世界版本。
5. 在“数据出口”查看指定版本的能力、资源与证据。
6. 需要文件分享时进入“分享与导入”，核对署名、许可与用途。

“社区与发行”目前用于准备可分享的版本与许可，不能理解为公共市场服务已经上线。

## 力量体系在哪里编辑

长篇工作台进入“世界与设定 → 世界起源 → 力量体系”。在同一页维护体系全貌、规则明细及等级词条；规则明细包含体系名称、描述、等级列表与修炼约束。世界引擎的“世界设定”也使用这个入口。

旧的“力量体系”独立导航已收起，旧链接会定位到世界起源的力量页。已有概述、规则明细和记录身份保留，不会自动互相覆盖；若概述与明细不一致，请核对后修改。多世界作品先选择当前世界，再编辑所属规则。

## 世界如何变成互动作品

先封存世界，再进入跑团、角色聊天、AI 小镇或文字游戏等具体产品，选择版本、完成定向配置并明确开始制作。世界页面不会直接把草稿变成正式游戏。

每种产品读取自己需要的世界内容，随后拥有独立的制作数据、素材、发布版本和存档。

## 叙事世界的本地实验预览

叙事注释、编译、视角查询与修改影响工具已合入主干；增强入口仍只在本地开发模式显式添加 `?narrative-preview=1` 时出现，生产构建默认隐藏。请用隔离的测试作品和备份试用。

1. 在事实库选择“叙事注释（实验）”，核对记录、原文证据、时间、可见范围，以及它属于事实、角色认知还是作者计划。模型建议先保存为候选，检查后确认，不直接覆盖原文。
2. 在“版本与封存”选择语义范围，可勾选“同时包含当前工作区作品的已确认正文与叙事”，再点“捕获并编译所选内容”。这一步核验快照，无需调用模型，也不会自动发布。离开后可返回选择已保存任务继续；来源变化时按提示重新核对。
3. 编译完成后确认冻结，再发布世界版本。在“数据出口”的实验查询中选择实体、故事线、时间或角色视角；索引摘要用于查找，点击“查看完整原文证据”核对冻结原文。未知时间与尚未标注的正文保留缺口，查询为空不表示故事中不存在。
4. 修改后编译时可选一个已有修订作为比较基准，查看直接变更、依赖待重验与作者待复核项目。它是检查清单，不自动改写正文、锁定内容或旧世界版本。

目前修改影响的语义准确度、正式规模性能、读者完整性和作者改稿省时仍待验收；不能把列表当成完整的因果证明。世界只提供语义内容，产品图片、发布与会话仍由各具体产品持有。依据：[PR #197](https://github.com/yuanbw2025/storyforge/pull/197)。

## 版本的意义

世界第一版可以供一场跑团使用，同时继续编辑第二版。已有作品和存档不会自动升级到第二版；是否采用新版，需要在相应产品中明确处理。

世界版本保存语义资料，不包含上层产品的图片、运行状态和玩家私域演化。
