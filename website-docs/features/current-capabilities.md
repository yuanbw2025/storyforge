# 当前产品能力

StoryForge 当前不是单一“AI 写小说”页面，而是一组共享叙事基座的创作与体验产品。

## 长篇小说

提供从资料、世界设定、故事设计、人物、大纲到章节正文的分步骤创作流程，并持续管理伏笔、事实、角色状态、物品与时间线。AI 输出以候选形式进入作者确认流程。

## 短篇小说

围绕独立短篇建立故事设计、章节规划、逐章创作、审校、定向重写与成稿检查流程，重点控制篇幅、完成条件和整篇一致性。

## 小说转剧本

保存原文来源与改编依据，把原作拆成事实、因果、改编决定、节拍、场景与结构化剧本正文，并支持面向剧本格式的导出。

## 小说转漫画

把叙事、分页分格、角色视觉资料、画面与排字拆成不同层级管理，以便单独修改某一格或某一层，而不是把整页当成不可编辑的图片。

## 世界引擎

用于建立可复用的世界设定、角色与规则，并把确认后的世界状态封存成可被其它作品或互动产品引用的版本。

## 节点创作

把部分长篇创作步骤以可视节点方式组合，复用现有作品、上下文与候选采纳机制。当前仍属于预览能力，完整跨模式互操作继续验证。

## 互动与体验产品

仓库包含跑团/AI KP、视觉小说、文字冒险等不同成熟度的体验入口。内置作品《雾港：失潮钟声》不需要模型 API 即可体验；部分互动能力仍处于预览或开发状态。

## Agent + Harness

核心 AI 任务逐步统一进入受治理、可恢复、可审计的执行链：冻结任务合同与上下文来源、限制重试、保存候选和运行证据，并在作者确认后通过正式写入路径采纳。

## 诚实边界

StoryForge 提供的是创作工具、状态管理和 AI 执行基础设施，不保证模型永远不遗忘，也不保证生成作品不存在矛盾。模型能力、费用和文学质量仍依赖用户选择的模型、作品材料与作者审校。
