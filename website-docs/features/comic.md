# 小说转漫画

把小说逐步转成漫画脚本、分页、页格、画面与排字。入口：“漫画 → 作品库”，选择或创建改编作品，再进入“漫画制作台”。


## 任务失败或刷新后

在任务列表检查运行失败、暂停、恢复中或需要核验的状态，打开原任务证据。已有保存候选时按入口恢复并检查，再由作者确认采纳。原请求结果未知时先保留记录，明确发起新请求会创建独立调用并可能计费。恢复读取失败保留错误，可再次检查原任务。见 [PR #255](https://github.com/yuanbw2025/storyforge/pull/255)。

## 先看一部动态漫画

从“漫画 → 作品库”或“首页 → 示例作品 → 漫画”打开《末班来信》，在新标签页观看 50 秒有声动态样片。无需配置模型；支持播放、暂停、拖动进度、重播、音量、全屏和静帧对照。建议横屏并佩戴耳机。返回漫画示例后仍可阅读原有四套完整页漫。

这是独立制作、已准备素材的播放展示，包含有限动作、镜头与环境效果，不代表当前漫画产品能够自动生成同等动画；不创建或修改你的作品。首次观看需要联网加载素材，声音在点击播放后开始，切换标签页会暂停。

## 推荐顺序

1. **原作与方案**：确认来源范围、阅读方向、篇幅、事实、因果与删改决定。
2. **漫画脚本**：把叙述改为可见的行动与对白，安排分页节奏。
3. **页格与排版**：检查镜头、格数和阅读顺序，再编辑对白、旁白、气泡与拟声。
4. **视觉与素材**：建立人物、场景、道具的视觉特征，管理参考图和具体页格的图片候选。
5. **质量审查**：检查叙事、阅读链、文字与媒资完整性，按问题修订。
6. **阅读预览**：按实际阅读方向通读。
7. **版本与导出**：选择分镜版或视觉版，通过相应检查后保存版本并导出。

## 先确认分镜，再制作画面

先看页格能否讲清故事，再投入图像生成费用。对白和气泡保存在独立排字层，修改错字不需要重新生成整格图片。

画面是否挡住文字、角色动作是否连续，仍需要人工阅读检查。

## 图片服务的限制

文字模型配置不等于图像服务配置。内置通用 OpenAI 兼容图像适配器目前按文本生成，不能因为提示词写了“参考图片”就认为图片已经传给模型。

参考图、固定 seed、局部重绘等能力取决于实际服务适配器。界面若阻止或降级某项操作，应查看能力提示；可在允许的入口使用有权使用的作者素材。

## 两种交付

- **分镜版**：重点验证脚本、页格与阅读结构。
- **视觉版**：还需要有效的选定图片、排字与媒资检查。

产品支持 PNG、WebP、CBZ、PDF 交付，具体可用格式取决于所选版本和完成状态。冻结版本保留其媒资引用；不要手动清理浏览器数据来释放图片空间。

漫画与源小说分别保存，漫画不提供派生世界路径。继续阅读：[导出与交付](/guides/export) · [数据与隐私](/guides/privacy)。
