# 小说转剧本

把已有小说改编为电影、剧集或短剧。入口：“剧本 → 我的剧本 → 新建剧本改编”。剧本与原作分别保存。

## 创建与冻结来源

选择本地小说，指定整部或部分章节；也可粘贴原作，或上传界面接受的 TXT、Markdown、DOCX、PDF。检查提取的文本，再选择剧本类型、集数和时长，点击“冻结来源并创建剧本”。

冻结表示本次改编使用确定的原文。后续修改源小说不会自动改写已经建立的剧本。

## 从原作到场景

1. **原作与来源**：核对原文范围、事实和因果依据。
2. **改编目标**：明确受众、形式和删改边界，检查改编决定。
3. **结构与节拍**：安排事件、转折与戏剧节奏。
4. **场次目录**：检查场景目的、人物、时间、地点与承接。
5. **剧本编辑**：编辑结构化场景、动作和对白。
6. **原作一致性**：检查改编与来源的关系。
7. **戏剧性审校**：检查冲突、节奏与场景效果，按问题定点修订。
8. **版本与导出**：通过检查后冻结版本并导出。

## 如何处理改编选择

把人物合并、情节删减或内心独白外化，记录成明确的改编决定。判断时同时考虑原作重要信息是否保留，以及新场景能否通过动作和对白表达。

已锁定或版本已改变的场景不能直接接受旧修订。先核对当前场景，再按界面提示处理。

## 输出与边界

支持 Fountain、FDX 和打印输出。打印时能否保存 PDF 取决于浏览器打印选项。完整项目备份另见[备份与恢复](/guides/backup-restore)。

这是剧本改编流程，不负责拍摄、剪辑或电影成片。剧本产品不提供派生世界路径。
