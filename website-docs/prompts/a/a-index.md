# 小说 Prompt 体系总目录与调用路线
::: tip 迁移来源
本页由原始 Word Prompt 资产迁移为 Markdown，尽量保留原文结构、术语、表格和示例。这里的 Prompt 是创作资产/方法资料，不等同于当前 StoryForge 代码中的唯一运行模板；实际产品行为以当前仓库和界面为准。
:::

## 九、最短可用路线

- 长篇完整稿：P00 → P02 → P03 → P05/P06/P07 → P08 → P09L → P10/P11/P12 循环 → P13/P14/P15 → P16。

- 连载长篇：上述路线 + P09R；读者反馈先经过整理和判断，再决定是否修改大纲。

- 短篇：P00 → P01/P03 → P09S → P10（精简）→ P11 → P14/P15 → P16。

- 已有全稿修订：P13 → P12 连续性审计 → P14 → P15 → P16。

## 十、使用原则

1.  不同时运行多个会修改同一事实目标的生成 Prompt。

2.  诊断输出先由作者确认，再进入修订 Prompt。

3.  类型规则和连载策略不能覆盖已写事实与作者明确选择。

4.  参考材料只用于提取创作机制，不把专有名称和表达指纹带入成品。

5.  每次写入前保留原稿、Prompt 版本、输入快照和采用记录。
