# 小说创作阶段与 Prompt 体系总蓝图

版本：1.0

适用范围：长篇小说、短篇小说、连载型网络小说

用途：定义 Prompt 资产的分类、依赖、输入输出和建设顺序。本文件不是一套固定写作公式。

## 一、设计结论

1.  小说创作不是一条不可回头的流水线，而是“构思、规划、起草、校验、修订”之间的循环。阶段编号表示依赖关系，不表示作者必须按顺序完成全部步骤。

2.  长篇与短篇不是同一模板的字数档位。长篇需要卷级承诺、复线编织、长期升级和连续性账本；短篇需要集中于一个核心变化、有限人物与视角、压缩背景，并更早进入不可逆变化。

3.  连载策略不是小说普遍规律。“章末钩子、固定频率回报、付费卡点、稳定更新”等仅在连载档案启用，不得污染文学短篇、非类型小说或完整出版稿。

4.  结构模型是诊断和规划工具，不是填空公式。三幕、七点、故事圈、雪花法、场景-后续等应按项目问题选择，不能同时强制叠加。

5.  Prompt 必须服务作者决策。高质量输出应给出多个可比较方案、明确取舍和可采纳的结构化结果，不能用华丽术语替代具体剧情。

## 二、四层规则模型

|                |                                    |                                                        |                |
|----------------|------------------------------------|--------------------------------------------------------|----------------|
| **层级**       | **含义**                           | **示例**                                               | **默认处理**   |
| U 通用叙事原则 | 跨体裁普遍有帮助，但仍允许有意违背 | 因果可理解、角色行为有动机、重要变化有铺垫与后果       | 默认开启       |
| G 体裁惯例     | 为满足特定读者期待而采用           | 推理的线索公平、爱情故事的关系主轴、成长文的可感知进步 | 选定体裁后开启 |
| S 连载策略     | 面向分章阅读、追更与平台节奏       | 单章阅读回报、阶段承诺、更新缓冲、断点设计             | 仅连载模式开启 |
| P 项目偏好     | 作者主动选择的风格与限制           | 视角、禁写项、叙事密度、语言基调、结局倾向             | 优先级最高     |

发生冲突时：事实与已写正文 \> 作者明确要求 \> 项目规则 \> 体裁惯例 \> 连载策略 \> 通用默认。所谓“通用”也只能作为默认建议，不能覆盖作者有意识的实验。

## 三、总流程

素材进入 → 灵感澄清 → 定位与承诺 → 故事核心 → 世界与研究 → 人物系统 → 剧情发动机 → 结构选择 → 长篇/短篇分支 → 章场规划 → 正文生成 → 连续性维护 → 宏观修订 → 场景与语言修订 → 读者验证 → 包装输出

另有两条贯穿全程的横向轨道：

- 事实与连续性轨：人物状态、时间线、物品、地点、世界规则、伏笔、已写事实。

- 质量保障轨：版权合规、信息安全、版本记录、测试样例、失败修复。

## 四、阶段任务矩阵

### P00 创作任务定义

- 目标：把“我想写点什么”变成可执行的创作简报。

- 必需输入：创作意图、篇幅模式、预期读者、是否连载、不可触碰项。

- 主要输出：创作简报、已知/未知清单、决策优先级、风险项。

- Prompt 家族：需求澄清器、创作约束整理器、缺失信息诊断器。

- 当前产品承接：项目信息、创作规则、参考资料。

### P01 原始灵感与素材净化

- 目标：从混杂材料中保留可迁移的冲突、意象、关系、机制和情绪，不带走原作指纹。

- 必需输入：碎片、笔记、梦境、观察、参考材料。

- 主要输出：原子灵感卡、创作机制、可变元素、不可复用元素和风险提示。

- Prompt 家族：灵感拆粒、去语境抽象、跨素材聚类、矛盾合并、灵感追问。

- 当前产品承接：灵感、参考资料、创作规则；现有能力偏记录，缺少系统聚类与筛选。

### P02 题材定位与读者承诺

- 目标：明确作品让哪类读者因何持续阅读，以及作品会交付什么体验。

- 必需输入：灵感卡、篇幅模式、候选题材。

- 主要输出：题材/子题材、目标读者、核心快感或情感价值、体裁承诺、差异点、禁用套路。

- Prompt 家族：题材识别、读者期待矩阵、承诺-兑现表、差异化定位、同类风险检查。

- 注意：市场定位是选择，不应反向抹平作者独特性。

### P03 概念筛选与故事核心

- 目标：把候选灵感压缩为具有因果潜力的故事概念。

- 必需输入：灵感卡、题材承诺、作者偏好。

- 主要输出：一句话故事、核心概念、主人公、欲望、阻力、代价、主题张力、核心戏剧问题。

- Prompt 家族：概念发散、概念评分、前提压力测试、故事核生成、主题对立面探索。

- 当前产品承接：故事核心中的主题、核心冲突、概念、主线、复线。

### P04 研究计划与事实边界

- 目标：区分必须考证、可以合理推演和允许架空的内容。

- 必需输入：故事核心、时代地点、职业/技术/文化要素。

- 主要输出：研究问题树、事实锚点、来源等级、待核验项、架空声明、避免时代错置的清单。

- Prompt 家族：研究计划、史实核验、专业场景问诊、来源冲突裁决、事实转剧情。

- 当前产品承接：历史资料、世界规则、地点、百科词条、场景考证。

### P05 世界观与叙事环境

- 目标：只构建会影响人物选择、资源分配和冲突的世界，而非百科堆砌。

- 必需输入：故事核心、体裁、研究边界、人物初步需求。

- 主要输出：世界规则、空间关系、资源与生计、制度、势力、历史因果、文化习惯、日常感官、矛盾源。

- Prompt 家族：世界原则、地理-资源-社会链、制度压力、势力生态、历史年表、生活纹理、设定矛盾审计。

- 当前产品承接：世界起源、自然/人文、力量体系、地理、历史、规则、地点、词条。

### P06 人物系统

- 目标：设计能在压力下做出有辨识度选择的人物网络。

- 必需输入：故事核心、世界压力、体裁承诺。

- 主要输出：角色功能、外在目标、内在需要、价值观、恐惧、矛盾、资源、弱点、声音、弧线、关系动力。

- Prompt 家族：主角/对抗力量/配角设计、人物反差、谎言-欲望-需要、关系张力、人物声音、角色冗余审计。

- 当前产品承接：完整人物字段、人物关系、人物状态、人物驱动剧情。

### P07 剧情发动机

- 目标：建立能够持续产生选择、阻力、后果和新问题的机制。

- 必需输入：人物目标与资源、世界规则、体裁承诺。

- 主要输出：核心冲突链、升级阶梯、风险与代价、对抗策略、信息差、失败后果、重复可变机制。

- Prompt 家族：目标-动机-冲突、对抗力量、升级阶梯、尝试-失败循环、信息释放、奖励与代价设计。

- 当前产品承接：故事核心、故事线、情绪节拍、力量体系；缺少专门的升级阶梯和信息释放矩阵。

### P08 结构模型选择与全书转折

- 目标：根据故事问题选择最少且足够的结构工具。

- 必需输入：故事核心、预期结局、篇幅模式、体裁承诺。

- 主要输出：结构选择理由、开端状态、诱发事件、重大转折、中点变化、危机、高潮、结局新状态。

- Prompt 家族：结构模型推荐、结局反推、重大节点规划、结构对照审计、反公式化改写。

- 约束：输出必须说明模型适配原因和不适用处，不得同时强制套用多个模板。

### P09-L 长篇架构分支

- 目标：把全书转折扩展为可持续的卷、故事线和承诺-兑现系统。

- 必需输入：全书转折、目标字数、连载模式、主要人物弧。

- 主要输出：卷级目标、卷内冲突、卷末状态变化、复线编织、高潮梯度、中段支撑、伏笔周期、信息释放计划。

- Prompt 家族：卷级架构、长篇中段诊断、复线编织、角色弧对齐、高潮阶梯、卷级承诺-兑现账本。

- 当前产品承接：卷纲、章纲、故事线、伏笔、情绪节拍；需增强复线碰撞和卷级账本。

### P09-S 短篇架构分支

- 目标：围绕一个核心变化建立高压缩叙事。

- 必需输入：核心事件或顿悟、主角、主导情绪/洞见、目标字数。

- 主要输出：最小人物表、单一主线、进入点、关键选择、转折、结尾余震、必须删去的背景。

- Prompt 家族：单一效果设计、短篇压缩、晚进入早离开、人物合并、结尾反照、删减审计。

- 约束：默认不生成复线和庞大设定；必要时才增加第二视角或框架叙事。

### P09-R 连载运营分支

- 目标：在不破坏作品完整性的前提下设计分章阅读体验和生产缓冲。

- 必需输入：长篇架构、更新频率、章节长度范围、平台/读者习惯。

- 主要输出：阶段阅读回报、更新缓冲、卷/章断点、追更问题、反馈采纳规则。

- Prompt 家族：连载节奏、章末断点、承诺兑现密度、存稿规划、反馈去噪。

- 约束：只有启用连载模式时，才把章末钩子和更新节奏作为硬约束。

### P10 章节与场景规划

- 目标：确保每章、每场景都有不可替代的叙事作用。

- 必需输入：所属故事线、前后节点、角色当前状态、场景条件。

- 主要输出：章节功能、场景目标、阻力、转折、结果、情绪变化、信息增量、出入场状态、预计篇幅。

- Prompt 家族：章节任务单、场景卡、场景-后续、情绪节拍、信息增量检查、删场合场诊断。

- 当前产品承接：章纲、细纲、场景、情绪弧、开头衔接、结尾设计。

### P11 正文起草

- 目标：依据已确认计划生成具有具体行动、感官、声音和节奏的小说文本。

- 必需输入：章节任务、场景卡、连续性事实、人物声音、创作规则。

- 主要输出：正文草稿、必要时附不确定项清单。

- Prompt 家族：首章、普通章节、续写、对话、动作、内心、描述、转场、章节标题、替代开场/结尾。

- 约束：“展示而非告知”改为按叙事目的选择展示、概述或省略；不默认每章都以悬念结束。

### P12 连续性与叙事记忆

- 目标：让长文本跨章保持事实、状态、物品、时间、地点、关系和伏笔一致。

- 必需输入：已写正文、上一章交接、当前计划、事实账本。

- 主要输出：章节摘要、结尾交接、计划-正文偏差、状态变化、时间线事件、物品流转、伏笔变化、冲突警报。

- Prompt 家族：章节记忆、事实抽取、状态更新、时间线核对、物品账、关系变化、伏笔生命周期、计划对账。

- 当前产品承接：这是现有能力最强的部分，应作为所有长篇 Prompt 的强制输入层。

### P13 宏观修订

- 目标：先修故事，再修句子。

- 必需输入：全稿或分层摘要、故事承诺、结构计划、读者反馈。

- 主要输出：问题证据、影响范围、优先级、保留项、删改移补方案、修订顺序。

- Prompt 家族：发展性编辑、因果链审计、中段疲软、人物弧漂移、复线失联、高潮不足、结局兑现、结构重排。

- 约束：诊断与改写分开；先引用具体位置和症状，再给方案。

### P14 场景级与语言级修订

- 目标：在不擅自改剧情的前提下，提高场景功能、视角稳定、语言准确和人物声音。

- 必需输入：待改文本、允许改动范围、上下文、风格规则。

- 主要输出：问题清单、定向修订稿、变更说明。

- Prompt 家族：场景张力、对白潜台词、视角与距离、节奏、描写比例、信息重复、行文润色、扩写/压缩、去模板化表达。

- 约束：不把“更华丽”当作“更好”；扩写必须有新增叙事功能。

### P15 读者体验与质量验证

- 目标：模拟不同读者在阅读中的理解、期待、情绪和弃读风险。

- 必需输入：文本、目标读者、体裁承诺、评审维度。

- 主要输出：阅读轨迹、疑问时间线、期待/兑现、困惑点、可信度问题、严重度和修改建议。

- Prompt 家族：首章盲读、类型读者测试、贝塔读者模拟、悬念公平性、情感可信度、可读性、反套路过度诊断。

- 约束：读者模拟只能提供风险信号，不能伪装成真实市场数据。

### P16 标题、简介与对外包装

- 目标：准确传达作品承诺，不用包装掩盖内容不匹配。

- 必需输入：故事核心、读者定位、已完成内容、禁剧透边界。

- 主要输出：书名、章节名、简介、梗概、标签、投稿摘要等不同规格文本。

- Prompt 家族：书名发散与筛选、章节标题、无剧透简介、完整梗概、卖点提炼、包装一致性审计。

### P17 归档与复用

- 目标：把有效决策和 Prompt 运行结果沉淀为可迭代资产。

- 必需输入：采用结果、人工修改、失败样例、评分。

- 主要输出：版本记录、适用条件、反例、评测集、改进规则。

- Prompt 家族：运行复盘、差异归因、Prompt 修复、规则升级、资产去重。

## 五、现有能力覆盖与缺口

### 已有强覆盖

- 世界观、角色、故事核心、创作规则。

- 卷纲、章纲、细纲、场景与角色驱动剧情。

- 正文、续写、润色、扩写、表达去模板化。

- 章节记忆、事实、状态、物品、地点、时间线、关系、伏笔。

- 场景考证、历史咨询、文风学习和多类审校。

### 优先补齐

1.  灵感净化、聚类、概念筛选和创作简报。

2.  题材承诺、目标读者和长度模式的显式契约。

3.  结构模型选择器，而不是单一网文结构硬套。

4.  长篇复线编织、信息释放、高潮阶梯、卷级承诺账本和中段诊断。

5.  短篇独立架构。

6.  章节标题、首章盲读、结局兑现和发展性编辑。

7.  读者体验模拟、反馈去噪、Prompt 评测集和版本治理。

## 六、Prompt 资产类型

每个阶段至少可包含以下资产中的一种：

- 生成型：从已确认输入生成候选方案。

- 诊断型：只定位问题，不自动改写。

- 修订型：依据诊断和允许范围定向修改。

- 决策型：对多个方案按同一标准比较，保留作者选择权。

- 抽取型：从正文或材料提取结构化事实。

- 校验型：检查输出是否满足事实、格式和创作约束。

- 元 Prompt：根据任务规格生成或改造上述 Prompt。

同一文档不得仅通过改标题复制成多个资产。若输入、判断逻辑和输出字段相同，应合并为一个参数化 Prompt；若创作目标或验证标准不同，必须拆分。

## 七、首批建设顺序

### 第一批：决策地基

P00、P01、P02、P03、P08，以及 Prompt 质量规范。它们决定后续是否在正确的问题上工作。

### 第二批：长篇核心

P06、P07、P09-L、P10、P12、P13。重点是人物选择、剧情发动机、卷级持续性、连续性和宏观修订。

### 第三批：短篇与连载分支

P09-S、P09-R、首章/章节断点、短篇压缩和连载反馈去噪。

### 第四批：类型专项

推理线索矩阵、爱情关系节拍、成长/升级经济、历史考据、群像与多视角等。每个类型包都必须声明适用范围，不能回写为通用规则。

### 第五批：语言与发布

场景修订、对白、叙事距离、章节名、简介、梗概、贝塔读者模拟和资产复盘。

## 八、完成判据

一个阶段只有在以下条件同时满足时才算建成：

- 有清晰的目标、必需输入、可选输入和结构化输出。

- 已区分长篇、短篇、连载和类型差异。
