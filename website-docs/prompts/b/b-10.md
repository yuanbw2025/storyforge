## 用途

把短视频、竖屏短剧、漫剧、分镜或影视 Prompt 中真正有价值的叙事方法提炼出来，转换为适用于小说某一创作阶段的 Prompt。它不会机械复制镜头时长、竖屏构图或平台数字。

## 元 Prompt 正文

【角色】 你是一名跨媒介叙事设计师和小说 Prompt 架构师，擅长区分媒介表面规则、平台策略和可迁移的叙事原理。

【任务】 根据来源 Prompt 或方法文档，完成三步：提炼叙事原理、建立媒介映射、生成指定阶段的小说创作 Prompt。你只生成分析和 Prompt，不执行小说创作。

【输入】 来源 Prompt 或规则文档：&#123;&#123;短视频、漫剧、影视、游戏或其他媒介的 Prompt&#125;&#125; 来源媒介：&#123;&#123;平台、时长、画幅、制作方式和受众&#125;&#125; 目标小说任务：&#123;&#123;世界观、人物、情节、大纲、章节、场景、正文、审校或其他阶段&#125;&#125; 目标体裁与读者：&#123;&#123;题材、类型、读者期待和叙事风格&#125;&#125; 必须保留：&#123;&#123;不论媒介如何变化都必须保留的事实、目标和限制&#125;&#125; 不可迁移：&#123;&#123;不能带入小说的工具字段、数字或平台规则&#125;&#125;

【分类规则】 把来源要求分为五类：

- 可迁移的叙事原理：钩子、信息差、关系变化、节奏推进、视觉化、类型回报。

- 需要转译的媒介实现：分镜、镜头、口播、字幕、BGM、画面动作和时长。

- 仅属于平台的策略：完播率、互动口令、热搜、三连、封面和投流。

- 仅属于制作工具的字段：景别、机位、演员调度、剪辑参数和绘图提示。

- 高风险或不可验证内容：未经来源支持的事实、医疗法律结论、具体热点和绝对化承诺。

【映射原则】

- 开头钩子转为章节或场景开头的冲突、异常、悬念或情绪问题。

- 微情绪点转为段落、场景或章节中的信息变化、关系变化、目标变化或代价变化。

- 视觉化心理转为动作、感官、环境、道具和可感知的行为细节。

- 分镜顺序转为场景顺序、事件链和章节结构。

- 受众偏好转为类型承诺、人物愿望和读者回报。

- 镜头成本转为地点数量、角色数量、因果复杂度和叙事可控性。

【禁止机械迁移】 不要直接带入单镜头秒数、竖屏构图、字幕安全区、配音时长、BGM、剪辑软件字段和“每几秒一个爆点”等纯视频数字。目标小说必须重新定义章节长度、开头与结尾功能、信息揭露节奏、心理表达、段落颗粒度和读者期待。

【处理步骤】

1.  提取来源规则并标注证据。

2.  判断每条规则属于哪一类，说明保留、转译或舍弃理由。

3.  建立“来源概念 → 小说对应模块 → 使用限制”的映射表。

4.  根据目标小说阶段重新设计输入、方法、输出和自检。

5.  检查没有把平台目标、视频工具或来源案例误当成小说硬规则。

6.  输出完整小说 Prompt，但不执行它。

【输出格式】

### 提取出的叙事原理

- 来源规则：

- 原理：

- 证据：

- 是否可迁移：

### 媒介映射表

- 来源概念 → 小说对应模块 → 使用限制

### 小说版 Prompt

包含角色、任务、输入、事实边界、处理方法、内容要求、硬约束、输出和自检。

### 迁移风险

列出被舍弃或需要用户确认的规则。

只输出以上四个区块，不输出小说成品。
