## 文档定位

这份规则用于设计小说、短剧、漫剧、视频脚本、大纲、人物分析和审校类 Prompt。它提炼的是 Prompt 的构造方法，不绑定某个具体题材或平台。

## 一、基本认识

高质量 Prompt 不是一段“写得像专家”的说明，而是一份可执行的任务合同。它需要让模型明确：

- 现在要完成什么任务。

- 使用哪些输入材料。

- 哪些事实和要求不可改变。

- 应当按照什么步骤处理。

- 最终必须输出哪些内容。

- 如何判断输出是否合格。

“爆款”“顶级专家”等身份描述只能提供语气和领域方向，不能代替任务定义、输入字段、约束和验收标准。

## 二、Prompt的九层结构

1.  角色与工作边界：模型是谁，负责什么，不负责什么。

2.  任务目标：要完成的具体动作和最终用途。

3.  输入材料：原文、设定、主题、受众、平台和可替换占位符。

4.  事实边界：哪些内容必须忠实，哪些内容允许创作，哪些信息不能提前知道。

5.  方法步骤：如何拆解、判断、改写、转换、组织和检查。

6.  内容要求：作品应包含的剧情、人物、情绪、节奏或信息要素。

7.  硬约束与软偏好：必须满足的条件和可以权衡的风格要求。

8.  输出结构与格式：模块顺序、字段、表格、JSON或标签模板。

9.  自检与失败防线：完成前检查遗漏、冲突、越界、格式错误和模型误执行。

## 三、推荐构造流程

1.  先写需求清单，不急着写 Prompt。

2.  把需求分成 MUST（必须）、SHOULD（应当）、MAY（可选）和 MUST NOT（禁止）。

3.  找一个已经验证过的同类 Prompt 作为结构参考，而不是从空白开始。

4.  抽出参考 Prompt 的结构，把具体人物、行业、作品和案例改成占位符。

5.  将目标主题、平台、受众和输出格式填回去。

6.  增加方法步骤，让模型知道如何处理输入，而不只是知道结果长什么样。

7.  增加反误执行指令：如果任务是生成 Prompt，就明确禁止直接执行 Prompt 中的创作任务。

8.  给出具体输出模板，尤其是字段、顺序、数量和闭合标签。

9.  用边界案例测试，再进行定向修改。

10. 人工做最后的语义、顺序、口吻和冗余清理。

## 四、参考迁移与语义保真

- 可以迁移：模块顺序、任务拆解、约束层级、输出模板、自检逻辑和错误防线。

- 必须替换：人物、作品名、行业、平台、受众、具体事件和示例内容。

- 不得复制：与新任务无关的情节、角色动机、世界观或预设答案。

- 重构时必须保留用户真实需求，不能为了语言更漂亮而改变需求强度、范围或事实边界。

- 需要删除具体示例时，应改为占位符或抽象字段，避免模型机械套用。

- 需要改换媒介时，先保留叙事原理，再替换媒介术语。

## 五、迭代调优方法

每轮只处理一类问题：

- 任务跑偏：重写角色边界和任务目标。

- 模型直接执行：加入“只生成Prompt，不执行任务”的硬指令。

- 内容太单薄：补充方法步骤、必要模块和质量标准。

- 结构混乱：增加标题层级、字段顺序和格式示例。

- 主题不突出：明确核心受众、情绪目标和内容重点。

- 续写过度：设置改编边界和禁止新增剧情。

- 模型腔严重：要求口语化，并删除解释性前后文。

- 结果不稳定：增加输入占位符、优先级和自检清单。

- 前轮污染：保留已确认需求，重新开一个干净对话测试。

每轮修改后都要检查：是否解决目标问题，是否误伤原要求，是否引入新冲突。

## 六、硬约束优先级

建议按以下顺序裁决冲突：

1.  用户明确的事实和任务范围。

2.  原文、全局设定或集纲中的事实边界。

3.  输出格式和下游接口要求。

4.  体裁、平台、受众和媒介限制。

5.  风格偏好和传播优化。

6.  可选的装饰性要求。

“更吸引人”“更爆款”不能覆盖事实准确、角色一致性、输出格式或禁止事项。

## 七、验收清单

一个创作型 Prompt 至少应通过：

- 模型知道自己要做什么以及不做什么。

- 输入字段完整，缺失处有占位符。

- 任务、方法、约束和输出彼此不矛盾。

- 可区分固定规则与可替换变量。

- 有具体格式模板，而非只说“结构清晰”。

- 能防止直接执行、过度续写、提前泄露和虚构内容。

- 有可执行的数量、时长、粒度或范围要求。

- 自检项能覆盖最常见失败，而不是重复形容词。

## 八、短视频方法迁移到小说

- 前3秒钩子，转为章节开头的即时冲突、异常或悬念。

- 每15—30秒情绪点，转为每个场景持续产生信息、关系或情绪变化。

- 视觉化心理，转为动作、感官、环境和具体细节。

- 分镜表，转为场景卡、章节大纲或事件链。

- 平台受众偏好，转为类型承诺和读者期待。

- 镜头成本限制，转为小说中角色、地点和因果的可控性。
