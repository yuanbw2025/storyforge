# 小说创作 Prompt 方法论基础

:::




这套 Prompt 体系面向小说从灵感、立项、规划、写作到修订、包装的完整过程。它不要求作者服从某一种创作公式，而是把复杂的创作问题拆成可判断、可执行、可回改的任务，在保留作者选择权的前提下提高作品的完整性、连贯性和表达质量。

## 一、核心目标

小说创作不是一次性生成文本，而是不断提出问题、作出选择、观察后果并修订前提的过程。这套体系围绕五个目标设计：

1.  **把模糊灵感转化为明确的故事承诺**：回答作品写什么、为谁而写、提供什么独特体验。

2.  **建立能够持续运转的故事系统**：让人物欲望、世界条件、冲突压力和事件后果彼此咬合。

3.  **支持长篇中的持续发展**：管理跨章、跨卷的人物状态、事实变化、伏笔、关系和故事线。

4.  **把诊断与改写分开**：先确认问题，再限定修订范围，避免局部润色掩盖结构缺陷。

5.  **让作者始终拥有最终决定权**：AI 提供候选、分析和对照，不替作者悄悄改变设定、事实或创作方向。

## 二、八个方法支柱

### 故事承诺

每部作品都需要形成可识别的核心承诺，包括题材体验、主要矛盾、情绪基调、人物变化和结局方向。故事承诺不是宣传口号，而是后续世界、人物、结构和场景设计的共同判断标准。

### 因果链

情节不以“发生了很多事”为目标，而要说明：谁因为什么作出选择，这个选择造成什么结果，结果又如何改变下一步的条件。重要转折必须能从人物动机、已知信息和世界规则中找到依据。

### 人物动力

人物由欲望、恐惧、价值冲突、认知局限和压力下的选择构成。人物设定需要落实为可观察的行为、语言、关系反应和代价，而不是停留在性格标签与背景履历。

### 世界压力

世界观的价值在于制造条件与后果。地理、资源、技术、制度、阶层、文化和超自然规则需要影响人物能做什么、不能做什么、必须付出什么，以及不同群体为什么产生冲突。

### 信息与期待

悬念来自读者已知信息、未知问题、错误理解和未来期待之间的关系。信息释放既要考虑角色知道什么，也要考虑读者何时获得线索、如何形成判断，以及揭示后如何改变故事意义。

### 结构与节奏

结构用于安排承诺、升级、转折、高潮和兑现，节奏用于调节行动、反应、信息、关系与情绪的密度。结构模型是帮助诊断故事功能的工具，不是强制所有作品服从同一比例和节点。

### 连续性

长篇写作需要持续维护正文事实、人物状态、物品归属、地点、时间线、关系变化、伏笔和故事线。已确认的正文事实优先于旧计划；出现冲突时应提示作者复核，而不是自动覆盖。

### 分层修订

修订依次处理故事承诺、结构因果、人物弧、信息节奏、场景功能、视角、对白和语言。越上层的问题影响范围越大，因此先完成宏观诊断，再进入局部改写和句子润色。

## 三、从灵感到成稿的工作链

|              |                                        |                                  |
|--------------|----------------------------------------|----------------------------------|
| **创作阶段** | **核心问题**                           | **主要产物**                     |
| 灵感整理     | 哪些材料是真正有生命力的创作原子       | 灵感卡、主题聚类、组合方向       |
| 作品定位     | 作品向目标读者承诺什么体验             | 题材定位、读者承诺、差异化机制   |
| 故事核心     | 主角要什么，什么阻止他，失败意味着什么 | 故事前提、核心冲突、主题问题     |
| 世界与人物   | 什么条件迫使人物作出艰难选择           | 世界因果链、人物动力、关系网络   |
| 剧情发动机   | 冲突如何持续升级而不依赖巧合           | 升级阶梯、信息矩阵、复线关系     |
| 全书结构     | 重大变化如何逐步发生并汇向结局         | 全书骨架、卷级任务、高潮与兑现   |
| 章场规划     | 本章和每个场景具体改变什么             | 章节任务、场景卡、情绪节拍       |
| 正文写作     | 如何把计划转化为有张力的叙述           | 章节正文、对白、动作与叙述       |
| 连续性维护   | 本章产生了哪些新的事实和状态           | 章节记忆、状态差分、伏笔与时间线 |
| 宏观修订     | 故事层面最需要解决的是什么             | 诊断报告、修订优先级、重构路线   |
| 语言修订     | 如何在不改变事实的前提下改善表达       | 定向改写稿、变更说明             |
| 读者验证     | 读者可能在哪里困惑、失去期待或误判     | 阅读风险、理解轨迹、验证问题     |
| 包装交付     | 如何准确传达作品而不作虚假承诺         | 书名、简介、梗概、标签与投稿材料 |

各阶段不是不可逆的流水线。人物设计可能暴露故事前提的问题，场景写作可能发现世界规则不足，正文中的真实选择也可能要求修订后续大纲。允许返回上游，是保持作品生命力的重要机制。

## 四、长篇、短篇与连载分轨

### 长篇

长篇需要管理多阶段变化。每一卷既要完成局部任务，也要改变全书局势；中段不能只增加事件数量，而要改变人物策略、关系、资源、认知或冲突层级。复线必须有独立功能，并在关键节点发生碰撞、交换后果或共同汇向结局。

### 短篇

短篇强调集中与压缩。人物、背景、视角和支线都围绕一个核心变化服务；故事通常更晚进入关键情境，并通过意象、动作和有限信息承担多重功能。结尾应完成核心变化，同时留下与全文一致的余味。

### 连载

连载在故事结构之外增加阅读回报和生产管理。章节既要推进长期矛盾，也要提供阶段性获得；断点应来自尚未完成的行动、判断或后果，而不是任意截断。更新节奏、章节长度和回报密度都应由作品档案配置。

## 五、类型专项的启用方式

类型规则用于强化作品的主要阅读承诺，不应同时无差别加载。

- **推理**关注谜底、证据链、误导依据、读者可见信息和揭示公平性。

- **爱情**关注关系主轴、双向吸引、可信阻力、亲密变化和情感结局。

- **成长升级**关注能力变化、获得依据、资源成本、挑战阶梯和新限制。

- **历史**关注时代条件、制度约束、生活质感以及史实与虚构的边界。

- **科幻**关注新设定的约束、连锁推演和对制度及人物选择的影响。

- **奇幻**关注规则、代价、文化、神话结构和奇观产生的实际后果。

- **群像**关注视角不可替代性、角色权重、信息互补和汇流节点。

- **现实与文学向**关注日常压力、细微变化、人物复杂性和开放意义。

- **恐怖**关注威胁边界、未知管理、感官证据、升级方式和余悸。

- **喜剧**关注人物逻辑、反差、误会的信息公平、节奏和人物尊严。

多类型作品应先确定主要承诺，再选择少量辅助类型。辅助类型可以丰富体验，但不能覆盖主要类型的核心兑现。

## 六、高质量 Prompt 的基本结构

每个可直接使用的 Prompt 应至少包含：

1.  **任务目标**：本次只解决哪个创作问题。

2.  **输入契约**：需要哪些材料，缺少时如何处理。

3.  **事实优先级**：正文、作者决定、项目规则和类型惯例发生冲突时如何裁决。

4.  **执行步骤**：先分析什么，再比较什么，最后生成什么。

5.  **输出契约**：字段、顺序、格式、篇幅和可采纳单位。

6.  **边界约束**：禁止脑补、禁止越权改写、禁止把建议冒充事实。

7.  **自检标准**：检查遗漏、矛盾、因果、重复、格式和可执行性。

角色身份只是工作视角，不能代替任务逻辑。形容词数量也不能代替明确的输入、步骤、输出和测试。

## 七、使用原则

1.  通用原则、类型规则、连载策略和作者项目规则分层管理，作者项目规则优先。

2.  诊断结果先由作者确认，再进入修订或写回。

3.  同一轮不并行运行多个会修改同一事实目标的生成任务。

4.  参考材料只用于抽象机制，不把原有名称、专有设定和表达指纹带入成品。

5.  AI 生成的是候选方案，不是自动生效的标准答案。

6.  任何结构化结果在采纳前都应进行字段、引用、冲突和归属检查。

7.  Prompt 的升级以跨题材样例表现为依据，不能只凭单次输出的观感判断。

## 八、方法论价值

这套体系的价值不在于替作者找到唯一正确的故事，而在于让创作过程中的关键判断变得清晰：故事为何成立、人物为何行动、世界如何施压、冲突如何升级、信息如何释放、章节改变了什么、结局兑现了什么，以及修订应该先从哪里开始。

当这些问题可以被明确提出、分步处理并反复校验时，AI 才能成为作者稳定的创作辅助工具，而不是不可控的文本生成器。
