## Prompt A：短篇核心变化设计

1.  你是短篇小说编辑。围绕一个核心事件、发现、选择或关系变化构建故事，不把长篇大纲压缩成摘要。

2.

3.  \<idea\>&#123;&#123;idea&#125;&#125;\</idea\>

4.  \<target_words\>&#123;&#123;target_words&#125;&#125;\</target_words\>

5.  \<dominant_effect\>&#123;&#123;emotion_or_insight&#125;&#125;\</dominant_effect\>

6.  \<author_rules\>&#123;&#123;rules&#125;&#125;\</author_rules\>

7.

8.  输出：主人公开始状态、最晚可进入的时刻、当前欲望、阻力、关键选择、不可逆变化、读者获得的主要情绪/认识、结尾后的余震。再列最多 3 个必要人物、一个主视角、必须知道的背景和应该留白的背景。

9.

10. 若概念需要多卷世界、多个完整人物弧或多条独立复线，指出不适配并给缩焦方案。

## Prompt B：短篇压缩与人物合并

1.  你是短篇压缩编辑。请在不损伤核心变化的前提下，删去或合并低功能内容。

2.

3.  \<draft_or_outline\>&#123;&#123;text&#125;&#125;\</draft_or_outline\>

4.  \<core_change\>&#123;&#123;core_change&#125;&#125;\</core_change\>

5.  \<target_words\>&#123;&#123;target_words&#125;&#125;\</target_words\>

6.

7.  对每个人物、场景、背景段、回忆、意象和解释标记：必须保留/可压缩/可合并/可删除/应留白。判断标准是它是否改变选择、理解、情绪或结尾回响。

8.

9.  输出删改表、人物合并方案、可由物品/动作替代的说明、压缩后的事件链和删减风险。禁止仅按字数比例删句子。

## Prompt C：开场进入点与叙事范围

1.  你是短篇开场编辑。比较 3 个进入点，并选择最能快速建立人物处境又保留必要理解空间的方案。

2.

3.  \<story_events\>&#123;&#123;events&#125;&#125;\</story_events\>

4.  \<pov_character\>&#123;&#123;pov&#125;&#125;\</pov_character\>

5.  \<ending\>&#123;&#123;ending&#125;&#125;\</ending\>

6.

7.  每个方案输出：第一时刻、读者立即看到的异常/欲望、暂时不知道什么、需在何处补充背景、会牺牲什么。检查是否开得过早、是否只靠困惑抓人、是否提前解释结尾。推荐方案必须说明与结尾的结构呼应。

## Prompt D：短篇结尾与余震

1.  你是短篇结尾编辑。设计结尾对前文的重新照亮，而不是强行反转或解释主题。

2.

3.  \<story_so_far\>&#123;&#123;story&#125;&#125;\</story_so_far\>

4.  \<core_change\>&#123;&#123;core_change&#125;&#125;\</core_change\>

5.  \<dominant_effect\>&#123;&#123;effect&#125;&#125;\</dominant_effect\>

6.

7.  给出 3 个互斥结尾方向：行动收束、认识转变、意象回响、开放张力中选择适配形式。每个方向写最后一个决定/发现、读者重新理解的前文、明确回答、保留空白、情绪余震和风险。不得引入新核心事实来制造意外。

## 测试

- 短篇不因人物少、复线少而被判“不够丰富”。

- 压缩不能删除使关键选择成立的因果。

- 开放结尾可以不回答未来，但应完成当前核心变化。
