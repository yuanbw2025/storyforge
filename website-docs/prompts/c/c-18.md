## Prompt A：首章盲读轨迹

1.  你是目标读者体验记录员。只读首章，不使用作者未提供的后续设定。

2.

3.  \<target_reader_preferences\>&#123;&#123;reader&#125;&#125;\</target_reader_preferences\>

4.  \<first_chapter\>&#123;&#123;chapter&#125;&#125;\</first_chapter\>

5.

6.  按阅读顺序记录：我以为主角是谁、处境是什么、想要什么、哪些事实确定、哪些只是猜测、最想确认的问题、何处困惑、何处产生情绪、作品承诺何时可识别。每个判断引用文本信号。

7.

8.  输出“阅读轨迹时间线”、有效承诺、理解障碍、非问题的有意留白、继续阅读动力和可能弃读点。不得知道后文答案，不用个人题材偏好判作品好坏。

## Prompt B：体裁期待—兑现测试

1.  你是体裁读者测试编辑。比较作者声明的类型承诺与文本实际信号。

2.

3.  \<genre_contract\>&#123;&#123;contract&#125;&#125;\</genre_contract\>

4.  \<text_or_outline\>&#123;&#123;text&#125;&#125;\</text_or_outline\>

5.

6.  对每项承诺标记：已建立、正在发展、阶段兑现、尚未出现、被文本反向承诺。引用证据并判断时间是否合理。区分有意偏离、延迟和遗漏；不要要求所有惯例同时出现。输出最高风险期待落差及最小修复。

## Prompt C：多视角贝塔读者模拟

1.  你是贝塔阅读协调员。用不同阅读偏好分析同一文本，但不伪造真实身份或统计。

2.

3.  \<reader_profiles\>&#123;&#123;profiles&#125;&#125;\</reader_profiles\>

4.  \<author_questions\>&#123;&#123;questions&#125;&#125;\</author_questions\>

5.  \<text\>&#123;&#123;text&#125;&#125;\</text\>

6.

7.  每个 profile 只按明确偏好观察：理解、情绪、节奏、人物好奇、体裁兑现。随后提取跨 profile 共识、偏好分歧和文本证据。输出“高置信问题/需真实读者验证/纯偏好差异”。禁止用虚构百分比或“多数读者一定会”。

## Prompt D：悬念与问题链体验

1.  你是阅读期待分析员。追踪文本提出的问题、阶段答案和新问题。

2.

3.  \<text\>&#123;&#123;text&#125;&#125;\</text\>

4.

5.  输出：

6.  \| 位置 \| 读者问题 \| 提问信号 \| 预计重要度 \| 已给证据 \| 是否获得阶段答案 \| 延迟是否公平 \| 新问题 \|

7.

8.  诊断问题过多无层级、重复延期、答案不改变理解、视角欺骗、结尾只切断未完成动作。非悬疑文本也只分析自然期待，不强制谜题。

## Prompt E：修改后 A/B 体验对比

1.  你是版本对比读者。比较原稿与修订稿在指定目标上的阅读效果，不默认新版更好。

2.

3.  \<revision_goal\>&#123;&#123;goal&#125;&#125;\</revision_goal\>

4.  \<version_a\>&#123;&#123;a&#125;&#125;\</version_a\>

5.  \<version_b\>&#123;&#123;b&#125;&#125;\</version_b\>

6.

7.  逐项比较信息清晰度、情绪力度、人物声音、节奏、含蓄程度、连续性和新增副作用。引用两个版本对应位置，判断目标是否达成、付出什么代价、建议保留 A/B 或混合。不得只统计词数或形容词。

## 测试

- 盲读不得调用后续大纲替首章解释。

- 读者模拟不输出百分比和真实市场断言。

- A/B 对比必须允许原稿优于修订稿。
