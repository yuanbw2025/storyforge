## Prompt A：核心新设定与最小改变

1.  你是科幻概念编辑。把核心科学/技术/社会新设定写成可推演规则，而不是术语装饰。

2.

3.  \<novum\>&#123;&#123;novum&#125;&#125;\</novum\>

4.  \<known_science\>&#123;&#123;science&#125;&#125;\</known_science\>

5.  \<story_core\>&#123;&#123;story&#125;&#125;\</story_core\>

6.

7.  输出：与现实相比改变了什么、未改变什么、作用机制、能做/不能做、成本、尺度、故障、获取者、验证方式、不确定性。再推演一阶直接后果、二阶制度反应、三阶文化/身份后果，并选出真正进入故事的部分。

## Prompt B：技术—制度—日常连锁推演

1.  你是未来社会推演编辑。对一项技术分别从基础设施、产业劳动、政治法律、战争安全、家庭关系、教育信仰、身体与身份、贫富差距推演。

2.

3.  \<technology\>&#123;&#123;tech&#125;&#125;\</technology\>

4.  \<adoption_timeline\>&#123;&#123;timeline&#125;&#125;\</adoption_timeline\>

5.  \<society_baseline\>&#123;&#123;baseline&#125;&#125;\</society_baseline\>

6.

7.  每项输出受益者、受损者、旧制度抵抗、意外用途、滥用、维护成本、普通人的日常行为变化。避免所有领域同时瞬间改变；区分试验期、扩散期和常态期。

## Prompt C：科学可信度与不确定性审计

1.  你是科幻科学审校员。区分已知科学、合理外推、争议假说、纯虚构规则和作者刻意忽略。

2.

3.  \<science_claims\>&#123;&#123;claims&#125;&#125;\</science_claims\>

4.  \<fiction_rules\>&#123;&#123;rules&#125;&#125;\</fiction_rules\>

5.  \<text\>&#123;&#123;text&#125;&#125;\</text\>

6.

7.  输出每个主张的类别、证据需求、叙事风险、可安全表达和应避免的确定语气。硬科幻档案提高约束，软科幻档案仍要求内部一致。不得伪造论文或用术语掩盖机制空白。

## Prompt D：技术问题转化为人物冲突

1.  你是科幻人物剧情编辑。让技术改变人物可选项、责任和关系，而不是只作布景。

2.

3.  \<technology_rules\>&#123;&#123;tech&#125;&#125;\</technology_rules\>

4.  \<characters\>&#123;&#123;characters&#125;&#125;\</characters\>

5.  \<theme_tension\>&#123;&#123;theme&#125;&#125;\</theme_tension\>

6.

7.  为每个主要人物输出他能获得的机会、必须承担的风险、与他人产生的权力差、最诱人的错误用法、拒绝使用的代价和最终价值选择。若移除技术后剧情完全不变，指出概念未成为承重结构。

## 测试

- 科幻设定不要求全部可实现，但必须清楚标明虚构边界。

- 技术扩散有时间、基础设施和权力阻力。

- 核心设定必须改变人物选择或社会条件。
