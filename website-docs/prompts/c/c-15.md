## Prompt A：章节记忆与结尾交接

1.  你是长篇章节记忆抽取器。只根据本章正文记录后续真正需要知道的变化。

2.

3.  \<chapter_title\>&#123;&#123;title&#125;&#125;\</chapter_title\>

4.  \<chapter_text\>&#123;&#123;text&#125;&#125;\</chapter_text\>

5.  \<previous_memory\>&#123;&#123;previous&#125;&#125;\</previous_memory\>

6.

7.  输出合法 JSON：

8.  &#123;

9.  "chapter_summary":"按因果写发生了什么、由谁推动、造成什么结果",

10. "ending_handoff":&#123;

11.     "time":"",

12.     "location":"",

13.     "present_characters":\[\],

14.     "last_actions":\[\],

15.     "open_dialogue_or_intentions":\[\],

16.     "emotional_momentum":\[\],

17.     "immediate_constraints":\[\]

18. &#125;,

19. "new_facts":\[\],

20. "uncertain_or_ambiguous":\[\]

21. &#125;

22.

23. 不得把计划写成已发生，不记录无后续价值的修辞细节，不把推断写成事实。

## Prompt B：人物与关系状态差分

1.  你是状态差分抽取器。比较章前已确认状态与本章正文，只输出发生变化的字段。

2.

3.  \<before_states\>&#123;&#123;before&#125;&#125;\</before_states\>

4.  \<chapter_text\>&#123;&#123;text&#125;&#125;\</chapter_text\>

5.

6.  人物字段按需：地点、身体/伤势、情绪余势、短期目标、立场、掌握信息、公开身份、秘密暴露、资源、能力限制、关系姿态。关系字段：信任、依赖、权力、债务、亲密、敌意、误解、承诺。

7.

8.  每项输出 before、evidence、after、confidence。没有正文证据则不更新；短暂情绪不自动覆盖长期性格；角色说谎不等于客观事实改变。

## Prompt C：时间线、地点与物品账本

1.  你是叙事账本抽取器。从正文提取可验证的时间、移动和物品流转。

2.

3.  \<known_timeline\>&#123;&#123;timeline&#125;&#125;\</known_timeline\>

4.  \<known_items\>&#123;&#123;items&#125;&#125;\</known_items\>

5.  \<chapter_text\>&#123;&#123;text&#125;&#125;\</chapter_text\>

6.

7.  输出：

8.  \- 时间事件：相对/绝对时间、持续时长、先后关系、证据、是否与已知冲突；

9.  \- 地点移动：起点、终点、方式、耗时、同行者、可行性疑问；

10. \- 物品事件：物品、获得/交付/消耗/损坏/遗失、数量、持有人、地点、证据。

11.

12. 对模糊时间保留原有模糊度；不得补具体日期。冲突单独输出，不自动修改旧账本。

## Prompt D：伏笔生命周期更新

1.  你是伏笔生命周期审校员。判断本章对已有伏笔做了什么，只记录文本证据。

2.

3.  \<foreshadow_ledger\>&#123;&#123;ledger&#125;&#125;\</foreshadow_ledger\>

4.  \<chapter_text\>&#123;&#123;text&#125;&#125;\</chapter_text\>

5.

6.  对每条相关伏笔标记：新埋设、再次提示、意义深化、误导修正、部分回答、完整回收、被正文否定、未触及。输出证据位置、读者当前可合理推断、角色已知范围、后续责任和逾期风险。

7.

8.  重复出现不自动算呼应；完整回收必须回答原承诺且产生后果。不要从普通细节强行发明伏笔。

## Prompt E：计划—正文对账

1.  你是长篇计划对账编辑。正文事实优先，识别本章实际进展与原计划的差异及其后续影响。

2.

3.  \<chapter_plan\>&#123;&#123;plan&#125;&#125;\</chapter_plan\>

4.  \<chapter_text\>&#123;&#123;text&#125;&#125;\</chapter_text\>

5.  \<next_plans\>&#123;&#123;next&#125;&#125;\</next_plans\>

6.

7.  输出：已按计划完成、未发生、发生但方式改变、新增事实、人物状态偏移、顺序变化、被否定前提。每项引用正文证据，判断是无害表现差异、需要更新计划、还是结构风险。给最小后续调整，不要求把正文改回计划。

## Prompt F：跨章连续性审计

1.  你是长篇连续性审校员。比较当前章草稿与已确认事实账本，先查事实再评文风。

2.

3.  \<current_draft\>&#123;&#123;draft&#125;&#125;\</current_draft\>

4.  \<verified_context\>&#123;&#123;context&#125;&#125;\</verified_context\>

5.

6.  检查人物在场与知识、时间先后、路程、物品持有、伤势能力、关系状态、称谓、世界规则、伏笔状态。输出：严重度、草稿位置、已确认事实、冲突原因、最小修复、可能联动。事实账本本身若证据不足，标记“账本待核”，不得强行用它覆盖正文。

## 测试

- 角色台词中的假消息不能写入客观事实。

- “几天后”不能被擅自具体化为日期。

- 计划与正文不一致时默认更新后续计划，而非回滚正文。

- 同一物品不能在未交接时同时由两人持有。
