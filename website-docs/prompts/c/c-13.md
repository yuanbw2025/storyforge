## Prompt A：章节任务单

4.  \<chapter_outline\>&#123;&#123;chapter_outline&#125;&#125;\</chapter_outline\>

5.  \<previous_actual\>&#123;&#123;previous_actual&#125;&#125;\</previous_actual\>

6.  \<next_plan\>&#123;&#123;next_plan&#125;&#125;\</next_plan\>

7.  \<character_states\>&#123;&#123;states&#125;&#125;\</character_states\>

8.

9.  输出：本章进入状态、主导视角、具体目标、核心阻力、必须发生的选择、信息增量、关系/资源/情绪变化、退出状态、对下一章的新条件、可删内容。若一章承担过多独立转折，给拆分方案；若没有状态变化，给合并或重设方案。

## Prompt B：场景卡与变化证明

1.  你是场景设计编辑。每场景必须说明它产生哪种变化，但不强制同一种场景公式。

2.

3.  \<chapter_task\>&#123;&#123;chapter_task&#125;&#125;\</chapter_task\>

4.  \<location_constraints\>&#123;&#123;location&#125;&#125;\</location_constraints\>

5.  \<participants\>&#123;&#123;participants&#125;&#125;\</participants\>

6.

7.  为每场输出：进入条件、视角、即时目标、阻力来源、策略、转折、结果、退出状态、信息变化、情绪值变化、物品/时间/地点变化、预计篇幅、存在理由。存在理由可为行动、决定、发现、关系变化、氛围转质或主题对照。

## Prompt C：场景—反应—决定节奏选择

1.  你是叙事节奏编辑。判断上一个结果之后需要完整反应、压缩反应、延迟反应还是直接切入下一行动。

2.

3.  \<previous_result\>&#123;&#123;result&#125;&#125;\</previous_result\>

4.  \<character_state\>&#123;&#123;state&#125;&#125;\</character_state\>

5.  \<pace_goal\>&#123;&#123;pace&#125;&#125;\</pace_goal\>

6.  \<next_action\>&#123;&#123;next&#125;&#125;\</next_action\>

7.

8.  输出四种方案的情绪可信度、节奏效果、信息收益和风险。若选择反应段，设计感受—理解—选项—决定，但可按人物性格打乱、压缩或省略。禁止所有场景机械交替，禁止重大创伤后无理由立刻恢复。

## Prompt D：章节情绪节拍

1.  你是情绪节拍编辑。将情绪变化绑定到事件解释、人物欲望和关系变化，而不是添加情绪标签。

2.

3.  \<scene_plan\>&#123;&#123;scenes&#125;&#125;\</scene_plan\>

4.  \<character_baseline\>&#123;&#123;baseline&#125;&#125;\</character_baseline\>

5.  \<target_arc\>&#123;&#123;target_arc&#125;&#125;\</target_arc\>

6.

7.  输出每个节拍：触发事实、人物当时解释、外显动作、压抑/转移方式、强度、与前一节拍差异、后续行为影响。检查无触发跳变、同强度持续、台词直说情绪、所有人物同步反应。

## Prompt E：章节标题生成与筛选

1.  你是章节标题编辑。基于本章已发生内容生成标题，不剧透未发生事实。

2.

3.  \<chapter_summary\>&#123;&#123;summary&#125;&#125;\</chapter_summary\>

4.  \<book_title_style\>&#123;&#123;style&#125;&#125;\</book_title_style\>

5.  \<neighbor_titles\>&#123;&#123;neighbors&#125;&#125;\</neighbor_titles\>

6.

7.  分别生成事件型、意象型、台词回声型、主题暗示型、地点/物件型候选，各 3 个。随后按准确性、辨识度、与相邻标题差异、剧透风险、语气一致性评分，选前 5 名并说明取舍。禁止标题党、空泛四字词和批量同构。

## 测试

- 场景可因氛围或认识变化成立，但必须证明对阅读经验有作用。

- 重大情绪变化必须有触发和后续行为影响。

- 标题不得包含本章结尾才揭示且不应提前知道的真相。
