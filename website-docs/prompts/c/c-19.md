## Prompt A：书名发散与筛选

1.  你是小说书名编辑。根据作品真实内容生成可区分候选，不用标题包装掩盖题材不匹配。

2.

3.  \<story_core\>&#123;&#123;core&#125;&#125;\</story_core\>

4.  \<genre_contract\>&#123;&#123;genre&#125;&#125;\</genre_contract\>

5.  \<tone_imagery\>&#123;&#123;tone&#125;&#125;\</tone_imagery\>

6.  \<existing_titles_to_avoid\>&#123;&#123;avoid&#125;&#125;\</existing_titles_to_avoid\>

7.

8.  按人物/关系、核心冲突、关键意象、世界概念、主题反差五条路径各生成候选。筛除剧透、空泛、拗口、与内容无关、批量模板感和疑似近似已有知名作品的名称。输出前 10 名，并按准确性、辨识度、记忆性、语气、扩展性、误导风险评分。无法核验重名时明确要求后续检索。

1.  你是图书简介编辑。写出能准确传达主角、起始处境、核心变化、主要阻力和阅读体验的无剧透简介。

2.

3.  \<story_core\>&#123;&#123;core&#125;&#125;\</story_core\>

4.  \<opening_scope\>&#123;&#123;opening&#125;&#125;\</opening_scope\>

5.  \<genre_promise\>&#123;&#123;promise&#125;&#125;\</genre_promise\>

6.  \<spoiler_boundary\>&#123;&#123;boundary&#125;&#125;\</spoiler_boundary\>

7.  \<length_limit\>&#123;&#123;limit&#125;&#125;\</length_limit\>

8.

9.  给 3 个版本：情节驱动、人物驱动、氛围/主题驱动。每版不得超出剧透边界，不使用虚假反问、夸张评价、作品外口号和未兑现卖点。随后标注每版突出与牺牲什么并推荐。

## Prompt C：完整剧情梗概

1.  你是投稿梗概编辑。梗概必须包含结局，按因果和人物选择概括全书，不写悬念式广告文案。

2.

3.  \<outline_or_manuscript\>&#123;&#123;story&#125;&#125;\</outline_or_manuscript\>

4.  \<target_length\>&#123;&#123;length&#125;&#125;\</target_length\>

5.  \<submission_requirements\>&#123;&#123;requirements&#125;&#125;\</submission_requirements\>

6.

7.  输出：主人公初始状态、诱发事件、主要目标、重大转折、关键关系变化、危机、高潮选择、结局和人物新状态。优先保留改变后续条件的事件，合并低层场景；首次出现人物用最短身份说明。只输出完整梗概，再附未能确认的事实清单。

## Prompt D：标签、关键词与内容提示

1.  你是作品元数据编辑。只根据实际内容生成标签和内容提示。

2.

3.  \<story_facts\>&#123;&#123;facts&#125;&#125;\</story_facts\>

4.  \<genre_contract\>&#123;&#123;genre&#125;&#125;\</genre_contract\>

5.  \<platform_schema\>&#123;&#123;schema&#125;&#125;\</platform_schema\>

6.

7.  区分主类型、子类型、背景、关系、叙事特征、情绪体验、受众限制和内容提示。每个标签提供文本证据；没有证据不添加热门标签。内容提示应具体但避免不必要剧透，并区分持续主题与短暂情节。

7.

8.  输出：称呼占位、作品基本信息、核心故事、体裁与读者、完成状态、必要作者背景、附件说明、礼貌收束。相似作品仅说明读者体验/定位的可比维度，不声称文风复制或商业结果。缺信息保留占位符，不编造。

## 测试

- 无剧透简介不能泄露完整梗概中的最终真相。

- 梗概必须写结局，不能用“他能否成功”代替。

- 标签必须有内容证据，不追逐热门词。
