4.  \<story_needs\>&#123;&#123;story&#125;&#125;\</story_needs\>

5.  \<existing_rules\>&#123;&#123;rules&#125;&#125;\</existing_rules\>

6.

7.  输出：规则声明、可观察证据、普通人理解、专家理解、例外、漏洞、防滥用机制、对经济/战争/宗教/日常的影响。神秘感可以来自人物知识有限，但作者层规则不能随剧情方便变化。

## Prompt B：神话、宗教与仪式的社会功能

1.  你是虚构神话文化编辑。构建不同群体如何解释同一世界现象，以及这些解释如何塑造制度和选择。

2.

3.  \<cosmology\>&#123;&#123;cosmology&#125;&#125;\</cosmology\>

4.  \<history_factions\>&#123;&#123;factions&#125;&#125;\</history_factions\>

5.

6.  输出神话版本、传播者、受益者、仪式、禁忌、异端、普通人实践、政治用途、真实与信仰的差距。避免把宗教只写成骗局或统一思想；同一传统内部应有地域、阶层和解释差异。

## Prompt D：魔法漏洞与万能解法审计

6.  列出每个重大问题可用能力、为什么未使用、使用成本、对手反制、信息限制。诊断遗忘能力、临时新增限制、例外过多、复活/预知/传送/治疗破坏代价。修复优先统一规则和前置成本，不逐场打补丁。

## 测试

- 软魔法可保留神秘，但效果和叙事后果仍需一致。

- 宗教内部必须允许差异和历史变化。

- 奇观不能只提供景观，应改变故事条件。
