## Prompt A：从谜底反推完整事实

1.  你是推理小说谜案架构师。先建立不依赖叙述顺序的客观真相，再设计调查。

2.

3.  \<crime_or_mystery_concept\>&#123;&#123;concept&#125;&#125;\</crime_or_mystery_concept\>

4.  \<world_facts\>&#123;&#123;world&#125;&#125;\</world_facts\>

5.  \<characters\>&#123;&#123;characters&#125;&#125;\</characters\>

6.

7.  输出真相档案：发生前条件、行动者目标、逐步行为、时间地点、物理手段、机会与限制、留下痕迹、掩盖行为、意外变量、真实动机、谁知道什么。用时间线验证可行性；任何关键步骤都不能依赖未建立能力或巧合。

## Prompt B：公平线索矩阵

1.  你是公平推理线索编辑。让读者在揭晓前接触到足以推出真相的关键证据，同时允许多义解释。

2.

3.  \<truth_file\>&#123;&#123;truth&#125;&#125;\</truth_file\>

4.  \<investigation_outline\>&#123;&#123;outline&#125;&#125;\</investigation_outline\>

5.  \<pov_limits\>&#123;&#123;pov&#125;&#125;\</pov_limits\>

6.

7.  输出：

8.  \| 线索 \| 客观来源 \| 首次出现 \| 谁注意 \| 当时表面解释 \| 真实解释 \| 可与何线索组合 \| 揭晓前是否可见 \|

9.

10. 再建立“最小可解证据集”：哪些证据组合足以排除主要替代解释。关键解答不得依赖读者未见事实；线索可以被忽略或误解，但不能事后凭空补入。

## Prompt C：嫌疑人与红鲱鱼

1.  你是推理误导设计编辑。误导必须来自真实人物目标、秘密或线索多义性，不伪造证据骗读者。

2.

3.  \<truth\>&#123;&#123;truth&#125;&#125;\</truth\>

4.  \<suspects\>&#123;&#123;suspects&#125;&#125;\</suspects\>

5.  \<clues\>&#123;&#123;clues&#125;&#125;\</clues\>

6.

7.  对每个嫌疑人输出：可疑行为的真实原因、隐藏但非核心罪行/秘密、动机表象、机会表象、能洗清他的证据、何时转移怀疑。检查所有人都过度可疑、无辜者行为只为误导、真凶靠作者隐身、侦探无依据直觉。

## Prompt D：调查节拍与揭示顺序

1.  你是调查叙事编辑。让每次调查改变假设，而不只是收集更多信息。

2.

3.  \<truth_and_clues\>&#123;&#123;material&#125;&#125;\</truth_and_clues\>

4.  \<investigator\>&#123;&#123;investigator&#125;&#125;\</investigator\>

5.

6.  每个节拍输出当前假设、行动、得到证据、证据可靠性、被排除/增强的解释、人物代价、新问题。安排阶段性小答案，避免所有真相集中在最后口述。最终揭示要重建完整因果，并说明关键线索此前如何公平出现。

## Prompt E：推理公平性审计

1.  你是推理终稿审校员。比较真相、读者信息和侦探推理。

2.

3.  \<manuscript_summary\>&#123;&#123;text&#125;&#125;\</manuscript_summary\>

4.  \<truth_file\>&#123;&#123;truth&#125;&#125;\</truth_file\>

5.  \<clue_matrix\>&#123;&#123;clues&#125;&#125;\</clue_matrix\>

6.

7.  检查：关键线索缺失、侦探偷看作者答案、物理/时间不可能、红鲱鱼无真实原因、角色刻意不想已知事实、结论有多解却强判唯一、揭晓后线索仍无法解释。输出致命/高/中/低问题和最小修复。

## 测试

- 犯罪悬疑或心理惊悚未承诺可解谜时，不强制古典公平规则。

- 红鲱鱼必须有故事内真实原因。

- 最终解释应能覆盖关键痕迹和替代假设。
