先确认类型：若核心关系不是主线，使用“恋爱支线”模式；若结局不承诺情感上满足和乐观，标为爱情题材/悲剧爱情，不冒充类型爱情小说。

## Prompt A：双主角关系发动机

1.  你是爱情小说关系编辑。分别建立双方的独立人生目标、关系需求和防御策略。

2.

3.  \<characters\>&#123;&#123;characters&#125;&#125;\</characters\>

4.  \<world_pressure\>&#123;&#123;world&#125;&#125;\</world_pressure\>

5.  \<romance_mode\>&#123;&#123;mode&#125;&#125;\</romance_mode\>

6.

7.  对双方输出：外在目标、亲密需求、自我保护信念、被对方吸引的具体价值/行为、对对方的真实担忧、关系会威胁什么、可以提供什么、不能妥协什么。建立“靠近的理由”和“分开的理由”，两者都必须持续变化。

## Prompt B：关系节拍与新平衡

1.  你是关系弧编辑。用互动结果推动关系，而不是按固定亲吻/误会节点填表。

2.

3.  \<relationship_engine\>&#123;&#123;engine&#125;&#125;\</relationship_engine\>

4.  \<external_plot\>&#123;&#123;plot&#125;&#125;\</external_plot\>

5.  \<ending_contract\>&#123;&#123;ending&#125;&#125;\</ending_contract\>

6.

7.  每阶段输出：旧平衡、共同/冲突目标、一次暴露真实自我的行动、对方的新理解、信任/权力/依赖变化、亲密升级或撤退、外部剧情带来的新条件。身体亲密、情感坦白、承诺和公开关系分别追踪，不能互相替代。

## Prompt C：可信阻力与冲突修复

1.  你是爱情冲突编辑。诊断阻力是否来自价值、目标、处境、创伤防御或信息不对称，而不是可一句解释消除的误会。

2.

3.  \<relationship_outline\>&#123;&#123;outline&#125;&#125;\</relationship_outline\>

4.  \<characters_knowledge\>&#123;&#123;knowledge&#125;&#125;\</characters_knowledge\>

5.

6.  输出每个冲突：双方合理立场、不能立刻说开的原因、错误策略、短期收益、伤害、修复所需行动、信任恢复证据。若冲突只能靠角色拒绝沟通维持，给重构方案。道歉不能自动清零后果，修复必须改变行为或承担代价。

## Prompt D：亲密场景的同意、脆弱与后果

1.  你是关系亲密场景编辑。根据作品尺度设计双方都具主体性的亲密互动。

2.

3.  \<relationship_state\>&#123;&#123;state&#125;&#125;\</relationship_state\>

4.  \<scene_goal\>&#123;&#123;goal&#125;&#125;\</scene_goal\>

5.  \<content_boundary\>&#123;&#123;boundary&#125;&#125;\</content_boundary\>

6.

7.  输出场景前关系条件、双方目的、明确/持续的同意信号、犹豫和边界、暴露的脆弱、权力差处理、场景后关系新状态。禁止把沉默默认同意、把嫉妒控制自动浪漫化、把身体亲密当作所有冲突的解决。

## Prompt E：关系高潮与乐观结局兑现

1.  你是爱情类型结局编辑。检查双方是否通过行动证明能建立新的关系模式。

2.

3.  \<relationship_arc\>&#123;&#123;arc&#125;&#125;\</relationship_arc\>

4.  \<ending\>&#123;&#123;ending&#125;&#125;\</ending\>

5.

6.  输出最终关系障碍、双方各自必须做出的选择、需要放弃的防御、承担的现实代价、彼此承诺的可执行内容、外部问题的处理和结局后的可持续新平衡。类型爱情模式需情感满足与希望；悲剧/开放模式则明确其不同承诺。

## 测试

- 只有恋爱支线时不得让关系吞掉主线。

- 误会若可立即解释，必须有可信阻止机制或重构。

- 结局要证明关系模式改变，而不只写“在一起”。
