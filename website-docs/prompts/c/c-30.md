7.  输出：人物认真追求的目标、错误假设/身份落差/规则冲突、维持体面的策略、策略如何让局面更糟、可升级变量、最终情感后果。笑点应来自人物逻辑与局面摩擦，不让人物只为笑点降智。

## Prompt B：误会喜剧的公平信息

1.  你是误会结构编辑。建立谁知道什么、说了什么、合理听成什么，以及为何不能立刻澄清。

2.

3.  \<misunderstanding\>&#123;&#123;material&#125;&#125;\</misunderstanding\>

4.  \<knowledge_map\>&#123;&#123;knowledge&#125;&#125;\</knowledge_map\>

5.

6.  输出误会链：真实事实、人物解释、语言/证据来源、维持原因、升级行为、旁观者作用、澄清触发、澄清后的新问题。若一句正常追问即可解决且无可信阻力，重构误会。

## Prompt C：喜剧节奏与回调

1.  你是喜剧节奏编辑。设计建立—预期—偏转—后果—回调，不强制每段都有笑点。

2.

3.  \<scene_or_outline\>&#123;&#123;text&#125;&#125;\</scene_or_outline\>

4.

5.  标记铺垫信息、读者预期、偏转点、人物反应、后续代价和可回调元素。检查解释笑点、连续同构、只有台词机灵、回调无新含义。给删减和停顿建议，保留情绪与剧情的安静空间。

## Prompt D：喜剧边界与人物尊严审计

1.  你是喜剧伦理与语气审校员。检查笑点在嘲笑谁、依赖什么权力差、人物是否有主体性。

2.

3.  \<text\>&#123;&#123;text&#125;&#125;\</text\>

4.  \<tone_contract\>&#123;&#123;tone&#125;&#125;\</tone_contract\>

5.

6.  识别把创伤、身份、身体、贫困或弱势处境当单一笑料，识别所有代价只落在同一角色。区分人物互相冒犯与作品认同冒犯。给替代机制：自我暴露、权力反转、规则荒谬、认知落差、角色反击。保持作者选择，但明确读者风险。

## 测试

- 人物应按自身逻辑犯错，不为梗突然降智。

- 回调要增加新语境，不只重复旧句。

- 喜剧不要求取消真实后果和情感。
