## 适用阶段

用于已有世界观、角色设定或同人参考资料，需要直接生成适配目标短视频平台的2—3分钟治愈系竖屏漫剧分镜脚本时。

## 可直接使用的提示词

【角色与任务】

请以资深动画编剧和短视频漫剧策划专家的身份，根据参考信息创作一集适配目标短视频平台平台的治愈系竖屏漫剧剧本。

如果输入来自既有作品或角色，请尊重参考资料中已经明确的世界观、人物性格、能力边界和关系状态。可以创作新的日常事件，但不得让角色做出明显违背其核心性格的行为，也不得凭空增加与参考设定冲突的重要背景。

【媒介规格】

- 平台：&#123;&#123;target_platform，默认通用竖屏短视频平台&#125;&#125;。

- 画幅：9:16竖屏。

- 形式：短视频漫剧，可采用静态立绘、分层背景、轻动画、推拉摇移和局部特写。

- 单集时长：2—3分钟。

- 台词总量：建议15—25句，旁白也计入台词量。

- 单镜头时长：通常3—5秒；关键情绪停顿可以略长，但不能形成无信息变化的长镜头。

- 对白风格：口语化、生活化、短句优先，避免书面语、解释性独白和连续大段对话。

- 字幕适配：一句台词尽量能在竖屏字幕安全区内清楚读完，避免一屏堆叠过多文字。 【叙事节奏】

1.  前3秒

    - 必须抛出一个清晰的画面钩子或情绪钩子。

    - 钩子可以是异常可爱的物件、反差动作、让人心软的一句话或一个尚未解释的小困境。

    - 治愈系钩子不依赖吵架、危险或夸张反转。

2.  前10秒

    - 交代人物关系、当前地点和本集的小目标。

    - 让观众迅速明白“谁在陪伴谁”“他们准备做什么”。

3.  中段

    - 每25—35秒设置一个微情绪点，例如被照顾、被理解、笨拙帮忙、小误会化开、生活细节带来的惊喜。

    - 微情绪点之间要有清晰因果，不要堆叠互不相关的可爱片段。

    - 本集只解决一个小而具体的问题，避免塞入过多设定或支线。

4.  结尾

    - 完成主要情绪落点，让观众得到安定、被陪伴或重新有力气的感受。

    - 可以留下轻柔的下集钩子，但不能破坏本集已经形成的治愈余韵。 【治愈系创作原则】

- 核心是“情绪避风港”，不是爽点密集、强冲突或强行煽情。

- 通过做饭、修理、缝补、等雨、分享食物、照顾小动物、共同完成小事等日常行动承载情感。

- 角色不必直接说“我关心你”，应尽量用递东西、留灯、调整衣角、分出最后一口食物等可见动作表达。

- 允许安静和留白，但每个留白都要有画面信息或情绪变化。

- 幽默应来自性格反差和生活小失误，不嘲弄弱者，不用冒犯性笑料。

- 不制造无必要的误会、争吵、反派或危险来推动剧情。

- 结尾的情绪价值要具体，例如“累了也有人给你留一盏灯”，不要只写“温暖治愈”。 【竖屏分镜原则】

- 重要人物、手部动作和关键小道具优先放在竖屏中心区域。

- 使用上近下远、前景遮挡、纵向空间和高低差强化9:16构图。

- 多使用脸部、手部、食物、叶片、雨滴、灯光等局部特写承载情绪。

- 每个镜头描述需写明景别、人物位置、关键动作和竖屏构图重点。

- 对话场景通过正反打、双人上下构图、表情特写和道具切镜避免画面停滞。

- 考虑漫剧制作成本：合理复用背景和角色立绘，用推近、轻摇、眨眼、衣摆、蒸汽、光影等局部运动制造生命感。

- 不要设计必须依赖复杂长镜头、大规模群演或高成本连续动作才能成立的场面。 【生成要求】

1.  故事必须在参考世界观内成立。

2.  角色说话和行动必须符合各自性格、能力和关系阶段。

3.  单集应有明确的小目标、轻阻碍、陪伴过程和情绪落点。

4.  台词数量控制在15—25句；音效和纯动作不计入台词。

5.  分镜顺序必须能支撑2—3分钟时长，镜头间因果和空间位置清楚。

6.  不输出创作分析、设定复述或与剧本无关的说明。 【输出前自检】

> 输出前逐项自检；只输出规定结果，不附检查过程：

7.  前3秒是否有明确钩子？

8.  前10秒是否建立角色关系、场景和小目标？

9.  是否每25—35秒至少有一个自然的微情绪点？

10. 台词是否为15—25句，且口语化、易读、无长篇解释？

11. 每个镜头是否包含可画、可制作的竖屏构图和动作？

12. 是否存在超过5秒却没有画面或情绪变化的长镜头？

13. 角色行为是否符合参考设定，没有越过能力和关系边界？

14. 是否通过具体行动体现陪伴，而非只靠台词宣告治愈？

15. 结尾是否留下具体情绪价值和适度余韵？

16. 输出结构是否完整，分镜序号是否连续？ 【输出格式】

> 严格按以下顺序输出，不要添加额外分析。

17. 故事标题 标题：&#123;简洁、有画面感、与本集小事件相关的标题&#125;

18. 分镜脚本

|              |                                            |                                              |                                |
|--------------|--------------------------------------------|----------------------------------------------|--------------------------------|
| **镜头序号** | **画面描述（含竖屏构图说明）**             | **台词/音效**                                | **情绪/节奏标注**              |
| 1            | &#123;景别、人物位置、动作、关键物件及9:16构图&#125; | &#123;角色台词、旁白或音效；无台词时写音效或“无”&#125; | &#123;3秒钩子/轻松/停顿/微情绪点等&#125; |

1.  本集核心情绪价值 &#123;用1—2句话写清观众在本集结束时获得的具体情绪感受，以及这种感受由哪个行动或关系变化承载。&#125;
