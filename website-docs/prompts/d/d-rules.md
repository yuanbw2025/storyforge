## 文档定位

本方法论聚焦漫剧 Prompt 的分阶段设计、事实忠实、视听可执行性、质量审查和工作流衔接。核心目标是建立一套能生成、能复核、能迭代、能接入创作流程的 Prompt 工程方法。

## 一、最重要的结论

1.  剧本与分镜必须分阶段。 推荐链路是：原始故事或小说 → 关键情节与改编决策 → 标准漫剧剧本 → 分镜生产包 → 生图、视频、配音和剪辑。把编剧、分镜、导演、绘图提示词和审校同时塞进一条 Prompt，会显著增加角色错配、时长失真和格式遗漏。

2.  钩子不能凌驾于原文。 开场和结尾钩子应从原素材的危险、身份差、未完成动作、信息揭露或情绪断裂中提炼，不能为了“更抓人”另造事实、提前揭露或续写低质量剧情。

3.  快节奏不等于删除因果。压缩时最常见的风险是删掉必要铺垫，导致台词突兀、角色突然知道不该知道的信息、前后动作无法衔接。应删除重复表达，保留理解后续行为所必需的原因。

4.  视觉化不等于堆镜头术语。有效视觉化是把抽象心理转成动作、微表情、空间、道具和结果；无效视觉化是在单镜内塞入互相冲突的景别变化、使用无法呈现的抽象词，或给极短镜头安排多句台词和复合动作。

5.  Prompt 必须自带验证闸门。常见薄弱点是视觉化和输出格式写得很细，但明确自检和角色一致性要求不足；高风险错误通常集中在时长、角色、台词归属、素材忠实和逻辑连续性。

## 二、常见失败模式

需要重点防范的失败包括：

- 画面或动作无法在给定镜头内完成。

- 节奏、钩子与信息密度不匹配。

- 输出字段缺失或指令遵循不完整。

- 台词、旁白和说话人归属错误。

- 素材事实被遗漏、改写或无依据扩展。

- 角色信息、外形、状态和关系不一致。

- 因果、时序、空间或上下文发生断裂。

- 语言生硬、含义不准确或不符合角色。

- 单镜时长、时间轴或总时长计算错误。

- 忽略发行渠道合规和制作限制。

质量检查顺序应为：事实与说话人 → 因果与连续性 → 时长和镜头负载 → 角色与视觉一致性 → 节奏和钩子 → 格式与语言 → 合规与制作。不能先判断刺激程度，再补事实基础。

## 三、标准五阶段工作流

### 阶段1：素材证据登记

提取人物、身份、关系、时间线、地点、道具、已知信息、原台词、关键动作、因果链、伏笔和输入终点。所有后续改动都应能回指素材证据。

### 阶段2：改编决策与情节压缩

把内容标记为保留、压缩、合并、重排、视觉化、允许补全或禁止新增。只允许补全镜头可理解所需的动作和过渡，不允许补写输入终点之后的新剧情。

### 阶段3：标准漫剧剧本

按分集、分场景输出场景题头、出场人物、画面动作、台词、必要的 OS/VO 和声音提示。此阶段解决剧情、人物、情绪和场景，不生成逐镜 AI 绘图 Prompt。

### 阶段4：分镜生产包

基于已经确认的剧本拆分镜头，建立角色与场景连续性表，分配时长、景别、视角、构图、动作、台词、音效、首尾帧和每镜差异化生图提示词。

### 阶段5：独立审查与定向修订

先审查再修订。审查输出事实错误、角色错配、时长错误、镜头负载、连续性、钩子和格式问题；修订阶段只修诊断指出的问题。

## 四、稳定的质量修订规则

- 降低解释成本。 短时长内容优先使用一眼能理解的机制，不为复杂世界观额外背负大量说明。

- 让冲突服务于题材和受众。 甜宠的冲突要推动关系与成长，悬疑的冲突要推动认知更新，爽剧的冲突要建立压抑与释放，而不是只增加戏剧动作。

- 人物弧光要有行为链。起点、触发、选择、代价和终点必须有对应情节，不能用一句抽象结论代替。

- 重排集数而非平均切片。 合并弱集、扩展高潮与回报，让每集有独立功能和向下游传递的状态。

- 抽象文学语言改成表演指令。把比喻性情绪拆成可见的身体姿态、视线、表情、动作和结果。

- 台词口语化但不能失去逻辑。 白话转译要保留观点和人物身份；不能为了短句删掉对话成立所需的前文。

- 现实逻辑优先。 成年人的行为、职业流程、空间距离、信息来源和道具使用必须合理，不能用幼稚动作或夸张桥段代替冲突。

- 输出格式属于内容质量。 缺字段、错说话人、错误 VO/OS、错误总时长都不是排版小问题，而是生产事故。

## 五、时长与镜头负载规则

1.  台词时间 默认中文清晰配音按每秒3.5—4个汉字估算。情绪爆发、哭腔、停顿较多时按每秒3—3.5个汉字估算。台词时间应包含必要停顿，不能只数文字。

2.  动作时间

- 单一表情或视线变化：约1—2秒。

- 单一简单动作：约2—3秒。

- 有起点和结果的复合动作：约4—6秒。

- 走位、互动、取放道具或多人反应：通常需要5秒以上，必要时拆镜。

1.  单镜时长 若台词与动作可以同时发生，单镜时长不得小于二者较大值；若动作必须先后完成，时长应相加。转场另留0.5—1秒。任何镜头若无法在分配秒数内完成，就必须拆镜、删减或延长，不能伪造合计时间。

2.  累计校验 每镜必须给出开始时间、结束时间和时长。先逐行求和，再核对总时长；总时长与目标不符时，修改镜头内容或分配，不得只改“预估总时长”文字。

## 六、角色与 AIGC 连续性规则

- 每个角色建立固定锚点：年龄段、体型、脸部特征、发型、服装基线、标志物和色彩。

- 每场记录可变状态：伤势、污渍、湿度、道具持有、情绪、站位和朝向。

- 同一连续场景保持光线、天气、时间、空间布局和屏幕方向一致。

- 一镜只承担一个主要视觉任务；景别大幅变化、人物位置变化或动作阶段变化时拆镜。

- 生图 Prompt 使用“全局视觉常量 + 本镜差异变量”，避免每镜复制完全相同的关键词，也避免风格漂移。

- 角色首次出现时写完整外观；后续镜头引用角色 ID 与本镜状态变化，不重复生成一套新人物。

## 七、反向 Prompt 构建原则

1.  先判断样本本身是否值得学习，不能从有明显错误的输出反向提炼规则。

2.  把特征分成：直接观察、合理推断、样本偶然选择、疑似错误、无法确定。

3.  每条反向规则都附样本证据和置信度。

4.  样本中没有出现某种手法，不等于必须禁止。 只有明确规范、重复稳定的回避模式或对照证据，才能转成负面约束。

5.  单个样本的集数、场次数、角色数和台词长度不能直接泛化；项目特定数字应改成变量。

6.  反向 Prompt 要保留结构与能力，不把样本具体剧情当成通用规则。

7.  必须进行复现测试：用同类但未见过的输入生成，再比较结构、风格、事实、节奏和格式，而不是要求逐字复刻。

8.  人工审核是正式步骤，不是可选补丁。

## 八、Prompt 验收清单

- 输入材料与占位符完整，固定事实和可变参数分开。

- 任务只承担一个阶段，不同时写剧本、分镜、审校和修订。

- 允许压缩、重排和补全的边界清楚。

- 角色信息边界和台词归属可追踪。

- 钩子来自输入剧情，没有篡改事实或越过输入终点。

- 时长可逐镜计算，动作和台词负载与秒数匹配。

- 输出字段可被下游直接读取，不依赖解释性前言。

- 有独立自检，并规定失败时返回诊断而不是伪造合格结果。

- 少样本示例只展示格式和关键转换，不用大段具体答案污染生成。

- 高风险事实、版权、平台合规和 AIGC 制作限制有单独检查。

## 九、项目集成建议

每份 Prompt 资产建议记录：Prompt ID、版本、创作阶段、读取输入、写出字段、固定事实、可变参数、禁止事项、输出 schema、验收规则、失败分类、测试用例和版本变更记录。这样可以把 Prompt 作为可维护的工作流组件，而不是一段无法追踪的长文本。
