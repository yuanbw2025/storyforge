# 封存、制作、发布与存档

## 三阶段如何衔接

| 阶段 | 你做什么 | 得到什么 |
| --- | --- | --- |
| S1 世界封存 | 确认世界内容与范围 | 可引用的确定世界版本 |
| S2 产品定向 | 在跑团、聊天、小镇等产品中配置目标、来源和规则 | 明确的制作方案 |
| S3 产品执行 | 明确开始制作、检查产物、发布并运行 | 产品版本与独立存档 |

部分产品允许先保存没有世界来源的 S2 草稿。正式制作前仍需满足来源和产品检查，保存草稿不等于正式开始。

独立长篇、短篇和小说改编不要求先走世界封存；它们有自己的创作流程。

## “发布”是否公开上网

产品中的发布通常表示保留不可变的本地版本，供导出或游玩使用。它不等于自动上传公共网站、开通社区账户或上线商业服务。

文件分享时另外核对署名、许可和素材权利。

## 修改后为什么旧版没变

冻结版本保留当时内容，后续修订形成新版本。这样旧导出、旧游戏和旧存档仍可追溯到当时依据。

世界版本、产品版本和存档是三个不同对象。世界升级不会自动升级产品，产品新版本也不应被理解为自动覆盖已有存档。

## 给作者的检查顺序

发布前检查来源版本、候选采纳、严重问题和素材完整性。发布后核对导出或游玩使用的是哪个版本，再保留[完整备份](/guides/backup-restore)。
