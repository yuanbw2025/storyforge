# 项目、作品与世界

| 名称 | 可以怎样理解 | 不应混淆为 |
| --- | --- | --- |
| 项目 / 工作区（Workspace） | 本地组织与管理的容器 | 某部小说的标题、正文和所有权本身 |
| 作品（Work） | 一部长篇、短篇、剧本、漫画或互动产品 | 所有产品共用的一份可随意覆盖的内容 |
| 世界（World） | 设定、人物、规则与关系等语义资料 | 图片素材、游戏进度或在线房间 |
| 世界版本 | 作者封存的确定世界内容 | 随草稿自动改变的实时引用 |

## 写小说不需要先造独立世界

长篇和短篇可以直接开始，作品内部的设定足以服务创作。需要让这些内容供其他产品引用时，再由作者显式派生世界。

派生保存来源，不改变原作归属。原作与世界的后续编辑分别进行。

## 改编不是覆盖原文

剧本、漫画与漫剧素材保留本次改编的来源范围和版本，产物属于自己的作品。修改剧本场景不会修改小说正文。

## 游戏结果不会自动变成公共设定

跑团、角色聊天、小镇和文字游戏有自己的会话、角色关系和事件。它们引用冻结世界，但玩家的选择只影响相应作品或存档。

如果要改变共享世界，需要作者在世界编辑中明确处理，不能把一次游玩的结果当作所有作品共同接受的事实。
