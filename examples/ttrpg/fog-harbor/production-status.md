核验日期：2026-09-07。社区试玩版 `1.0.0-preview.1` 使用真实生产的 Build #4 / ProductRelease #4；完整内容与规则在 Build #1 已跑通，后续发布包仅修订美术。播放器自审迭代保留同一个不可变游戏包，改进交接隐私和存档恢复；验证记录见下文。

## 体验与范围

启动项目后打开 `/storyforge/play`，点击《雾港：最后一盏灯》的“开始一场新冒险”，配置本人可用的模型 API、选择角色并接受开团约定。游戏包随仓库提供，无需玩家制作世界或导入测试夹具。

- 7 个场景、5 名角色（3 名玩家角色与 2 名 NPC）、6 条线索、2 个共同任务、3 种结局。
- 单人加 2 名 AI 同伴，或同一设备上多人交接；AI 担任 KP。
- 原创 StoryForge 叙事 2d6，规则内核执行骰点、数值和资源变化，AI 提交候选。
- 个人秘密、私密指引、行动前询问、自动保存、检查点分支恢复和可见失败续接。
- 随包提供 1 张场景图、沈砚立绘；目录封面单独随静态站点提供。其他角色使用姓名标记。

当前定位是可游玩的社区预览，不是公共联网多人服务或商业运营完成声明。完整自由语义裁定、独立分队主持及长期叙事质量仍有差距。

## API 问题结论

用户当前 Agnes 配置有效，真实文本、图像和运行请求均已成功。历史 401 不能代表当前 Key 无效。

旧连接测试把含 reasoning、正文为空的 HTTP 200 误认为成功；现已要求实际正文，并为 Agnes 的极短测试保留合理输出预算。正式任务的主要失败来自模型输出不合法、供应商图片参数不支持以及项目适配问题。已修复参数、上下文来源、格式兼容和失败恢复；不会用自动重发掩盖认证、预算或未知结果。

模型仍可能叙述重复、附加不可靠细节或违反格式。系统可确定性限制权限、数值、场景、线索和发布内容，但不承诺自然语言的语义绝对正确。旁白与调查手记矛盾时，以已核实的手记和规则回执为准。

## 播放器自审迭代 · 2026-09-07

本轮修复真实入口的恢复与显示问题，没有改动上述分发包、世界来源、规则或 AI 调用协议。

- **目录故障挡住本地存档**：原先两个读取放在同一个 `Promise.all`，任一失败都不显示已有存档。现在独立加载并各自提供重试；通过 Dexie 订阅同步其他标签页新增或更新的存档。
- **恢复时旧桌面与错误状态残留**：路由按 session 重新挂载，丢弃过期异步读取；检查点错误只显示在恢复区域，保留可用桌面。读取期间禁止操作旧桌面，主持期间禁用恢复，重复点击只创建一个分支。
- **同机多人误看私人信息**：原先刷新后默认显示第一位真人的桌面，私人手记可能暴露。现在刷新、恢复和切换待回应玩家时遮住整块记录与手记，确认后才显示本人视图；另有手动“遮住桌面”。开团期间锁定角色与模式，运行视图仅允许已分配给真人的角色读取私人资料。这是同机交接防误看，不是账户认证或服务端秘密隔离。
- **手机标题冗长**：将以 ` · ` 分隔的存档附注放到次要位置，完整原名仍保留；恢复次数不会继续拉长主标题。

自动化证据：`R-TTRPG4H-session-route-recovery` 覆盖慢请求乱序、无效地址恢复、坏检查点和重复恢复；`ttrpg-community-recovery.spec.ts` 覆盖目录 503、跨标签存档列表、真实分发包的同机交接/刷新/分支恢复，以及单人选择非默认角色。浏览器中的模型响应为隔离测试响应，不是新一轮真实 provider 试玩；上文真实制作与完整游玩证据仍来自首版。
