# 01 · 旗舰交付与产品结果契约

> 层级：L2 · 版本：1.0.0 · 生效：2026-09-06
> 性质：目标产品契约；不得据此宣称尚未通过验收的能力已经完成。

## 1. 用户最终得到什么

作者从冻结世界或导入的大纲/成稿开始，经可观察的 AI 专业制作流程，得到一个有限篇幅、状态驱动、可完整通关的文字冒险。玩家能阅读正文与对白，查看角色、属性、技能、资源、装备、背包、任务和旅程记录，通过选择或被合法化的自由输入采取行动，承担可理解的代价，并在不同状态与行动链下进入有完整收束的不同结局。

首个旗舰样例目标约 60 分钟，采用一个易理解但不向通用 schema 注入专用名词的原创题材。它必须体现 StoryForge 的核心价值：世界版本可追溯、AI 大规模生产可治理、作者可逐层控制、规则状态确定、内容与插图统一装配、发布后 AI 不可用仍可完整游玩。

## 2. 三种完成级别

| 等级 | 可做什么 | 不得声称什么 |
|---|---|---|
| 工程夹具 | 验证 schema、编译、事件、存档或 UI 的局部路径 | 内容完整、达到目标时长、可向社区推荐 |
| 可试玩 Build | 从开局走到至少一个结局，允许作者审查和迭代 | 已发布、所有路线合格、具有推荐质量 |
| 社区推荐候选 | 通过结构、内容、媒资、性能、恢复和完整人类试玩验收，可导出可分享 | 已经对外发布；对外发布需要作者另行确认 |

只有作者显式采纳推荐候选并完成发布闸门后，系统才能生成不可变 ProductRelease。任何外部社区上传、覆盖或公开分享都是额外外部动作，必须再次取得作者明确授权。

## 3. 首个推荐候选的硬合同

### 内容和体验

- 目标实测中位游玩时间 50–75 分钟；至少一条完整主路线不得短于 45 分钟。
- 单条完整主路线至少 12,000 个玩家实际可见中文内容单位；发布包总可玩内容至少 20,000 个，标题、标签、配置、失败模板和重复文本不得充数。
- 至少 20 次推进主线所需的正式玩家行动；其中至少 6 次是具有可持续后果的有效决定。
- 有效决定必须改变至少一类正式状态，并在两个以上后续节点产生可观察回响；仅改变下一句措辞或立即汇流且无状态差异不计。
- 至少 5 个有姓名、有动机、有知识边界的主要 NPC；至少 30 个有效对白轮次，并包含玩家可选择的回应或行动。
- 一条完整主线任务至少包含 3 个阶段和 8 个目标；至少 2 条多阶段支线与 4 个区域/动态 storylet 可被主线状态影响或反向影响主线。
- 至少 3 个因果不同的完整结局场景；每个结局有正文、角色回响、状态结算和行动链回顾，不能只是一句摘要。
- 至少一次失败推进：失败产生代价、新局面或替代路线，不以无反馈重试或软锁结束。

这些阈值是首个一小时旗舰的发布下限，不是所有文字冒险题材的永久通用规则。未来规模档通过版本化质量配置扩展，但不得降低“声明时长必须被实测证据支持”的不变量。

### 游戏工程

- 角色属性、技能、生命/法力/体力、经验、技能点、货币与时间有明确状态、上限下限和玩家 UI。
- 物品、背包、装备槽、能力修正、取得/使用/交付/装备操作有确定性结算和 UI。
- 主线、支线、区域任务具有可用/已接取/进行中/完成/失败状态、阶段、目标、追踪和 UI。
- 场景、地图层级、移动、行动可用性、检查、资源代价、关系变化、storylet、结局条件全部进入版本化合同。
- 存档、自动存档、刷新恢复、从存档分支、事件重放、损坏检测和 ProductRelease/hash 固定通过验证。
- AI 不可用时，冻结正文、模板叙述与明确按钮仍能走完全部核心路线。

### 媒资

- 支持纯文字完整通关；推荐候选至少有封面、区域图、主要角色锚点、关键地点和关键转折/结局插图。
- 主要角色锚点必须经作者确认；素材可上传、替换、锁定、单项重生成，并保留来源、权利、provider receipt 和内容哈希。
- 图片失败只能触发文字替代与缺失提示，不得改变规则状态、阻塞存档或制造不同结局。

## 4. 不在本次旗舰中的能力

调查证据盘、法庭质询、完整职业战斗循环、生存模拟、政策与民意、恋爱阶段、完整经营经济、持续角色自治、按需世界模拟、多人、运行期动态出图、连续 AVG 舞台演出均不进入首个旗舰内核。它们以后只能通过版本化能力模块和玩法配方接入。

## 5. 导入、导出和分享

- 作者可导入受支持的 StoryForge 产品包；解析、schema/version、hash、作用域、引用和媒资完整性必须先校验，不能部分写入后才报错。
- 导出包必须固定 ProductRelease、SourceManifest、运行包、媒资清单/Blob、权利声明和兼容版本；私密 API Key、临时 provider 请求与未采纳候选不得进入包。
- 导入后生成新本地作用域并按 `PROJECT_TABLES` 重映射引用；删除、迁移、重复导入和损坏包必须有正反例。
- “可上传”表示生成通过验证的不可变包，不代表系统自动对外发布。
