# AVG 分层验收、局部返修与首场景

> L2 · 版本：1.2.0 · 生效：2026-10-14 · 受 [AVG 产品契约](../AVG.md)约束。
> 这是验证设计，首场景/对照试验尚未执行；当前研究的宣传帧和官方手册不能作为本规格的实际作品验收。

## 1 五类证据分别成立

| 门 | 必需证据 | 不能代替它的材料 |
|---|---|---|
| 工程/治理 | 准确输入/package/Build hash、来源权限、schema/引用/状态机、恢复/隔离/回归及真实消费 | 模型自报“完整”、岗位名称、一个漂亮截图 |
| 专业表达 | 真实剧本、实际图片/音频及连续场景，对照方法/rubric 的具体问题与观察范围 | Prompt、无字节需求、只有技术指标、单张图平均分 |
| 作者采用 | 作者看/听/试玩准确候选/Build，决定与修改理由及版本 | 自动 schema pass、LLM 扮演作者、导入 fixture |
| 独立玩家 | 真实参与者/目标、准确 Build、操作路径、原始理解回答/停顿退出/问题，assist 与条件 | 开发者自己通关、机器人 E2E、同模型写评价 |
| 分发/经济 | 指定包/平台、离线安装及权利/政策/渠道检查；实际花费/工时和真实反馈/收入 | release 已生成、商店文案、论文/头部产品销量 |

采用总纲成熟度：engineering-playable → creator-accepted → player-validated → distribution-ready。门按用途和证据推进，不因平均分、研究丰富或 CI 通过自动升级。现金回本/收入单独记录，distribution-ready 不代表已出售或盈利。

每份回执保存 scope、input/build/release hash、rubric/version、observer 身份/类型、实际观察范围、时间、结果/pass/fail/unknown/not-applicable、证据 refs 与问题。not-applicable 只能来自冻结 Brief，不能在失败后临时取消一项；输入变更使受影响回执 stale。

## 2 质量 rubric 与阻断条件

| 维度 | 实际检查 | blocking 示例 |
|---|---|---|
| 故事/人物 | 行动目的/代价、因果、角色声音、日常当下用途及后场回响 | 关键事实矛盾、动机缺失使选择不可理解、同一角色无依据换身份 |
| 路线/系统 | 可理解选项、条件/代价、即时与延迟结果、知识和可达结局 | 假选择、错误知识披露、库存重复/丢失、必需路径无法继续 |
| 对白/节奏 | 言语行动、潜台词、回应、文字量与停顿；实际阅读界面 | 关键对白表达与规则后果相反、揭示前泄漏秘密 |
| 美术/连续性 | 同人/同服装/同物件、空间/光源/锚点、安全区、小图辨认 | 核心人物无法辨认、错误物件状态、必要视觉信息被遮挡 |
| 导演/界面 | 注意目标、转场/镜头/声音有用途，操作可发现且可访问 | 消费绑定错对象、界面挡住必要提示、不能操作/退出 |
| 声音/配音 | 真正审听读音/演法/接话/噪音/循环/混音及句匹配 | 错句/错人物/关键漏词、不断叠播、语音等待永久卡死 |
| 整体体验 | 完整场景/路线中的理解、情绪转折、反馈和继续意愿 | 恢复改写后果、跨线结合后关键信息不可理解 |

可用 1～5 的有锚点分数描述其余表现，但阻断问题逐项处理，不允许用其他维度高分抵消。评审记录具体 line/scene/action/consumer/clip 和实际证据，不能只写“再润色/再优化”。

模型收不到图或音时该艺术项为 unknown；没有操作的 reviewer 不能给输入/恢复通过。独立模型评审须不同 provider + model 的真实路由，另一个 Key 或同模型独立 Run 只算辅助审校。人类参与、成本和运行 receipt 不能由模型生成。

### 2.1 商业参照的判定范围

| 质量结论 | 判定依据 | 当前状态 |
|---|---|---|
| 基础系统可用 | 启用范围的对话/规则/库存/消费者/恢复/性能反例通过 | 旧 V1 有底座；目标增量尚未实施 |
| 本作品可交付 | 准确版本的技术、完整表达、作者/独立玩家、权利及指定环境通过 | 新作品尚无证据 |
| 接近指定商业参照 | 同场景类型/语言/观察范围的逐项比较，内容/画面/声音有相应经验者的实际意见，所有关键项无明显落差 | 尚未冻结连续锚点或比较样本，不成立 |
| 完整长篇/批量生产达到目标 | 真实长作的路线/节奏/回收、连续资产/演法、返修与成本、维护和独立反馈 | 后置；短戏/精选素材不能代证 |

这些是允许陈述的质量结论，不增加产品身份、成熟度级别或万能认证。CAL-00 的 QualityProfile 必须冻结参照作品/平台/版本/语言/场景/用途、样本合法来源、观察者范围、rubric 锚点、逐项差距、人工/现金政策、有限次数和停止条件（作者可显式不设总费用/工时上限）；不可只写“顶尖”“4分”或一个游戏名。

rubric 的 1～5 级锚点为：1=关键意图/信息无法成立，2=需显著重写/加工才能用，3=意图成立但表达或连续性仍明显粗糙，4=在指定观察项接近参照，5=该项有具体证据的突出表现。4/5 的“参照”必须是实际看/听/读过的匹配片段；未观察不能打这一分。blocking 另行清零，不用分数平均掉。

商业质量候选至少分别取得具有相应经验的剧情/编辑、视觉/演出、声音/表演意见（身份/经验与范围可核验，不能由模型扮演），以及作者/读者完整体验。样本随机顺序/去除不必要品牌提示，记录熟悉度/识别和语言差异，不能伪称完全盲测；保留不利意见和原始 n/N。跨语言未匹配时只比较可观察的结构/画面，不直接宣称对白自然度等同。

工程可用、读者通关、作者喜欢都不能单独推出“比肩商业”。专业人工改稿/作画/录音可作为正式制作路径，记录自动原稿→加工→最后成品的独立成绩和投入；最终作品达到目标不等于模型原始输出已达目标。若质量/人工投入超出冻结上限，停止扩大/重新选方法，不无限生成直到偶然精选一份成功。

## 3 头部成品与方法校准

研究依据是[商业对标](../../audits/AVG-PRODUCTION-RESEARCH-20261013.md)、[主创/方法](../../audits/AVG-PROFESSIONAL-METHODS-20261013.md)和[系统/媒资](../../audits/AVG-SYSTEMS-AND-MEDIA-RESEARCH-20261013.md)。参照已研究的 Fate/stay night、STEINS;GATE、Key/柚子社、月姬/魔法使之夜等代表性成品，以及逆转裁判等模块机制；每部 AVG 按体验目标选择系统。

现有证据只包括 24 个实际查看的宣传帧及一张官方操作手册图等；九场完整商业场景及音频审听仍待补。校准工作选择研究中的日常铺陈、冲突/关键选择、后场回响三类连续场景，覆盖相应视角/系统/演出，按可合法访问的准确版本观察完整前因/后果及声音。无法取得材料记缺口，不虚报游戏通关，也不把商业资产复制进生成作品。

2026-10-14 的 CAL-00 可访问性复核：Key [官方开发日志](https://key.visualarts.gr.jp/archives/6986)指向公开短篇参照页，但该故事页和 RB 手册经网页读取、普通 HTTPS 与浏览器均未能完整打开；Capcom [官方支持页](https://www.capcom-support.com/hc/en-us/articles/13470932959516-Apollo-Justice-Ace-Attorney-Trilogy-Online-Manual)可读，其链接的操作手册本轮访问被拒。可访问的说明不等于已观察完整故事、系统操作或音频；本轮不增加连续场景/审听完成数，保留参照缺口，不以预算未给出解释。

场景观察记录：作品/发行版本、来源与授权范围、时间/位置、视角/人物/行动、信息变化、句/停顿、画面/声音用途、系统操作、后果和可观察限制。优先得到首场景所需的明确方法锚点；未观察完九场不声称研究全部完成。

内容校准总设计为三种原创 Brief × 三种路径 × 每条件三个独立样本，即 27 个候选样本，分期执行：CAL-01 在最小专业路径就绪后先做一个匹配 Brief 的 9 样本，质量/投入不失败才由 06 补两类的 18 样本；不等完整三线系统才测试专业化收益。多岗位路径每样本可含多次调用，因此绝不等于 27 次 API 调用。三个路径为当前通用路径、专业写作路径、加入分离编辑/审校的专业路径。相同来源/输出要求、可比总预算、留存全部原始输出/拒绝和人工改稿工时；小样本是继续或返修依据，不是效果统计证明。

先冻结 provider/model、Skill/Prompt/schema、采样参数、每样本有限资源、attempt/repair、整体费用/工时政策与停止条件、blind review 顺序和 rubric，再调用。本次首轮作者已明确无总费用/工时上限，保留有限批次和全量投入记录；这项授权不等待重复确认。评测声明有限 evaluation 或正式 production 的真实边界，不污染作者作品，也不另造未注册调用；route 不独立时不宣称独立模型证据。

## 4 第一场完整戏：3～5 分钟

首场景是通用产品验收集合：雨夜档案室，两位成年人、一封未开封的信、一个可理解的决定及两个不同回响结果。它沿用研究中的原创方法示例，正式生产前另冻来源世界/Brief/预算；不是把预写片段塞入产品默认生成器。

| 项 | 冻结意图与验收 |
|---|---|
| 日常 D01 | 护住档案/晾干信封等当下有效行动形成具体关系；不只靠“我很关心你”解释 |
| 冲突 C01 | 是否让对方核对邮戳/出示信封有信息与信任代价；结果由正式规则执行 |
| 回响 H01 | 两个结果在后续回应/行动中实际消费此前决定，汇流不抹去差异 |
| 物件/知识 | 同一信封的 icon/detail/剧情特写一致；看邮戳不会自动读到未开封内容或得知隐藏寄件人 |
| 对话/演出 | 两个人物声音可区分、具体动作/停顿、正确构图/表情和必要镜头；台词/字幕/配音一致 |
| 声音 | 一组必要 BGM/环境/SFX、关键短对白真实配音，测试循环/接话/打断和缺声策略 |
| 恢复 | 决定与出示前后保存/刷新/加载；状态、显示和已发生后果一致，不重复执行 |

最低资源需求：两个已确认人物基准及实际必要表情/姿态，一处雨夜背景，同一信封图标/详情，必要关键画面，必要音乐/雨声/动作声和关键短句配音。准确张数/句数、尺寸/格式、尝试数、总费用和工时在 Pilot Brief 冻结；不能以无限变体或全部句配音扩大范围。

两种证据必须分开：

1. **授权导入/组装模式**：可用合法自有媒资建立工程/艺术参照，验证三线交接、消费者、播放/规则和恢复。不能证明自动参考生图、TTS 或批量质量。
2. **生成并绑定模式**：正式 Skill/Harness、真实参考与 provider 返回、采用、typed binding 和 Build；记录用/废率、返修、成本和真实质量，才能验证自动生产路径。

导入模式不阻塞必要工程发现；生成模式必须等待相应基础/能力/预算授权。当前文档交付不执行任一模式，不调用模型或生成资产。

PILOT-01A 的直接前置为最小编辑/预览 05A、物件 02B1、单会话播放/恢复 03A 与实际参照/Brief；不等待完整媒体工厂、工作台或跨周目进度。PILOT-01B 再加入 04A/B 的正式真实生产；两个模式形成不同 Build/hash/receipt，不复制整体验收。05B 用真实首戏问题补全工作台，03B/02B2 的未选能力后续独立施工。

## 5 首场景验证矩阵

| 探针 | 正例 | 反例/故障 |
|---|---|---|
| 来源/知识 | 正确来源与公开邮戳进入系统/媒资/对白 | 私密信内容进入 icon/detail/消息时阻断 |
| 行动/库存 | 获得一次、重复检查无重复奖励、出示按明确政策保留 | 重发 command 不重复；未知对象、非法打开/消耗拒绝 |
| 分支 | 两次实际选择有立即反馈和后续消费 | 同义选项/汇流清零/隐藏无代价被评审退回 |
| 舞台/资产 | 同物件与人物连续，inventory/detail/CG 各在正确槽 | unknown consumer、wrong kind、错人物/锚点或遮字阻断 |
| voice | 准确句/音色/演法、实际 ended 驱动 auto | 改稿旧 voice stale；换句旧回调无效，失败按策略退出等待 |
| 存档 | 选择/出示/消息前后加载重放一致，旧档保留 | 缺 hash/损坏/跨 Work 拒绝，SFX 不因重绘重复改变事实 |
| 阅读/可访问性 | manual/auto/已读 skip/历史回听/键盘/触屏各自有效 | auto 不选答案，回听不重复效果，未读 skip 不伪报读完 |
| 局部修订 | 改对白重验 voice；换表情重验家族；无关背景保留 | 锁定输入冲突不能忽略 stale，子 Build 不借父回执 |
| 版本 | 修复版绑定新包，旧 release/save 仍读旧包 | 静默覆盖旧 Blob、包或档案阻断 |

试验先由作者完整操作并指出表达问题，再安排少量独立目标读者反馈。逐项保留原始意见，修好 blocking 后重测同一戏；不能因美术漂亮就扩大篇幅。

## 6 扩展到 15～30 分钟与通用性

首戏通过后，AVG-06 制作 15～30 分钟、至少两个真实不同结果的切片，完整观察三线、作者修改及发布后问题→修复版→旧档闭环。至少 8 名目标读者、6/8 无指导完成且能解释冲突/关键后果、4/8 愿意尝试另一结果，以及内容/人物/演出中位数目标 4/5，作为待冻结的试点阈值；保留实际 n/N、退出/辅助使用和负面反馈。这些是小规模继续决策标准，不是商业转化或头部质量认证。

早期模型/家族/短对白试验记录原始合格候选数/总数、全部失败/费用、修稿/修图/修音/审听时间、最终采用率及每可用游玩分钟的投入。人工/现金政策（允许作者显式不设总上限）及每批具体调用/token/时长/attempt 必须在 CAL-00/Brief 冻结，阶段间不能静默扩大单批或隐去投入；当前首轮的无总上限授权已取得，不再以此为等待项。缺真实费用/人工和质量证据时不能判断生产经济性可行，角色/声音基准未通过时不能靠扩大素材量改善报告。

AVG-08 再验证第二题材/不同配置：至少一线性、另一分支/调查组合，换世界/人物/资产/规则后仍通过同一专业流程与消费合同。首作专属分支、固定台词/角色和自动评分特例不能通过通用性门；完整长作品、小游戏和高级表现等后置到证据支持后。

## 7 问题定位与返修闭包

问题单绑定准确 Build/release/save 与 line/action/consumer/clip，包含实际观察、severity、owner、上游依赖、允许修改域、成本影响及重验门。内容事实回 source/story/route owner；表达回 writer/editor；规则回 system owner；演出回 director；媒资回对应主体/用途 owner。

确定性影响分析生成待失效列表和可保留项，作者确认返修范围后新建候选/Build。不能为修一张图无边界重写全作，也不能为保留锁定图而改剧情真相。共享 Blob 只复用合法字节，不复制旧质量/玩家回执。

停止条件包括：未授权开始/收费、关键来源冲突、无法满足必读/禁止、预算不明/耗尽、provider 结果未知、观察缺失、候选 stale、破坏数据/兼容的反例失败。停止在最小闭包并保留证据；文档设计不因此自行扩大为修改产品或开展真实生产。
