# StoryForge 文字游戏类型与设计方向

> 状态：当前类型规划
>
> 目的：先明确“要做哪种游戏”，再决定复用哪些底层能力；不把所有文字表现的游戏混成一个产品。

## 1. 分类原则

文字只是表现媒介，不足以定义一种游戏。这里优先根据玩家的核心行为、世界是否持续运转、内容由谁控制
以及一局游戏如何推进来分类。

另外需要区分两个维度：

- **游戏类型**：玩家怎么玩，例如分支叙事、角色互动、文字冒险、文字开放世界。
- **表现方式**：游戏如何呈现，例如纯文字、卡片 UI、轻量插图、AVG 立绘与镜头演出。

AVG / Galgame 首先是一种强叙事、强演出的产品路线，不应因为也有文字和选项，就与开放世界状态系统
放进同一个首期框架。

## 2. 已确定的类型

### 2.1 分支互动叙事

玩家阅读作者安排的故事，在关键节点选择方向，进入不同路线和结局。

主要特点：

- 作者预制内容占主导，世界主要随剧情节点推进。
- 有条件选项、隐藏路线、分支汇流和多个结局。
- 数值、物品、技能可以存在，但主要服务剧情 gate。
- 重点是结构完整、选择有意义、伏笔与结局可达。
- 适合短篇互动小说、剧情选择游戏和实验性叙事。

它比开放世界简单，可复用现有可执行叙事蓝图和 SIM 分支能力，是当前第一个独立施工产品。

### 2.2 角色互动 / 关系叙事

玩家持续与一个或多个角色交流，角色依据人格、知识、记忆和关系做出反应。

主要特点：

- 核心内容是对话、人物关系和长期记忆。
- 角色只能知道其合理获得的信息。
- 多角色场景需要发言调度、冲突和相互影响。
- 可以是日常陪伴、恋爱、群像、阵营交涉或剧情角色扮演。
- 角色说出的内容不能直接改变物品、生死、位置或能力。

现有 `CHATGAME-1` 已完成单角色聊天 MVP。长期记忆、多角色和真实世界行动不继续扩张聊天私有状态，
未来从共享运行时或文字开放世界能力中组合。

### 2.3 文字冒险 / 轻 RPG

玩家操控角色探索地点、获得物品、使用能力、推进任务并承担行动结果。

主要特点：

- 角色、地点、物品、技能、关系和任务是实际游戏状态。
- 玩家可以通过选择或自由文字提交行动。
- 战斗、交涉、调查、交易、制作等由规则判断。
- 世界规模通常有限，重点是玩家路线和成长，不要求整个世界持续自治。
- 可用于探险、推理、生存、养成和小队冒险。

它是文字开放世界的重要能力子集，也可以将来以更轻的 Profile 单独发布。

### 2.4 AVG / Galgame 视觉叙事（独立表现线）

以作者精编剧情和场景演出为核心，使用对话框、背景、立绘、表情、CG、镜头、转场和音频控制体验。

主要特点：

- 线性或有限分支，作者对节奏和镜头有较强控制。
- 美术与演出资源是内容生产的重要部分。
- 世界通常不需要像开放世界一样持续自治。
- 技术重点是演出时间线、媒资、预载、回看、自动播放与已读跳过。

《饿殍：明末千里行》式目标放在此方向参考。它已有独立开发方案，不与 `TEXTWORLD-1` 同期施工。

### 2.5 复杂叙事模拟

玩家管理角色、组织、资源或某种大型系统，长期决策形成连锁后果。

主要特点：

- 时间、资源、组织、政策、危机和多个指标共同运作。
- 玩家选择可能在很多回合后产生后果。
- 世界事件不仅由主线触发，也由状态阈值和规则产生。
- 可以实现历史治理、玄幻宗门、科幻殖民地、都市公司等题材。
- 重点是因果、资源平衡、信息不完全和失败状态。

“崇祯模拟器式”目标属于这一方向，但我们追求的是通用结构，不是历史官制或具体内容。

### 2.6 文字开放世界（最终阶段）

玩家可以自由进入不同区域，在一个会随时间和行动持续变化的世界中探索、接触人物、发现任务、解决或
忽略问题，并形成自己的经历顺序。

主要特点：

- 世界由区域和交通关系构成，每个区域有独立的资源、人物、组织、问题与任务生态。
- NPC 和组织有位置、目标、日程和有限知识，不完全停下来等待玩家。
- 固定主线、人物故事、系统事件和动态任务可以同时存在。
- 任务不是地图问号清单，而是通过人物、传闻、公告、遭遇、信件等渠道自然发现。
- 区域动态任务导演根据玩家进度、任务积压、区域资源、世界机制和叙事节奏受控发牌。
- 玩家完成、失败或忽略任务都会改变世界，区域之间还能发生资源、人口、组织和危机传播。
- AI 可以配置和表现任务，但世界事实、合法行动、奖励和后果由规则系统决定。

这已经属于开放世界的逻辑体量，只是表现媒介以文字为主，而不是 3D 地图和动作系统。

## 3. 类型之间的关系

这些类型不是从简单到复杂的强制升级树，也不是互斥标签：

- 文字开放世界会使用文字冒险和复杂模拟的部分能力。
- 角色互动可嵌入任何类型，但不能成为整个世界状态的权威。
- 分支互动叙事可以成为开放世界中的固定主线或关键人物线。
- 未来可以给开放世界增加插图，但这不等于把它改造成 AVG。
- AVG 未来可以读取同一 World Canon，但不需要继承开放世界的区域自治和任务导演。

开发时应先选一个主类型，再按需要组合次要能力，禁止以“以后可能都用到”为理由同时建设所有系统。

## 4. 当前优先级

1. **STORYGAME-1 分支互动叙事。** 先复用现有叙事蓝图和 SIM 做出第一条完整可玩产品链。
2. **CHATGAME-2 角色互动与关系叙事。** 在单角色 MVP 上补记忆、关系、知识和多角色。
3. **TEXTADV-1 文字冒险 / 轻 RPG。** 加入地点、物品、能力、任务和行动规则。
4. **AVG-1 视觉叙事。** 作为独立表现线，在 STORYGAME 稳定后建设，不阻塞玩法线。
5. **TEXTSIM-1 复杂叙事模拟。** 完成资源、组织、政策、危机和长期因果。
6. **TEXTWORLD-1 文字开放世界。** 最后组合成熟能力，再建设区域自治、任务导演和跨区域演化。

## 5. 防跑偏判断

一个需求属于当前文字开放世界主线，至少应回答其中一个问题：

- 它是否让区域或世界更真实地运转？
- 它是否改善玩家自由探索和行动？
- 它是否让任务更自然地从世界状态中产生、传播或收束？
- 它是否让玩家行为对人物、组织、资源和区域产生可回放的后果？
- 它是否改善长局一致性、节奏、重复控制或失败恢复？

如果需求主要回答“画面如何切换、立绘如何移动、CG 如何生成”，它属于 AVG / Presentation 方向，
不进入当前 STORYGAME 设计或后续玩法与世界线；应按 AVG-1 独立范围登记。
