# 插件体系与创意工坊一期

> 施工基线 1.0 · 2026-10-08 · 共享工程底座研发；实现状态以源码、测试和验收证据为准。

## 目标与边界

把完整功能作为独立包交付：界面、处理逻辑、自有数据、AI 工作流与外部连接可以组合。新增与替换是明确的贡献类型，官方数据的 owner 和正式写回契约不随插件改变。创意工坊一期提供本地安装、静态目录发现、版本检查、组合包、启停和故障恢复；不引入在线创作、账户或支付服务器。

本任务属于总纲 §8 共享工程底座的产品研发。插件不创造新的 S1/S2/S3 旁路；World/Work/ProductRelease 仍分别负责自己的内容与版本。插件包是全局本地资产，启用配置和插件记录归具体 World/Work；普通作品备份不携带可执行插件。缺少插件时保留数据，导入不自动执行代码。

## 施工顺序

1. P0：独立 ESM 工厂打包、共享 React、Blob/CSP 加载与有界 JSON Schema 解释验证。
2. P1：版本化 SDK、声明校验、依赖排序、贡献注册、作用域实例、清理与安全启动。
3. P2：安装包、配置、记录、契约、操作回执；登记 PROJECT_TABLES；迁移、卸载保留与备份往返。
4. P3：工作台贡献、世界历史与作品时间线替换、官方参考插件。
5. P4：受治理 AI 调用、注册快照、候选确认、durable 恢复与历史证据。
6. P5：世界语义封存与产品规则版本绑定的独立纵切面。
7. P6：外部能力与可选本机桥；普通插件安装无需 Node/Python。
8. P7：工坊发现与管理、开发脚手架、打包校验与使用文档。
9. P8：各产品通用扩展入口；专业算法逐项适配与验证。
10. P9：无插件回归、隔离浏览器、性能、升级恢复和交付检查。

## 接口与数据约定

- 插件依赖公开 SDK，不导入宿主私有模块、Dexie 或 Zustand。宿主 React 由工厂参数提供；安装时不运行 npm、不从 CDN 加载运行依赖。
- 包身份是 id、version 和 SHA-256；相同版本不同字节拒绝覆盖。配置锁定准确包，启用依赖拓扑排序；循环、缺失、不兼容或重复替换拒绝。
- 原生 UI 插件是可信本地代码，权限声明不冒充安全沙箱；错误边界不能终止主线程死循环。安全启动在模块求值前跳过全部插件。
- 核心字段走现有领域接口；AI 通过注册源、durable Harness、CreativeArtifact 和作者采纳。插件数据只写自己的 namespace，并以 schema、revision 和 generation 约束。
- 三注册表仍为唯一事实源。物理表由 PROJECT_TABLES 派生备份、删除和重映射；动态声明不得重新定义核心 owner 或字段意义。
- 升级数据写新 generation，验证后原子切换。旧数据保留；升级后的编辑不能被盲目回滚覆盖。
- 旧备份只通过明确版本转换进入新协议，不为任意损坏备份补表。离线导入不隐式启用插件或运行迁移；旧 AI 候选和工具结果仅作只读历史，不恢复原任务的执行权限。

## 验收与状态口径

需要证明多个独立包可以共同运行，第二个同类插件无需修改宿主业务代码；复杂界面、自有数据、服务组合、生成流程和外部能力分别测试。还需覆盖错误包、循环依赖、跨作用域写入、版本冲突、刷新恢复、安全模式、卸载重装、备份往返和迁移竞争。

通用界面入口不等于所有产品内部算法都可以替换。未完成纵切面保持实验性；不把工坊目录、截图或 TypeScript 编译成功作为完整 1.0 验收证据。

这是插件底座与本地创意工坊共同交付的 1.0 试用版；API 1/SDK 0.1 保持开发预览，先用测试作品验收后再决定正式开放。普通产品默认不加载插件。

世界语义复用现有官方分类与词条，规则复用现有 RulePack 解释器，避免新增平行的世界读取协议和任意 JS 运行规则。它们分别是明确的一次确认与冻结，不自动同步作者后续编辑。复杂专业算法的替换仍需产品专属适配；通用工作台不代表每个内部函数已成为公开 SDK。

主要共享改动：数据库 10→11 新增五表；备份 14→15；三注册表增加插件数据及受限 AI 写策略；正式 AI 增加一个注册 Skill；Harness 允许严格零模型、零上下文/写回的确定性工具运行；现有 TTRPG 规则库增加不可变版本写选项；各产品增加可关闭的扩展入口。现有作品、世界、媒资和发布数据的 owner 不改变。

不包含在线创作服务器、账户、收费、评分、后台自动更新、任意 JS 游戏规则、标准 Worker 插件协议、Apps iframe 宿主或跨平台签名安装器。插件权限声明是契约，不是原生 UI 的恶意代码沙箱。开发与分发细节见 [插件开发约定](../guides/PLUGIN-DEVELOPMENT.md)。
