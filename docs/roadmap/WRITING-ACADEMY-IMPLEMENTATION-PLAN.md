# StoryForge 写作学院首版施工方案

> 版本：0.3.0 · 日期：2026-11-28 · 文档定位：L2 首版施工入口。承接用户确认的学院方向与域名，细化内容契约、施工单元、依赖和验收；完成状态以实际交付证据更新。当前工程已形成十语可用预览，已完成项与外部验收状态见第 14 节。

本方案将 [建设方案](./WRITING-ACADEMY-CONSTRUCTION-PLAN.md) 转化为可以逐项实施的工作包。首版目标是在 `academy.storyforge-lab.com` 交付十种语言的学习网站，让用户完成“找到方法 → 阅读案例 → 填写模板 → 导出自己的结果 → 按指南进入 StoryForge”的过程。

建设方案负责定位、研究方法和长期方向；本文件负责首版施工顺序与退出条件。变更首版范围时同步修改两份文档的对应内容，避免维护两套相互冲突的要求。

| 多语言 | `/zh/`、`/en/`、`/fr/`、`/de/`、`/it/`、`/ja/`、`/ko/`、`/es/`、`/pt/`、`/ar/`；同条目切换，阿拉伯语 RTL，核心内容版本同步 |

|---|---|---|

## 3 学院仓库结构与构建契约

首版采用建设方案推荐的 Astro 静态生成、Markdown/MDX 与 Pagefind。安装时核对官方兼容要求，固定依赖与锁文件；工程脚本在 AC-01 实现后才成为可运行命令。

```text
storyforge-academy/
  AGENTS.md                         学院数据和出版边界
  src/content.config.ts             各类内容 schema
  src/content/{en,zh}/               经编辑的公开内容源
  src/data/taxonomy.json             分类与标签词表
  src/data/glossary.json             中英术语、别名与概念关系
  src/data/bibliography.json         可公开的来源书目
  src/data/authors.json              作者与审校者公开信息
  src/data/templates/               模板定义与原创填好示例
  src/components/                    页面组件、模板编辑器
  src/layouts/                       阅读与学习路线布局
  src/pages/                         页面与路由
  scripts/                           校验、发布清单与索引脚本
  tests/{content,templates,search,ui}/
  docs/                              学院编辑与部署操作说明
  public/                            有权公开的站点静态资源
```

私有来源文本、授权文件、模型原始输出、密钥和用户填写内容不放入以上公开内容结构。MDX 只允许经审核的组件，模板字段只保存声明式数据，不接受可执行表达式或外部脚本。

生产构建从状态为 `published` 且属于本次发布清单的条目生成页面。目录、相关推荐、搜索、下载包与 sitemap 共用同一出版清单。草稿不生成可猜测的生产 URL；私有预览使用托管平台访问保护，并配置禁止搜索索引。

## 4 内容与编辑数据契约

### 4.1 内容对象

| 对象 | 必须字段 | 校验规则 |
|---|---|---|
| 所有条目 | `contentId`、`kind`、`locale`、`slug`、标题、摘要、状态、版本、作者、日期 | 同语言 slug 唯一，身份稳定，类型与语言受控 |
| 教学属性 | 学习目标、难度、阶段、题材/情节模式/机制、阅读与练习时间 | 标签来自词表；估算时间为非负值 |
| 内容关系 | `prerequisites`、`related`、案例与模板编号 | 引用存在；先修无环；生产页面只引用已发布目标 |
| 事实依据 | 书目编号、定位、主张或分析的性质 | 事实引用可回溯；研究推断与来源直接表达区分 |
| 双语关系 | 共用 `contentId`、语言、正文版本、所依据的对应版本 | 核心内容中英配对；实质更新后译文必须重新审校 |
| 审核 | 实际审核者、审核时间、审核对象内容 hash | 文本或模板实质变化使原审核失效，不复用旧通过状态 |
| 拆书 | 作品、作者、版本、实际范围、定位、剧透级别 | 不允许范围空白；开篇研究不可标为全书分析 |
| 路线 | 有序步骤、目标、对应条目、阶段产物 | 步骤目标存在，顺序与先修一致 |

正文文件名可以改变，`contentId` 不随语言或标题变化。公开页面显示作者、审校者和修改日期；审核身份必须对应实际完成的工作。

### 4.2 私有研究与公开书目

私有来源记录保存访问状态、权利判断、正文阅读情况、证据位置、许可范围和授权附件引用。研究卡保存问题、来源主张、编辑解释、反例和目标教程编号。

公开书目只投影标题、作者、出版者、原始地址、版本/日期、必要定位和允许公开的许可说明。构建使用允许字段列表生成书目；内部备注和私有文件地址不能进入输出。一个转载来源须能指向其原始出处。

来源处理状态为：`discovered → verified → read → extracted`，正文不可访问或来源待核对时记录 `pending`；重复条目标记 `duplicate` 并关联原记录。建立来源记录不等于完成精读。

### 4.3 编辑与出版状态

稿件按 `planned → researching → draft → fact_checked → language_checked → ready → published` 推进；另有 `changes_requested`、`withdrawn` 和 `archived`。

每次推进保存实际执行者、稿件版本与结果。发布校验检查来源、实质内容、双语、关系和许可；缺少必需审核不能通过修改一个状态字段直接上线。纯原创内容用原创声明解释其来源，而不伪造外部参考。

已发布条目的修改先形成新版本并预览，再替换正式版本。撤下条目须从正文、相关推荐、下载包、索引和 sitemap 同时移除；旧地址返回说明页或适当的撤下状态，不继续保留原文缓存。

## 5 资料搜集与内容生产任务

### 5.1 每批研究的交付规格

每批建立一张主题任务单，包含写作问题、目标读者、需要的案例、检索词、候选来源、缺口、预计阅读范围和产物编号。交付必须包括来源记录、精读研究卡、可核验论断清单及原创教学稿。

首批候选来源沿用建设方案第 3 节已核对入口。番茄课程正文逐篇访问；起点返回 403 的入口仍在待核验队列，不计入精读数量。原作使用正常授权阅读，不以二手梗概补造章节事实。资料使用条件和出版处理按建设方案第 4.5 节执行。

教程验收逐项检查：问题是否明确、步骤能否执行、例子是否说明原因、有没有适用条件、练习是否有产物、来源是否支持具体主张。每份模板至少由编辑使用原创设定完整填一次，并记录需要修改的字段。

### 5.4 第一个示范交付

先完成 L03、L06、L10 的示范版本，关联 T04、一篇实际开篇分析、一个原创系统文例子和六个术语。读者需要能够从教程进入案例、填写 T04，并导出自己设定的能力与限制。

此示范用于测量实际精读、写作、审校与开发耗时，再修正排期。内容编辑与英语审核必须对应实际执行人；若尚未取得英语审校或真人试读，其状态保持待完成，工程预览仍可继续。

## 6 页面施工清单

语言前缀统一为 `/en`、`/zh`。以下路径不含语言前缀，具体条目使用稳定 slug；所有详情页能独立访问和刷新。

| 页面 | 路径 | 必须组件与动作 | 验收重点 |
|---|---|---|---|
| 学院首页 | `/` | 定位、搜索、问题入口、路线、精选案例和模板 | 每个公开入口有真实目标 |
| 新人入口 | `/start/` | 按目标推荐路线、展示预期产物 | 新手能明确第一步 |
| 路线目录与详情 | `/paths/`、`/paths/{slug}/` | 有序步骤、先修、继续学习、本地进度 | 能跳读，修改后的路线不误记已完成 |
| 方法目录与详情 | `/learn/`、`/learn/{slug}/` | 筛选、正文、目录、示例、练习与关联内容 | 方法和来源可读，关闭脚本仍有正文 |
| 指南目录与详情 | `/genres/`、`/genres/{slug}/` | 期待、机制、变体、问题和关联资源 | 分类清楚，能够进入具体教程 |
| 拆书目录与详情 | `/case-studies/`、`/case-studies/{slug}/` | 版本、范围、剧透提示、事件与作用、来源 | 范围显著，剧透内容由用户展开 |
| 模板目录与详情 | `/templates/`、`/templates/{slug}/` | 指导、空白/示例、编辑、预览、复制、下载 | 用户输入与示例隔离，导出完整 |
| 术语库 | `/glossary/` 与词条锚点 | 双语名称、语境、相关概念与内容 | 同义词可搜，锚点稳定 |
| 搜索 | `/search/` | 查询、筛选、匹配片段、无结果提示 | 可分享查询与筛选状态 |
| 信任与支持 | `/about/`、`/sources/`、`/corrections/` | 编辑方法、公开书目、更正与联系 | 指向已核验的联系渠道 |
| 未知与撤下地址 | 404、撤下说明 | 返回入口、搜索或替代内容 | 不泄漏草稿或私有信息 |

根域入口默认进入英语首页，同时提供中文选择；只记住用户明确的语言选择。同条目切换使用稳定身份寻找译文；目标缺失时说明实际情况，不把其他内容伪装成译文。

### 6.1 视觉与交互验收

采用学习网站的阅读布局：清楚的栏目、稳定的正文区域、少量重点强调、可比较的案例和明确的练习区域。视觉首样先实现首页、教程页和模板页，由用户查看后修正组件规范。

桌面正文建议控制在约 40～46rem，正文建议 16～18px；左侧学习路线与右侧目录在空间不足时折叠。手机单列显示，目录和筛选进入抽屉。模板在窄屏切换填写与预览，按钮避免遮挡输入。

核对 360、768 和 1440 像素宽度，200% 缩放、键盘顺序、可见焦点、表单标签、对比度和图片替代文字。所有对照示例同时使用文字标签；不单靠颜色解释好坏。

## 7 模板与学习记录契约

### 7.1 模板定义

模板包包含 `templateId`、`schemaVersion`、`contentRevision`、语言、标题、用途、分组、字段、填写说明、默认空值、原创示例和许可。字段支持短文本、长文本、选择和重复行；必填、长度上限、选项与重复行数量由定义声明，校验在程序中执行。

字段 ID 跨语言保持稳定。原创示例是只读参考，“用示例填入”需要用户主动选择；已有草稿时先提供导出与覆盖提示。展示与导出将输入当作纯文本，不执行用户输入的 HTML 或脚本。

### 7.2 保存与导出

本地存储以模板 ID、语言和 schema 版本隔离；另存用户草稿的内容版本、时间与修订信息。显示保存状态，写入失败保留当前输入并提示下载，不能显示虚假保存成功。

模板定义更新后，同 schema 只合并仍兼容的字段；未知字段和旧草稿保留导出能力。schema 不兼容时禁止静默覆盖旧草稿，提供旧版导出和新模板入口。

复制与 Markdown 下载包含模板身份、版本、填写结果和必要来源说明。支持空表、中文、英文、多行、特殊字符和重复行；导出顺序与表单一致。用户可清空指定模板，清空前明确其范围。

阅读记录使用内容与路线的稳定 ID。路线步骤改动或内容大幅修订时提示更新；本地进度不视为跨设备账号数据或学习成绩。

## 8 双语与搜索施工契约

中文研究稿与英文教学稿共享学习目标、事实依据、模板字段和关系引用。术语表由统一词表生成；实质正文更新使对应译文进入待复核，发布清单只收录符合双语要求的核心条目。

Pagefind 索引仅从正式 HTML 生成，按 `lang` 区分语言；中文使用支持分词的发行版本。对“章末钩子 / chapter hook”等别名增加人工检索元数据，对系统文与 LitRPG 等相邻概念使用相关提示，不当作完全同义词。

建立固定的 20 组搜索验收用例：中文与英文各 10 组，每种语言覆盖标题 3 组、问题表达 2 组、术语/别名 2 组、多筛选组合 1 组、无结果 1 组和草稿泄漏反例 1 组。结果须包含指定已发布目标，首个相关结果进入前五；无结果和草稿反例不允许返回无权公开内容。查询清单在 AC-06 随实际内容冻结。

结构化数据、规范地址和中英对应链接由出版清单生成；未发布页面不生成 sitemap 条目。不因技术标签齐全而承诺搜索排名或自然流量。

| 场景 | 操作 | 预期 |
|---|---|---|
| 英文新手 | 从首页进入开篇路线，读教程，填模板并下载 | 能带走自己的故事设计，知道下一步 |

## 11 发布与恢复步骤

1. 冻结学院内容清单、稿件审核版本与代码提交，通过学院定向检查和正式构建。
2. 在独立预览环境检查中英页面、搜索、模板、移动端及草稿隔离；保留前一可用构建。
3. 核对实际 DNS 管理权、托管项目与现有记录，再添加 `academy` 解析和 HTTPS 绑定；不覆盖官网、文档站或邮件记录。
4. 发布学院，回读首页、两种语言、代表性教程、拆书、模板导出与未知路径，记录正式地址、提交、时间和构建版本。
5. 学院成功后，在官网功能分支增加学院入口；按官网现有国内/海外配置分别构建检查。合并和部署后，回读导航与返回路径。
6. 发布失败时恢复上一学院构建。官网入口失效时恢复导航变更或提供明确维护说明；用户设备上的模板草稿保留。
