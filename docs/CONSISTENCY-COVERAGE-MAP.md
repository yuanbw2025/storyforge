# 一致性覆盖地图 + 反例基线(诚实现状 · 供审查)

> **目的**:用可证伪的方式,如实标出"当前每一类矛盾,是代码**硬检测** / LLM **软检测** / **完全没检测**",作为一致性工程化的真实起点与度量基线。
> **为什么有这份**:根治"把'代码跑通 / 上下文装配成功'冒充'内容一致'"的过度承诺(`CLAUDE.md` 反复警告的"自己说修了实际无效")。实例:曾声称"上下文能保持一致",实则**世界起源 ↔ 力量体系互斥**。
> **状态**:Claude 基于代码逐条核查起草 2026-07-10；2026-07-25 落为可执行基线。每条反例由
> `tests/canon/` 显式标为已覆盖或 `todo`，CI 通过 `npm run check:canon-coverage` 防止地图与测试漂移。

---

世界冻结语义与未来查询/推演的设计和验收矩阵见 [叙事世界基座](./products/WORLD-ENGINE.md) §10、§12～19；本次设计不改变下表的实现/检测等级。

## 0. 一句话现状(不粉饰)

经代码核查并逐类落反例后，项目现有四类可执行的语义硬比对：物品重复获得、角色认知边界、已确认世界宪法互斥、角色存亡时序。认知与存亡的**闭集比对是代码确定性的，但前置语义引用抽取仍由 LLM 完成，可能漏检**；世界宪法也只保证已登记来源、受控主题、逐字证据且经作者确认的断言。其余能力要么是检索期过滤 / 结构写回校验 / 状态投影（有用，但不等于任意语义一致），要么是 **LLM 软审校（只提示、不阻断、会漏）**。

**两个维度必须分清(GPT 审查请重点看这里):**
- **检测可靠性**:🟢硬(代码确定性检出,不漏)/ 🟡软(LLM 检出,会漏会误)/ 🔴无(没有任何检出)。
- **处置强度**：正文检测（物品、认知、存亡）仍是 advisory，不阻断生成或自动改稿；世界宪法候选在作者确认时遇到同主体同主题异值会 blocking，只有独立的第二次明确取代操作才能关闭未锁定旧 Canon。

## 1. 覆盖地图(逐类 · 代码为证)

| 矛盾类别 | 现状机制 | 代码依据 | 检测等级 | 处置 |
|---|---|---|---|---|
| 物品重复获得(已持有又写成首次获得) | 从 itemLedger 投影持有物,确定性比对 | `consistency/held-items.ts` `checkHeldItemAcquisition` | 🟢硬 | advisory |
| 规范章序 / 输入排序 | 规范大纲遍历得唯一章序(**不判剧情时间线**:如"第3章死者第5章出场"不归它,见 R-CANON-timeline-1) | `chapter-memory/canonical-chapter-sequence.ts` | 🟢硬(顺序基础,非剧情时间线语义) | 用于装配 |
| 检索期未来泄漏 / 跨世界串台 | 只召回当前章之前 + 同 worldGroupId | `retrieval/retrieval.ts` 硬过滤 | 🟢硬(降风险,**不保证输出**) | 影响输入 |
| 单基数状态漂移(如"所在地点") | 新事实按规范章序 supersede 旧；逆序确认保留后章当前状态 | `fact-ledger/fact-ledger.ts` `conflictPolicy:'supersede'` | 🟡(投影状态,**不判任意正文语义**) | 覆盖 |
| 写回字段合法性(类型/枚举/FK/去重) | 采纳校验 | `adopt()` + `FIELD_REGISTRY` + `ADOPTION_SCHEMAS` | 🟢硬(结构,**非内容语义**) | 阻断非法写回 |
| 一般语义矛盾(正文自相矛盾 / 违反证据) | LLM 审校,逐字引文 findings + severity | `adapters/consistency-audit-adapter.ts`(**不自动改、不阻断**) | 🟡软(会漏会误) | advisory→ReviewPanel |
| AI 味 / 八股 / 破折号泛滥 | LLM 检测 + 建议 | `adapters/anti-ai-adapter.ts` | 🟡软 | advisory |
| **设定 ↔ 设定语义冲突(世界起源↔力量体系、故事核心↔角色档案…)** | 来源/主题/主体闭集抽取为 candidate；作者确认时同主题异值硬阻断 | `setting-assertions.ts` + `confirmFactCandidate` | 🟢硬（只覆盖已登记、已抽取、来源有效的断言） | 阻止确认；明确取代需第二次作者操作 |
| 认知边界 / 开天眼(角色表现出知道未获知信息) | 已确认认知事件按规范章序投影；LLM 只从闭集提取逐字引用；代码比对 unknown/mistaken | `knowledge-ledger/knowledge-ledger.ts` + `ReviewPanel` | 🟢硬比对（前置抽取仍🟡，会漏） | advisory |
| 角色存亡时序(已死亡角色在后章正常活动) | confirmed/superseded 历史 Canon 按规范章序投影；LLM 从死亡角色闭集提取正常活动逐字引文；代码比对 | `consistency/lifecycle-boundary.ts` + `ReviewPanel` | 🟢硬比对（前置抽取仍🟡；章内复杂时序未覆盖） | advisory |
| 角色动机 / 性格 OOC | 无专门检测(除非 LLM 审校碰巧提到) | 无 | 🟡/🔴 | advisory(碰运气) |
| 伏笔埋而不收 | 伏笔系统记状态,不强制检测未回收 | 伏笔 store(状态记录,非检测) | 🟡 | advisory |

**读法**：🟢 只对表中明确闭集和反例负责；设定、认知、存亡的开放自然语言抽取仍会漏，角色 OOC、复杂剧情时间、伏笔等仍主要是软审。世界宪法在“确认 Canon”这一步会阻止冲突，其余 finding 仍是 advisory。

## 3. 方法论(杜绝再次过度承诺)

1. **任何一致性声明 = 三段式**:"🟢 这 N 类我硬检测(附反例测试)+ 🟡 这 M 类只有软提示 + 🔴 这 K 类没覆盖"。**不许只说"一致了"**。
2. **绿灯只对它测的那件事有效**:"代码跑通 / 上下文装配成功"是一回事,"内容一致"是另一回事,不得互相冒充。
3. **覆盖地图是活文档**:每块 `CONSISTENCY-*` 砖落地,必须回来更新第 1 节等级 + 第 2 节考卷。
4. **硬检测 ≠ 硬处置**:可另行决定把哪些 🟢硬检测升级为 blocking / 强制作者确认（正文 finding 当前为 advisory；世界宪法确认冲突已有 blocking）。

## 4. 已交付：世界宪法 + 设定一致性校验

**问题**：散文设定之间的语义冲突，代码无法确定性解析任意自然语言。

**落地（软→硬）**：
- **抽取（软 · LLM + 作者确认）**：关键设定从登记的四类来源字段抽成结构化 candidate，包含受控主题、分类型主体、typed source FK、字段、指纹和逐字 quote。
- **比对（硬 · 代码）**：普通确认前检查同项目、同世界、同分类型主体、同主题异值；冲突即阻止。明确取代是独立作者操作，locked Canon 不可覆盖。
- **回注**：只把 confirmed 且来源仍有效的宪法注入生成与审校；来源修改自动 stale。
- **诚实边界**：只有已登记、已抽取并经作者确认的设定进入硬保证；未登记散文和复杂条件规则仍属软审计。

实现复用 `temporalFacts`，未另建平行 Canon 表；`canonAssertions` 走 `assembleContext`，
四类来源 FK 进入 `PROJECT_TABLES` 导出/导入重映射，候选采纳与来源失效均有回归。

确认与明确取代在同一读写事务内重读候选、校验 owner 和来源、计算规范章序并提交。
同主体、同世界组的单值状态按事务顺序取代；逆序补章同时缩短已有历史区间，锁定的重叠区间拒绝覆盖。
候选在等待中被修改或处理时，旧确认失效；否决也不能越过已确认状态。
`currentFacts` 与存亡投影只把有可解析截止章界的 superseded 当作历史有效区间，无章界取代保留审计记录但不继续注入当前值。
定向回归见 `R-SFQA124-fact-confirmation`，实际浏览器的并发确认、锁定提示与刷新见 `quality124-fact-confirmation`。
长程一致性档案在生成正文前使用同一章界规则，并把待复核来源单列为检查结果。

## 5. 结论(给作者和 GPT 审查)

- **现状是四类语义硬比对砖（物品、认知、世界宪法、存亡）+ 检索/结构硬过滤 + 一层会漏的 LLM 软审**。除世界宪法确认冲突会被阻止外，正文 finding 仍是 advisory；闭集解决了已登记命题，不代表任意自然语言都能检测。
- **一致性工程化的真实含义**:不是"开关一开就一致",而是"**把一致性从 100% 靠祈祷,一类一类地搬进代码硬保证**",每搬一类更新这张地图。**永远会有 🔴/🟡 残留**——诚实的产品是把地图摆给用户看,而不是假装全绿。
- **先做这张地图本身,就是最该先做的一步**:它是度量基线,也是防止我(或任何接手 AI)再次过度承诺的制度防线。
